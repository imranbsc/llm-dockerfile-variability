# Run-to-run variability and smells in LLM-generated Dockerfiles

Data, scripts and results for the paper *Run-to-Run Variability and Smells in Dockerfiles Generated by Small Open-Weight Language Models* (Imran Bašić, International Burch University, 2026).

The study asked how much Dockerfiles generated by small open-weight language models differ when the same prompt is repeated, how many best-practice violations (smells) they contain, and whether sampling temperature and model size affect both.

## Design

| | |
|---|---|
| Models | Qwen2.5-Coder 1.5B, 3B and 7B (instruct), served locally by Ollama 0.40.15 in the default 4-bit quantization, CPU only |
| Prompts | 30: six technology stacks x five application types (`prompts.csv`), template "Create a Dockerfile for {app}. Return the Dockerfile only." |
| Conditions | temperature 0 and 0.8, ten runs each (seeds 1-10), 1,024-token answer limit |
| Answers | 1,800, generated on 9-10 November 2026 |
| Instruments | hadolint 2.15.1 (all rules, default severity) and the Dockerfile checks of Checkov 3.3.29 |
| Analysis | prompt as the unit of analysis; two-way repeated-measures ANOVA, with the aligned rank transform (ART) ANOVA when the residuals are not normal; Holm-corrected pairwise tests; linear trend contrast over model size |

## Main results

- At temperature 0.8, repeated files had a mean pairwise similarity of 0.50 and the base image changed between runs for 92% of prompt and model combinations; at temperature 0 the similarity was 0.98, but output was still not fully deterministic.
- 62.3% of the 1,795 valid Dockerfiles had no hadolint finding; findings clustered in package installation and in the PHP and Go prompts. 99.0% of the files never set a non-root user.
- At temperature 0.8, 63.3% of prompt and model combinations produced both a smell-free and a smelly file.
- Larger models did not produce fewer smells; the 7B model was the most consistent.

All numbers are in `results/report.txt`.

## Reproducing the analysis

Requirements: Python 3.12 or 3.13, [Ollama](https://ollama.com) and [hadolint 2.15.1](https://github.com/hadolint/hadolint/releases/tag/v2.15.1) (place `hadolint` or `hadolint.exe` in this folder).

```
pip install -r requirements.txt
python check_setup.py
python lint_all.py      # re-lint the included data
python analyze.py       # tables, tests and figures in results/
```

To generate new answers, pull the three models (`ollama pull qwen2.5-coder:1.5b`, `:3b`, `:7b`) and run `python generate.py` into an empty `data/` folder. Temperature 0 is not fully deterministic on local hardware, so a new run will not reproduce every file exactly.
