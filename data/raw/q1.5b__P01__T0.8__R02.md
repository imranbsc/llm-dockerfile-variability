```dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container to /usr/src/app
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json file to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the files to the working directory
COPY . .

# Expose the default port that the application will listen on
EXPOSE 3000

# Run the app in production mode
CMD ["node", "server.js"]
```

This Dockerfile starts with an official Node.js runtime image, sets the working directory, copies the project files into it, installs dependencies, and then runs the server using Node.js.
