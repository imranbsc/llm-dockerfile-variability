```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container to /app
WORKDIR /app

# Copy the package.json and package-lock.json files to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Expose the default port for the Node.js application
EXPOSE 3000

# Start the Node.js application when the container launches
CMD ["node", "server.js"]
```

In this Dockerfile:
- We use a base image of Node.js `node:14` to ensure we have a solid foundation for our application.
- We set the working directory inside the container to `/app`, which is where our application files will be placed.
- We copy the `package.json` and `package-lock.json` files to the working directory, which helps in installing the dependencies specified in the `package.json`.
- We install the necessary dependencies using `npm install`.
- We copy the rest of the application code from the current directory to the `/app` directory inside the container.
- We expose port `3000`, which is the default port for Node.js applications.
- Finally, we specify the command to run the Node.js application with the `CMD` instruction, which in this case is `node server.js`.
