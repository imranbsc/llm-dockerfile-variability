```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container to /app
WORKDIR /app

# Copy the package.json and package-lock.json file to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Expose port 3000
EXPOSE 3000

# Start the server when the container launches
CMD ["node", "server.js"]
```

This Dockerfile sets up a Node.js environment, installs the necessary dependencies, and then copies the rest of the application code to the container. It also exposes port 3000 and specifies the command to run the server when the container is launched.
