```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json file to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the files in the working directory to the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run the app in the background
CMD ["npm", "start", "--background"]
```

This Dockerfile sets up a Node.js application that uses BullMQ as a background worker. It installs Node.js, copies the necessary files, sets up port 3000, and runs the application in the background using `npm start --background`.
