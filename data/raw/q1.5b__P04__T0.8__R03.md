```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container to /app
WORKDIR /app

# Copy the package.json and package-lock.json files to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Expose the default port of the command-line tool
EXPOSE 3000

# Define the command to run when the container launches
CMD ["node", "index.js"]
```

In this Dockerfile:
- We use Node.js 14 as the parent image.
- We set the working directory to `/app`.
- We copy the `package.json` and `package-lock.json` files to the working directory.
- We install the necessary packages specified in `package.json`.
- We copy the rest of the application code to the working directory.
- We expose the default port of the command-line tool (3000).
- We define the command to run when the container launches (`node index.js`).
