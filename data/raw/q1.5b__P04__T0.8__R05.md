```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container at /usr/src/app
COPY . .

# Expose the default Node.js port
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run the command when the container launches
CMD ["node", "index.js"]
```

In this Dockerfile, we start with the official Node.js runtime image version 14. We set the working directory to `/usr/src/app`, where our Node.js application will be installed and run. We then copy the `package.json` and `package-lock.json` files to this directory to install the dependencies. After that, we copy the rest of the application code from the current directory to `/usr/src/app`. We expose the default Node.js port 3000 and set an environment variable `NAME` to `World`. Finally, we run the Node.js application using `node index.js`.
