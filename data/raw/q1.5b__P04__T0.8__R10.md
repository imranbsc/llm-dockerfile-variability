```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files into the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application into the container
COPY . .

# Expose the port that the command-line tool will run on
EXPOSE 3000

# Define the command to run when the container launches
CMD ["npm", "start"]
```

This Dockerfile starts with an official Node.js runtime, sets the working directory, copies the necessary files, installs dependencies, copies the project files, exposes the required port, and defines the command to execute the tool.
