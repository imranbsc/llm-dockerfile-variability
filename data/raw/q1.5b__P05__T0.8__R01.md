```dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the package.json and package-lock.json files to the container at /app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container at /app
COPY . .

# Set the environment variable for node-cron
ENV CRON_EXPRESSION "0 0 * * *"  # Run the job every day at midnight

# Run the scheduled batch job
CMD ["node", "your-script.js"]
```

In this Dockerfile:
- We start with a Node.js runtime image `node:14-slim`.
- We set the working directory to `/app`.
- We copy the `package.json` and `package-lock.json` files to the container.
- We install any dependencies listed in `package.json`.
- We copy the rest of the application code to the container.
- We set the environment variable `CRON_EXPRESSION` to run the batch job every day at midnight.
- Finally, we run the scheduled batch job by executing `node your-script.js`.
