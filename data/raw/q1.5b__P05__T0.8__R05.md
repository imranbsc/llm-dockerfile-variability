```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the working directory
COPY package*.json .

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the project files to the working directory
COPY . .

# Set the environment variable for NODE_ENV
ENV NODE_ENV production

# Run the scheduled batch job
CMD ["node", "src/batchJob.js"]

# Expose the port that the scheduled batch job is listening on
EXPOSE 3000

# Define the command to run the scheduled job on a regular schedule
RUN crontab -e <<EOF
0 0 * * * /usr/bin/node src/batchJob.js
EOF
```

This Dockerfile creates a scheduled batch job built in Node.js using node-cron. It sets up a Node.js runtime, copies the necessary files, installs dependencies, sets the environment variable, and configures the scheduled job to run on a regular schedule.
