```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --trusted-host pypi.python.org -r requirements.txt

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "manage.py", "runserver", "0.0.0.0:80"]
```

### Explanation:
1. **Base Image**: We start with the official Python 3.8 runtime image (`python:3.8-slim`).
2. **Working Directory**: Set the working directory inside the container to `/app`.
3. **Copy Files**: Copy the current directory contents into the container at `/app`.
4. **Install Packages**: Install the required packages specified in `requirements.txt` using `pip`.
5. **Expose Port**: Make port 80 available to the world outside this container.
6. **Environment Variable**: Define the environment variable `NAME` with the value `World`.
7. **Command**: Run the Django server when the container launches with the command `python manage.py runserver 0.0.0.0:80`.

### Usage:
To build and run this Docker image, follow these steps:

1. Create a `requirements.txt` file with the required Python packages for your Django application.
2. Build the Docker image:
   ```sh
   docker build -t my-django-server .
   ```
3. Run the container:
   ```sh
   docker run -p 8000:80 my-django-server
   ```

This will start a Django server running in a Docker container, serving your application from port 8000.
