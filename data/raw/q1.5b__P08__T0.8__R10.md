```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5555 available to the world outside this container
EXPOSE 5555

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

This Dockerfile sets up a Python environment using Python 3.8, copies the current directory into the container, installs the required packages from `requirements.txt`, exposes port 5555, and sets the environment variable `NAME` to "World". The `CMD` instruction specifies that when the container launches, it should execute `python app.py`, which is assumed to be the entry point of your Celery application.
