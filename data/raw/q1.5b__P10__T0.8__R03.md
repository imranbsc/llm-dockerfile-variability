```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Define the command to run the scheduled batch job
CMD ["python", "run_batch_job.py"]
```

### Explanation:
1. **Base Image**: `python:3.9-slim` is used as the base image, which is a lightweight version of the official Python image. This ensures that the Docker image is small and efficient.
2. **Working Directory**: The working directory in the container is set to `/app`, where the Python application will be placed.
3. **Copying Files**: The contents of the current directory (`.`) are copied into the `/app` directory inside the container.
4. **Installing Packages**: The `requirements.txt` file is used to install any required Python packages. The `--no-cache-dir` option ensures that the packages are installed without caching.
5. **Command**: The command to run the scheduled batch job is defined as `CMD ["python", "run_batch_job.py"]`. This tells Docker to execute the `run_batch_job.py` script when the container is started.

To build and run this Docker image, you can use the following commands:
```sh
# Build the Docker image
docker build -t my-scheduled-job .

# Run the Docker container
docker run -d --name my-scheduled-job my-scheduled-job
```

Make sure to replace `requirements.txt` and `run_batch_job.py` with your actual requirements and batch job script.
