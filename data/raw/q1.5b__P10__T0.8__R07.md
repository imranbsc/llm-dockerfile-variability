```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Set the environment variable for APScheduler
ENV APSCHEDULER_CONFIG_FILE=/app/scheduler.cfg

# Expose the port that your application listens on
EXPOSE 5000

# Define the command to run your scheduled batch job
CMD ["python", "-m", "apscheduler.schedulers.background.BackgroundScheduler", "--loglevel=info", "your_script.py"]
```

### Explanation:
1. **Base Image**: The image `python:3.8-slim` is used as the base image, which provides a lightweight Python runtime.
2. **Working Directory**: The working directory in the container is set to `/app`.
3. **Copying Files**: The current directory contents are copied into the container at `/app`.
4. **Installing Packages**: Any packages listed in `requirements.txt` are installed using `pip`.
5. **Environment Variable**: The environment variable `APSCHEDULER_CONFIG_FILE` is set to the path of the scheduler configuration file (`scheduler.cfg`).
6. **Exposing Port**: The port `5000` is exposed to allow your application to listen on that port.
7. **Running Command**: The command `python -m apscheduler.schedulers.background.BackgroundScheduler --loglevel=info your_script.py` is used to run the scheduled batch job.

Make sure you have the `apscheduler` package installed in your Python environment and that `scheduler.cfg` is correctly configured for APScheduler to run your scheduled tasks.
