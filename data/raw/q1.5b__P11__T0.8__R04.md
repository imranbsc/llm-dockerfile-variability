```Dockerfile
# Use an official Java runtime as a parent image
FROM openjdk:11-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the Spring Boot app
CMD ["java", "-jar", "target/your-spring-boot-app.jar"]
```

In this Dockerfile, we start by using an official Java runtime image (`openjdk:11-slim`) as a parent image. The working directory is set to `/app`, which is where our Java application will be stored. The current directory contents are copied into this directory, and the `EXPOSE` statement specifies that the application should listen on port 8080. Finally, the `CMD` statement runs the Spring Boot application using the `java` command with the appropriate JAR file.
