```Dockerfile
# Use an official Java runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the Java executable and the JAR file
CMD ["java", "-jar", "target/*.jar"]
```

This Dockerfile sets up a basic Java runtime, copies the project files into the container, and specifies the port to listen on. The command to run the application is provided, which is typically the Java executable followed by the JAR file generated by your Spring Boot application.
