```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jre-slim

# Set the working directory in the container to /app
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in package.json or Gemfile
RUN npm install

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV NAME World

# Run the application
CMD ["java", "-jar", "target/your-application.jar"]
```
In this Dockerfile:
- It starts with an official OpenJDK runtime image.
- The working directory is set to `/app`.
- The current directory contents are copied into the container at `/app`.
- Any packages specified in `package.json` or `Gemfile` are installed.
- Port 8080 is exposed to the world outside this container.
- An environment variable `NAME` is set to `World`.
- Finally, the application is run using `java -jar target/your-application.jar`. Replace `your-application.jar` with the actual name of your compiled Spring Boot application jar.
