```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.16

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Build the Go app
RUN go build -o app

# Run the app in the background
CMD ["./app"]
```

This Dockerfile sets up a Go application using the Go 1.16 runtime. It copies the project files into the container, builds the application into the `/app` directory, and then runs the built binary as the container's main process.
