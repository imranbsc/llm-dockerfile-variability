```Dockerfile
# Use a Go runtime as the base image
FROM golang:1.18

# Set the working directory in the container
WORKDIR /app

# Copy the Go source code into the container
COPY . .

# Build the Go application
RUN go build -o server

# Set the environment variable for the server port
ENV PORT=8080

# Run the Go server when the container starts
CMD ["./server"]
```

This Dockerfile sets up a Go server that can be run as a Docker container. The Go source code is copied into the container, and the server is built using the `go build` command. The server runs on the default port (8080) and is set to listen for incoming connections.
