```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go get -v -t ./...

# Run the app in the background
CMD ["go", "run", "./your-worker.go"]
```

In this Dockerfile:
- We use the official Go runtime as a parent image.
- We set the working directory to `/app` where our Go files will be located.
- We copy the current directory contents into the container at `/app`.
- We install any dependencies specified in `requirements.txt` using `go get`.
- Finally, we run the Go worker in the background using `go run ./your-worker.go`. Replace `your-worker.go` with the actual name of your Go worker file.
