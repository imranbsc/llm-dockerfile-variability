```dockerfile
# Use an official PHP image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in composer.json
RUN composer install --optimize-autoloader

# Expose the default Laravel port
EXPOSE 80

# Define environment variable
ENV APP_ENV development

# Run any commands you need when the container launches
CMD ["php", "artisan", "serve"]
```

This Dockerfile sets up a PHP-FPM container based on the official PHP 7.4 image. It copies the current directory contents into the container, installs the necessary PHP extensions, sets the working directory, and exposes the default Laravel port. The CMD command runs the Laravel development server.
