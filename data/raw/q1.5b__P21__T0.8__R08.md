```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install

# Expose the default HTTP port
EXPOSE 80

# Define environment variable
ENV NAME World

# Run your app when the container launches
CMD ["php", "index.php"]
```

This Dockerfile sets up a PHP environment with Laravel, copies the project files into the container, installs dependencies, and exposes the default HTTP port. The `CMD` line specifies how to start the application when the container runs.
