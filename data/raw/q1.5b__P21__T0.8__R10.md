```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install

# Expose the default HTTP port
EXPOSE 9000

# Make port 9000 available to the world outside this container
VOLUME /var/www/html/storage/app/public

# Define environment variables
ENV NAME World

# Run your app
CMD ["php", "artisan", "serve"]
```

This Dockerfile sets up a PHP-FPM container using the PHP 8.1-fpm image. It copies the current directory contents into the container at /var/www/html, installs the dependencies specified in requirements.txt, and exposes the default HTTP port. The environment variable NAME is set to World, and the CMD command runs the Artisan serve command to start the PHP development server.
