```dockerfile
# Use a base PHP image
FROM php:8.0-fpm-alpine

# Set the working directory in the container
WORKDIR /var/www/html

# Install dependencies
COPY composer.json .
COPY composer.lock .
RUN composer install --no-dev

# Copy the rest of the project files
COPY . .

# Expose the default HTTP port
EXPOSE 9000

# Start the PHP-FPM service
CMD ["php-fpm"]
```

This Dockerfile sets up a basic PHP environment using PHP 8.0 with FPM. It installs dependencies using Composer, copies the project files from the host to the container, and exposes the default HTTP port for the web server. The `CMD` instruction runs PHP-FPM to start the server.
