```Dockerfile
# Use a stable PHP image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the composer.json and composer.lock files from the host to the container
COPY composer.json composer.lock ./

# Install dependencies using Composer
RUN composer install --prefer-dist --optimize-autoloader

# Copy the application files from the host to the container
COPY . .

# Set the environment variables
ENV APP_ENV development

# Expose the default port for PHP-FPM
EXPOSE 9000

# Start the Laravel queue worker
CMD ["php artisan", "queue:work"]
```

This Dockerfile sets up a PHP-FPM container with the PHP version 7.4 and the Laravel framework. It installs the necessary dependencies, copies the Laravel application files, sets the environment variables, and exposes the default port for PHP-FPM. Finally, it runs the Laravel queue worker.
