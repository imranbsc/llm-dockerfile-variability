```Dockerfile
# Use an official PHP:7.4-fpm image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libpq-dev \
    && docker-php-ext-install pdo-pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install the dependencies
RUN composer install --optimize-autoloader

# Expose the default Laravel port
EXPOSE 8000

# Run the Laravel command to start the queue worker
CMD ["php", "artisan", "queue:work"]
```

This Dockerfile sets up a PHP environment with Laravel queues, installs necessary packages, and runs the Laravel queue worker in the background.
