```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.0-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install --optimize-autoloader

# Run any commands to run your app
CMD ["php", "artisan", "queue:work", "--daemon"]
```

This Dockerfile sets up a PHP environment with Laravel queues running in the background. It uses the official PHP 8.0 FPM image as the base image, sets the working directory to `/var/www/html`, copies the current directory contents into the container, installs any required packages specified in `requirements.txt` using Composer, and runs `php artisan queue:work --daemon` to start the background worker.
