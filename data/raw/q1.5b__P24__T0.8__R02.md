```dockerfile
# Use a base PHP image
FROM php:8.0-fpm-alpine

# Set the working directory in the container
WORKDIR /var/www/html

# Install any required dependencies
RUN composer install --optimize-autoloader

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Define environment variable
ENV APP_ENV dev

# Expose the default console port
EXPOSE 9000

# Define the command to run
CMD ["php", "./bin/console"]
```

This Dockerfile sets up a basic PHP environment using the PHP:8.0-fpm-alpine image. It installs the dependencies specified in the `composer.json` file, copies the current directory contents into the container, sets the working directory, and defines the command to run the Symfony Console.
