```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.0-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install --optimize-autoloader

# Expose the default HTTP port
EXPOSE 80

# Define environment variables
ENV NAME World

# Run the command when the container launches
CMD ["php", "bin/console", "server:web:8000"]
```

**Explanation**:
- The `FROM` line specifies the parent image, which in this case is `php:8.0-fpm`. This image includes a recent version of PHP with the FPM (FastCGI Process Manager) which is suitable for running PHP applications.
- The `WORKDIR` command sets the working directory inside the container, which is set to `/var/www/html`.
- The `COPY` commands are used to copy the current directory contents into the container at `/var/www/html`. This allows you to include your PHP application files and dependencies directly in the Docker image.
- The `RUN composer install --optimize-autoloader` command installs the necessary PHP dependencies using Composer and optimizes the autoloader.
- The `EXPOSE` command specifies that the HTTP server will listen on port 80. This is important for running web applications.
- The `ENV` command sets an environment variable `NAME` to the default value "World". This can be overridden when running the container.
- The `CMD` command specifies the command to run when the container launches. In this case, it starts the PHP-FPM server with the Symfony Console server running on port 8000.
