```Dockerfile
# Use a stable PHP image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    curl \
    git \
    && rm -rf /var/lib/apt/lists/*

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies using Composer
RUN composer install

# Expose the default PHP-FPM port
EXPOSE 9000

# Start the PHP-FPM service
CMD ["php-fpm", "-F"]
```

This Dockerfile sets up a PHP environment with Symfony Console by using the official PHP 7.4-fpm image as the base. It installs necessary packages, sets up the working directory, copies the current directory contents into the container, installs Composer, installs dependencies, exposes the default PHP-FPM port, and starts the PHP-FPM service.
