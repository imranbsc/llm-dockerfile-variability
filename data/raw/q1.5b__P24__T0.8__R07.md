```Dockerfile
# Use an official PHP image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in composer.json
RUN composer install --optimize-autoloader

# Define environment variables
ENV APP_ENV prod

# Expose the default port
EXPOSE 9000

# Define the command to run when the container launches
CMD ["php", "bin/console", "serve:web"]
```

This Dockerfile sets up a basic PHP environment using the official PHP 7.4-FPM image. It copies the current directory contents into the container, installs any necessary packages from `composer.json`, sets the working directory, exposes the default port, and defines the command to run when the container launches. The command runs the Symfony Console `serve:web` command, which starts a web server on the specified port.
