```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.0-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install

# Install php artisan schedule job
RUN php artisan schedule:run

# Define environment variables
ENV APP_ENV=production

# Define the command to run when the container launches
CMD ["php", "artisan", "schedule:run"]
```

In this Dockerfile, we start by using the official PHP runtime as a parent image. We set the working directory in the container to `/var/www/html` and copy the current directory contents into the container at `/var/www/html`. We then install any needed packages specified in `requirements.txt` using Composer. After that, we install the Laravel task scheduler using `php artisan schedule:run`. We define the environment variable `APP_ENV` as `production`. Finally, we define the command to run when the container launches, which is `php artisan schedule:run`. This ensures that the scheduled batch job is executed on every container start.
