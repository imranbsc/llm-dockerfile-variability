```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.0-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install --optimize-autoloader

# Expose the default Laravel port
EXPOSE 80

# Define environment variable
ENV APP_ENV development

# Set the command to run the scheduled tasks
CMD ["/usr/local/bin/php", "artisan", "schedule:run"]
```

In this Dockerfile, we start with the official PHP 8.0-FPM image as the parent image. We set the working directory to `/var/www/html`, which is where our Laravel project will be installed. We copy the current directory contents into this directory, ensuring that our PHP application is ready to run.

After copying the files, we install any necessary packages required by our Laravel application using Composer. The `--optimize-autoloader` flag helps in speeding up the application by enabling the autoloader.

We then expose the default Laravel port 80, which is the standard port for HTTP traffic. We set the environment variable `APP_ENV` to `development`, which is a common way to differentiate between development and production environments in Laravel.

Finally, we define the command to run the scheduled tasks using PHP. The `artisan schedule:run` command is used to execute the scheduled tasks defined in the `app/Console/Kernel.php` file. This command is run as the default command when the container starts.
