```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install --optimize-autoloader

# Run the artisan schedule:run command to execute scheduled jobs
CMD ["php", "artisan", "schedule:run"]
```

In this Dockerfile, we start with the official PHP 8.1-FPM image as the parent image. We set the working directory to `/var/www/html` where our Laravel application is located. We then copy the contents of the current directory into the container at `/var/www/html`. After installing any necessary packages specified in the `requirements.txt` file using Composer, we run the `artisan schedule:run` command to execute scheduled jobs. This allows the scheduled tasks in your Laravel application to be executed in a scheduled manner.
