```Dockerfile
# Use a PHP image as the base image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the Composer configuration and dependencies
COPY composer.json ./
COPY composer.lock ./

# Install dependencies
RUN composer install --prefer-dist --no-dev

# Copy the application code into the container
COPY . .

# Run the Laravel artisan console command to migrate the database
CMD ["php", "artisan", "migrate"]
```

This Dockerfile starts with a PHP 8.1-FPM image as the base image. It sets the working directory to `/var/www/html`. The `composer.json` and `composer.lock` files are copied into the container to install the dependencies. The application code is then copied into the container. The `CMD` instruction runs the Laravel artisan console command to migrate the database upon container startup.
