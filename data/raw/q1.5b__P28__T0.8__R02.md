```dockerfile
# Use a official .NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
COPY ./WorkerService /app

# Set the entrypoint for the container
ENTRYPOINT ["dotnet", "WorkerService.dll"]
```

This Dockerfile sets up a basic .NET Core runtime container and copies the worker service project into the container. The entrypoint is set to execute the worker service executable.
