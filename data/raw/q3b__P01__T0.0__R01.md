Certainly! Below is a simple Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a basic Node.js application set up with an Express server.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Expose the port your application runs on
EXPOSE 3000

# Start the application
CMD ["node", "app.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies that the base image for the container is the official Node.js image version 14. You can choose a different version if needed.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory inside the container to `/usr/src/app`. This is where your application code will be stored.

3. **Copy Dependencies**: The `COPY package*.json ./` line copies the `package.json` and `package-lock.json` files into the container. These files are used by npm to install the project dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` line copies the rest of your application code into the container.

6. **Expose Port**: The `EXPOSE 3000` line tells Docker that the application listens on port 3000.

7. **Start Application**: The `CMD ["node", "app.js"]` line specifies the command to run when the container starts. This assumes that your application is named `app.js`.
