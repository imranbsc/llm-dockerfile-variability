Certainly! Below is a simple Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a basic Node.js application set up with an `index.js` file as the entry point.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run the application
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies that the base image for the container is the official Node.js image version 14. You can choose a different version if needed.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory inside the container to `/usr/src/app`. This is where your application files will be stored.

3. **Copy Dependencies**: The `COPY package*.json ./` line copies the `package.json` and `package-lock.json` files into the container. These files are used to install the application dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` line copies the rest of your application code into the container.

6. **Expose Port**: The `EXPOSE 3000` line tells Docker that the application listens on port 3000.

7. **Run Command**: The `CMD ["node", "index.js"]` line specifies the command to run when the container starts. This is the entry point of your application.

### Building and Running the Docker Image:

To build the Docker image, navigate to the directory containing the Dockerfile and run:

```sh
docker build -t my-node-api .
```

This will create a Docker image named `my-node-api`.

To run the container, use:

```sh
docker run -p 3000:3000 my-node-api
```

This will start a container and map port 3000 of the host to port 3000 of the container, allowing you to access your API at `http://localhost:3000`.
