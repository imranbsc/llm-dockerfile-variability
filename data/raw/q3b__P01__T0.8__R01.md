Here's a Dockerfile for a REST API built in Node.js using Express. This Dockerfile sets up a Node.js environment with Express and installs the necessary dependencies.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV PORT 3000

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Start the app
CMD ["node", "server.js"]
```

To use this Dockerfile, save it to a file named `Dockerfile` in the root directory of your Node.js project, and then run the following commands in the terminal to build and run the Docker container:

```bash
docker build -t my-node-express-app .
docker run -p 3000:3000 my-node-express-app
```

This will build a Docker image named `my-node-express-app` from the Dockerfile and run it, mapping port 3000 on the host to port 3000 in the container.
