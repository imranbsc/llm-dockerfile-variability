Certainly! Below is a simple Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a basic `package.json` file in your project.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . .

# Install any needed packages specified in package.json
RUN npm install

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run app.js when the container launches
CMD [ "node", "app.js" ]
```

### Explanation:

1. **Base Image**: `FROM node:14-alpine` - This line specifies the base image to use, which is an official Node.js image optimized for Alpine Linux. This is a lightweight version of Node.js that is great for production use.

2. **Working Directory**: `WORKDIR /usr/src/app` - This sets the working directory inside the container to `/usr/src/app`. This is where the application files will be placed.

3. **Copy Files**: `COPY . .` - This copies all files from the current directory (your project root) into the working directory inside the container.

4. **Install Dependencies**: `RUN npm install` - This installs all the dependencies listed in your `package.json` file.

5. **Expose Port**: `EXPOSE 3000` - This makes port 3000 available to the world outside this container. This is necessary because when you run your Docker container, you can access it on `localhost:3000`.

6. **Start the Application**: `CMD [ "node", "app.js" ]` - This command tells the container to start the application when it runs. `app.js` is the entry point of your application.

### How to Use the Dockerfile:

1. Save the Dockerfile to a file named `Dockerfile` in the root of your Node.js project directory.

2. Build the Docker image by running the following command in your terminal:
   ```bash
   docker build -t your-image-name .
   ```

3. Run the Docker container by executing:
   ```bash
   docker run -p 3000:3000 your-image-name
   ```

This will start your Node.js application inside a Docker container, and you can access it on `localhost:3000`.
