Certainly! Below is a simple Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a basic setup for your Node.js application, including a `package.json` file and an entry point (like `server.js`).

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . .

# Install any needed packages specified in package.json
RUN npm install

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run app.js when the container launches
CMD [ "node", "server.js" ]
```

### Explanation:
- **FROM node:14**: This line specifies that the base image for the container will be the official Node.js image with version 14.
- **WORKDIR /usr/src/app**: This sets the working directory inside the container where your application files will be stored.
- **COPY . .**: This copies all files from the current directory to the `/usr/src/app` directory inside the container.
- **RUN npm install**: This installs all the dependencies listed in your `package.json` file.
- **EXPOSE 3000**: This makes port 3000 available for external connections.
- **CMD [ "node", "server.js" ]**: This command specifies that the application should be run using Node.js to execute the `server.js` file when the container starts.

### How to Use:
1. Save the Dockerfile to a file named `Dockerfile` in the root directory of your project.
2. Make sure you have a `package.json` file in your project root with all necessary dependencies.
3. Create a `server.js` file with your Express application setup.
4. Build the Docker image by running `docker build -t my-node-app .` in your terminal.
5. Run the Docker container with `docker run -p 3000:3000 my-node-app`.

This setup provides a basic environment for running a Node.js Express application in a Docker container.
