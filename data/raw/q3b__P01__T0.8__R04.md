```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of the application code to the container
COPY . .

# Build the application
RUN npm run build

# Expose the port on which the application will run
EXPOSE 3000

# Start the application
CMD ["node", "dist/server.js"]
```

### Explanation:

- **FROM node:14-alpine**: This line specifies the base image to use for the container. `node:14-alpine` is a lightweight version of the official Node.js image that uses Alpine Linux, making it smaller and faster to build.
  
- **WORKDIR /usr/src/app**: This sets the working directory within the container where the application files will be stored.

- **COPY package*.json ./**: This command copies the `package.json` and `package-lock.json` files from the host machine to the working directory in the container.

- **RUN npm install**: This command installs all the dependencies listed in `package.json`.

- **COPY . .**: This command copies the rest of the application code (excluding `node_modules`) to the container.

- **RUN npm run build**: This command runs the build process defined in your `package.json` to prepare the application for production.

- **EXPOSE 3000**: This line informs Docker that the application will be listening on port 3000.

- **CMD ["node", "dist/server.js"]**: This sets the default command to run when the container starts, which is to execute the `server.js` file located in the `dist` directory after building the application.
