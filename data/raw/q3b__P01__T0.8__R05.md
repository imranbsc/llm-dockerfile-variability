Certainly! Below is a simple Dockerfile to create a Docker image for a REST API built in Node.js using Express. This example includes setting up Node.js and installing necessary dependencies.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json file and install dependencies
COPY package*.json ./

RUN npm install

# Copy the rest of your application code
COPY . .

# Expose the default port for Express applications
EXPOSE 3000

# Start the application
CMD ["node", "app.js"]
```

### Explanation:

1. **Base Image**: 
   - `FROM node:14-alpine` uses the latest Node.js 14 image from Docker Hub. Alpine version is used for smaller image size.

2. **Working Directory**:
   - `WORKDIR /usr/src/app` sets the working directory inside the container to `/usr/src/app`, which is where your application code will be stored.

3. **Install Dependencies**:
   - `COPY package*.json ./` copies the `package.json` and `package-lock.json` files into the container.
   - `RUN npm install` installs all the dependencies specified in the `package.json` file.

4. **Copy Application Code**:
   - `COPY . .` copies all the files from your local directory into the container, including the `app.js` file which contains your Express application code.

5. **Expose Port**:
   - `EXPOSE 3000` tells Docker that your application listens on port 3000, which is the default port for Express.

6. **Run the Application**:
   - `CMD ["node", "app.js"]` specifies the command to run when the container starts. This command tells the container to execute the Node.js application from the `app.js` file.

### Steps to Build and Run the Docker Image:

1. Save the Dockerfile in a directory with your `app.js` file and other necessary files.
2. Open a terminal and navigate to that directory.
3. Run the following commands to build and run the Docker image:

   ```sh
   docker build -t my-express-api .
   docker run -p 3000:3000 my-express-api
   ```

   - `docker build -t my-express-api .` builds the Docker image with the tag `my-express-api`.
   - `docker run -p 3000:3000 my-express-api` runs the container, mapping port 3000 of the host machine to port 3000 of the container, allowing you to access the application via `http://localhost:3000` in your browser.

This setup provides a basic structure for a Node.js Express application within a Docker container. You can customize it further by adding environment variables, configuration files, or additional services as needed.
