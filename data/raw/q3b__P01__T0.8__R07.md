Certainly! Below is a simple Dockerfile for a Node.js application using Express. This Dockerfile assumes you have a Node.js application with an `index.js` file as the entry point.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . .

# Install any needed packages specified in package.json
RUN npm install

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app.js when the container launches
CMD ["node", "index.js"]
```

### Explanation:

- **FROM node:14**: This line specifies the base image for the container. In this case, it's using Node.js version 14. You can choose a different version if needed.
- **WORKDIR /usr/src/app**: This sets the working directory for the application. All subsequent `COPY` and `RUN` commands will be executed in this directory.
- **COPY . .**: This copies all files from the current directory to the working directory inside the container.
- **RUN npm install**: This installs all dependencies listed in your `package.json`.
- **EXPOSE 3000**: This exposes port 3000 so that the container can be accessed on this port outside the container.
- **ENV NAME World**: This sets an environment variable named `NAME` with the value `World`.
- **CMD ["node", "index.js"]**: This specifies the default command to run when the container starts. In this case, it runs the Node.js application using the `index.js` file.

### To Use the Dockerfile:

1. Save the above content in a file named `Dockerfile` in the root of your Node.js application directory.
2. Open a terminal, navigate to the directory containing your application, and run:
   ```bash
   docker build -t my-node-app .
   ```
3. Run the container with:
   ```bash
   docker run -p 3000:3000 my-node-app
   ```

This will start a container that runs your Node.js application, serving it on port 3000. Adjust the port mappings and environment variables as needed for your specific application.
