Certainly! Below is a simple Dockerfile to create a Docker image for a REST API built in Node.js using Express.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json into the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code into the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV PORT 3000

# Run the app using node
CMD ["node", "app.js"]
```

This Dockerfile performs the following actions:

1. **Base Image**: Uses the official Node.js image version 14 as the base image.
2. **Working Directory**: Sets the working directory to `/usr/src/app`.
3. **Copy Dependencies**: Copies the `package.json` and `package-lock.json` files into the container and installs the required Node.js dependencies.
4. **Copy Application Code**: Copies the rest of your application code into the container.
5. **Expose Port**: Exposes port 3000, which is the default port for Express applications.
6. **Environment Variable**: Defines an environment variable `PORT` to use port 3000.
7. **Run Command**: Uses Node.js to run the application, assuming it is named `app.js`.

To build and run the Docker image, use the following commands:

```sh
# Build the Docker image
docker build -t my-express-app .

# Run the Docker container
docker run -d -p 3000:3000 my-express-app
```

Make sure to replace `my-express-app` with a suitable name for your Docker image.
