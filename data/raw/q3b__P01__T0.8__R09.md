Certainly! Below is a basic Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a Node.js application with an entrypoint script that starts the Express server.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code
COPY . .

# Expose the default port for Express applications
EXPOSE 3000

# Set the default command to run the application
CMD ["node", "server.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies the base image as an official Node.js image with Node.js version 14. This image is lightweight and has all the necessary tools and libraries for building and running Node.js applications.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory within the container to `/usr/src/app`, which is where your application files will be stored.

3. **Copy Dependencies**: The `COPY package*.json ./` command copies the `package.json` and `package-lock.json` files into the working directory. These files are essential for installing your application's dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` command copies all files from the current directory (the directory containing the Dockerfile) into the working directory of the container.

6. **Expose Port**: The `EXPOSE 3000` line tells Docker that your application is listening on port 3000. This port should match the port specified in your application's server configuration.

7. **Set Default Command**: The `CMD ["node", "server.js"]` sets the default command to run when the container starts. This command starts your Express server, assuming you have a file named `server.js` in the root of your application.

### Additional Notes:

- **Environment Variables**: You can add environment variables to your Dockerfile using the `ENV` directive. For example, to set an environment variable for the port, you could use `ENV PORT 3000`.

- **Build and Run**: You can build and run this Docker image using the following commands:

  ```sh
  # Build the Docker image
  docker build -t my-express-api .

  # Run the Docker container
  docker run -p 3000:3000 my-express-api
  ```

- **Entrypoint Script**: If you have a different entrypoint script or configuration, you can modify the `CMD` directive accordingly.

This Dockerfile provides a basic setup for a Node.js Express application. You can customize it based on your specific needs.
