Certainly! Below is a simple Dockerfile for a REST API built in Node.js using Express. This Dockerfile assumes you have a basic Node.js project set up with an `index.js` file as the entry point for your application.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Expose the port your application listens on
EXPOSE 3000

# Start the application
CMD [ "node", "index.js" ]
```

### Explanation:

- **FROM node:14**: This line specifies the base image to use, which is a Node.js version 14 image from the official Docker Hub.
- **WORKDIR /usr/src/app**: This sets the working directory inside the container to `/usr/src/app`.
- **COPY package*.json ./**: This copies the `package.json` and `package-lock.json` files from the host machine to the working directory in the container.
- **RUN npm install**: This installs all the dependencies specified in the `package.json` file.
- **COPY . .**: This copies the rest of your application code to the working directory in the container.
- **EXPOSE 3000**: This makes port 3000 available to the world outside this container.
- **CMD [ "node", "index.js" ]**: This specifies the command to run when the container starts, which is to execute the `index.js` file using Node.js.

To build and run this Docker image, you would typically use the following commands:

```bash
# Build the Docker image
docker build -t my-node-api .

# Run the Docker container
docker run -p 3000:3000 my-node-api
```

This will start a container and map port 3000 on your host machine to port 3000 in the container, allowing you to access your REST API.
