Certainly! Below is a Dockerfile for a server-rendered web application built in Node.js using Next.js. This Dockerfile assumes you have a basic Next.js project set up.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code
COPY . .

# Build the application
RUN npm run build

# Expose the port Next.js runs on
EXPOSE 3000

# Start the application
CMD ["npm", "start"]
```

### Explanation:

1. **Base Image**: The `node:14` image is used as the base image, which includes Node.js and npm.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`.

3. **Copy Dependencies**: The `COPY package*.json .` command copies the `package.json` and `package-lock.json` files into the container. These files are used to install the application dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` command copies the rest of your application code into the container.

6. **Build the Application**: The `RUN npm run build` command builds the application using the `build` script defined in your `package.json`.

7. **Expose Port**: The `EXPOSE 3000` instruction tells Docker that the application listens on port 3000.

8. **Start the Application**: The `CMD ["npm", "start"]` command starts the application using the `start` script defined in your `package.json`.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-nextjs-app .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -p 3000:3000 my-nextjs-app
   ```

This will start a Next.js server on port 3000, and you can access your application by visiting `http://localhost:3000` in your web browser.
