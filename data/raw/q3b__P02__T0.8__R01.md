Here is a simple Dockerfile for a Node.js application using Next.js:

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:16

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code
COPY . .

# Build the Next.js application
RUN npm run build

# Expose the port on which Next.js is running
EXPOSE 3000

# Command to run the application
CMD ["npm", "start"]
```

This Dockerfile:

1. Uses the official Node.js 16 image as the base.
2. Sets the working directory to `/usr/src/app`.
3. Copies `package.json` and `package-lock.json` to the working directory.
4. Installs the dependencies using `npm install`.
5. Copies the rest of the application code to the working directory.
6. Builds the Next.js application using `npm run build`.
7. Exposes port 3000, the default port for Next.js.
8. Runs the application with `npm start`.

Make sure to adjust the `EXPOSE` and `CMD` commands if your application uses a different port or has a different command to start.
