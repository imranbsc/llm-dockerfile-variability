Certainly! Below is a Dockerfile for a server-rendered web application built in Node.js using Next.js. This Dockerfile assumes you have a basic Next.js application set up.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:16-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json files to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code
COPY . .

# Build the application
RUN npm run build

# Expose the default port Next.js uses for server-side rendering
EXPOSE 3000

# Start the server
CMD ["npm", "start"]
```

### Explanation:
- **Base Image**: The `node:16-alpine` image is used as the base image, which is a lightweight version of Node.js optimized for size.
- **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`.
- **Copy Files**: The `COPY` instructions copy the `package.json` and `package-lock.json` files into the container, followed by the rest of the application code.
- **Install Dependencies**: The `RUN npm install` command installs all dependencies specified in `package.json`.
- **Build the Application**: The `RUN npm run build` command builds the Next.js application for production.
- **Expose Port**: The `EXPOSE` instruction exposes port 3000, which is the default port Next.js uses for server-side rendering.
- **Start the Server**: The `CMD ["npm", "start"]` command runs the Next.js server when the container starts.

### To Build and Run the Docker Container:
1. Save the Dockerfile in a directory with your Next.js application code.
2. Open a terminal in that directory.
3. Build the Docker image using the command:
   ```sh
   docker build -t my-nextjs-app .
   ```
4. Run the Docker container using the command:
   ```sh
   docker run -p 3000:3000 my-nextjs-app
   ```

This will start a Next.js server inside the Docker container, and you can access it at `http://localhost:3000` in your browser.
