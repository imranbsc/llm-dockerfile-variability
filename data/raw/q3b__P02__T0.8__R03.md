Certainly! Below is a Dockerfile for a server-rendered web application built in Node.js using Next.js. This Dockerfile sets up the necessary environment to run the Next.js application.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:16-slim

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of the application code
COPY . .

# Build the application
RUN npm run build

# Expose the port Next.js is serving on
EXPOSE 3000

# Start the application
CMD ["npm", "run", "start"]
```

### Explanation:

1. **Base Image**: The `node:16-slim` image is used as the base image, which is a lightweight version of the Node.js image. The `slim` variant contains only the minimum necessary packages to run Node.js.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory for the commands that follow. This is useful for organizing the files and ensuring that commands are executed in the correct location.

3. **Copying Files**: The `COPY` instructions copy the `package.json` and `package-lock.json` files from the host machine into the container. This ensures that the application has all necessary dependencies installed.

4. **Installing Dependencies**: The `RUN npm install` command installs the dependencies specified in the `package.json` file.

5. **Copying Application Code**: The `COPY . .` command copies the rest of the application code from the host machine into the container.

6. **Building the Application**: The `RUN npm run build` command builds the Next.js application in production mode. This is important for optimizing the application for production use.

7. **Exposing the Port**: The `EXPOSE 3000` command informs Docker that the application is listening on port 3000.

8. **Starting the Application**: The `CMD ["npm", "run", "start"]` command starts the Next.js development server when the container is run.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-next-app .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -p 3000:3000 my-next-app
   ```

This will start the Next.js application on port 3000 on your host machine, accessible at `http://localhost:3000`.
