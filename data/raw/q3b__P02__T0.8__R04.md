```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container at /usr/src/app
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run the application
CMD [ "npm", "run", "dev" ]
```

This Dockerfile is based on the official Node.js 14-alpine image and sets up a development environment for a Next.js application. It copies the `package.json` and `package-lock.json` files to install dependencies, copies the rest of the application code, and configures port 3000 for development. Finally, it runs the development server using `npm run dev`.
