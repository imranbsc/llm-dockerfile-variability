Certainly! Below is a Dockerfile for building and running a server-rendered web application built in Node.js using Next.js. This Dockerfile assumes that you have a basic Next.js application set up and that you want to use Node.js version 14.x for building and running the application.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files from the host machine to the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application source code to the container
COPY . .

# Build the Next.js application
RUN npm run build

# Run the Next.js application
CMD ["node", "./build/server.js"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official Node.js 14 image. This image provides a minimal environment for running Node.js applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`, where the application files will be stored.

3. **Copy Dependencies**: The `COPY` command is used to copy the `package.json` and `package-lock.json` files from the host machine to the container. These files are essential for installing the application dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies specified in the `package.json` file.

5. **Copy Application Source**: Another `COPY` command is used to copy the rest of your application files from the host machine to the container. This includes the source code for Next.js, configuration files, and other necessary files.

6. **Build the Application**: The `RUN npm run build` command builds the Next.js application. This step is crucial as it prepares the application for production.

7. **Run the Application**: The `CMD ["node", "./build/server.js"]` instruction runs the built Next.js application. The `./build/server.js` file is typically generated by the Next.js build process and contains the server logic.

### How to Use the Dockerfile:

1. Ensure you have a Next.js project set up and that the necessary files (like `package.json`, `next.config.js`, etc.) are in the root directory of your project.
2. Build the Docker image using the following command:
   ```sh
   docker build -t my-next-app .
   ```
3. Run the Docker container using the following command:
   ```sh
   docker run -d -p 3000:3000 --name my-next-app my-next-app
   ```
4. Access your application by visiting `http://localhost:3000` in your web browser.

This Dockerfile provides a basic setup for a server-rendered Next.js application. Depending on your specific application needs, you may need to add additional configurations or dependencies.
