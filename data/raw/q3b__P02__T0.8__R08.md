Certainly! Below is a Dockerfile for a server-rendered web application built in Node.js using Next.js. This Dockerfile assumes that you have a Next.js project set up and that you want to build and run it inside a Docker container.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:16-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Build the Next.js application
RUN npm run build

# Serve the Next.js application using the production build
CMD ["npm", "start"]
```

### How to Use the Dockerfile

1. **Ensure You Have a Next.js Project**: Make sure your Next.js project is set up and has a `package.json` file.

2. **Build the Docker Image**: Run the following command in your project directory:

   ```sh
   docker build -t nextjs-app .
   ```

3. **Run the Docker Container**: Once the image is built, you can run it using the following command:

   ```sh
   docker run -d -p 3000:3000 nextjs-app
   ```

4. **Access Your Application**: Open a web browser and navigate to `http://localhost:3000` to see your Next.js application running inside the Docker container.

This Dockerfile uses Node.js version 16 and Alpine Linux, which is lightweight and efficient for running production applications. Make sure to adjust the base image and Node.js version as needed for your specific project requirements.
