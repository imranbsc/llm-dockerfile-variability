```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json files to the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code to the container
COPY . .

# Expose the default port for the application
EXPOSE 3000

# Define environment variable for Redis connection
ENV REDIS_URL=redis://redis:6379

# Command to start the application
CMD ["node", "index.js"]
```

**Explanation**:
- The Dockerfile starts with an official Node.js runtime image as the base image.
- It sets the working directory to `/usr/src/app`.
- It copies the `package.json` and `package-lock.json` files to the container to install dependencies.
- It installs the dependencies using `npm install`.
- It copies the rest of the application code to the container.
- It exposes port 3000, which is the default port for the application.
- It sets an environment variable `REDIS_URL` to point to a Redis server running on the default Redis port 6379.
- Finally, it specifies the command to run the application using `node index.js`.
