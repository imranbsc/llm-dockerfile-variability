Certainly! Below is a Dockerfile for a command-line tool built in Node.js using Commander.js. This Dockerfile assumes you have a Node.js application set up with Commander.js.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run the application
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The `node:14` image is used as the base image, which includes Node.js and npm (Node Package Manager).

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`. This is where your application code will be stored.

3. **Copy Dependencies**: The `COPY package*.json .` command copies the `package.json` and `package-lock.json` files into the container. These files are used by npm to install the project dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` command copies the rest of your application code into the container.

6. **Expose Port**: The `EXPOSE 3000` instruction informs Docker that the application listens on port 3000.

7. **Run Command**: The `CMD ["node", "index.js"]` instruction specifies the command to run when the container starts. In this case, it runs the `index.js` file, which is the entry point of your application.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-command-line-tool .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -p 3000:3000 my-command-line-tool
   ```

This setup will allow you to run your command-line tool in a Docker container, making it easy to deploy and manage.
