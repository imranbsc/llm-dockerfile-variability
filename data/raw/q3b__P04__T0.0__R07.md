Certainly! Below is a Dockerfile for a command-line tool built in Node.js using Commander.js. This Dockerfile assumes you have a Node.js application set up with Commander.js.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NODE_ENV=production

# Run the application
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies that the base image for the container is the official Node.js image version 14. You can choose a different version if needed.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory inside the container to `/usr/src/app`, where your application code will be stored.

3. **Copy Dependencies**: The `COPY package*.json .` line copies the `package.json` and `package-lock.json` files into the container. These files are used to install the application dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` line copies the rest of your application code into the container.

6. **Expose Port**: The `EXPOSE 3000` line makes port 3000 available to the world outside this container. This is where your application will listen for incoming requests.

7. **Environment Variable**: The `ENV NODE_ENV=production` sets the environment variable `NODE_ENV` to `production`, which is useful for configuring your application for production.

8. **Run Command**: The `CMD ["node", "index.js"]` line specifies the command to run when the container starts. This is the entry point of your application.

### Building and Running the Docker Image:

To build the Docker image, navigate to the directory containing the Dockerfile and run:

```sh
docker build -t my-command-line-tool .
```

To run the Docker container, use:

```sh
docker run -p 3000:3000 my-command-line-tool
```

This will start a container and map port 3000 of the container to port 3000 of your host machine.
