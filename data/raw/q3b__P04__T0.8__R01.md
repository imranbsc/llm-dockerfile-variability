Here is a basic Dockerfile for a command-line tool built in Node.js using Commander.js. This Dockerfile assumes you have a Node.js application that uses Commander.js for command-line argument parsing.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code to the working directory
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV PORT 3000

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run the app
CMD ["node", "your-script.js"]
```

Replace `your-script.js` with the entry point of your Node.js application. Make sure to adjust the Node.js version and any other dependencies based on your project's requirements.
