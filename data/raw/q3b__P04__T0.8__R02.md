Certainly! Below is a Dockerfile for a Node.js command-line tool that uses Commander.js. This Dockerfile assumes you have a `package.json` file in your project directory, and it includes commands to install dependencies and build the tool.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install app dependencies
RUN npm install

# Copy the rest of the application code to the working directory
COPY . .

# Expose the port your application runs on
EXPOSE 3000

# Define the command to run the application
CMD ["node", "index.js"]
```

### Explanation:
- **FROM node:14-alpine**: This line specifies the base image to use, which is a lightweight version of Node.js based on Alpine Linux.
- **WORKDIR /usr/src/app**: Sets the working directory for the application within the container.
- **COPY package*.json ./**: Copies the `package.json` and `package-lock.json` files into the working directory.
- **RUN npm install**: Installs the project dependencies.
- **COPY . .**: Copies the rest of the application code into the working directory.
- **EXPOSE 3000**: Exposes port 3000, which is the default port for many Node.js applications.
- **CMD ["node", "index.js"]**: Specifies the command to run the application when the container starts.

### Steps to Build and Run the Docker Image:
1. Navigate to your project directory.
2. Build the Docker image using the following command:
   ```bash
   docker build -t my-command-line-tool .
   ```
3. Run the Docker container using the following command:
   ```bash
   docker run -p 3000:3000 --name my-running-tool my-command-line-tool
   ```

This Dockerfile is a basic setup and can be expanded with additional layers as needed.
