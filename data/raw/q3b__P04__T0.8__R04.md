```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code into the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Run the command to start the application
CMD ["node", "your-command-line-tool.js"]
```

Replace `"your-command-line-tool.js"` with the actual entry point of your command-line tool. This Dockerfile sets up a basic Node.js environment with Commander.js installed and your application code, exposing port 3000 for the application to listen on.
