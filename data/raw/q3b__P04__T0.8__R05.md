Certainly! Below is a Dockerfile for building a command-line tool in Node.js using Commander.js. This Dockerfile sets up a base Node.js image, installs necessary dependencies, and copies your code into the container.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:16-slim

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code into the container
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NODE_ENV=production

# Run the app
CMD ["node", "your-main-file.js"]
```

### Explanation:

- **Base Image**: The `node:16-slim` image is used as the base image, which is a minimal Node.js image. It is smaller and faster to use compared to a full image.
  
- **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory for the rest of the commands in the Dockerfile.

- **Package Files**: The `COPY package*.json ./` command copies the `package.json` and `package-lock.json` files into the container. These files are used by npm to install dependencies.

- **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

- **Copy Application Code**: The `COPY . .` command copies the entire application codebase into the container.

- **Expose Port**: The `EXPOSE 3000` command exposes port 3000, which is typically used by the application.

- **Environment Variable**: The `ENV NODE_ENV=production` sets the environment variable `NODE_ENV` to `production`, which is useful for configuring the application accordingly.

- **Command**: The `CMD ["node", "your-main-file.js"]` command specifies the command to run when the container starts. Replace `your-main-file.js` with the name of your main JavaScript file.

### Building the Docker Image

To build the Docker image, navigate to the directory containing your Dockerfile and run:

```sh
docker build -t your-image-name .
```

### Running the Docker Container

To run the Docker container, use:

```sh
docker run -p 3000:3000 -d your-image-name
```

This will start a container with your application running on port 3000, accessible from the host machine.
