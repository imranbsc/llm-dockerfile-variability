Certainly! Below is a Dockerfile for a simple command-line tool built in Node.js using Commander.js. This Dockerfile assumes you have a Node.js application set up with Commander.js.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-slim

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Expose the port your application runs on
EXPOSE 3000

# Define environment variables (if any)
ENV NODE_ENV=production

# Command to run the application
CMD ["node", "app.js"]
```

### Explanation:
- **Base Image**: `node:14-slim` - A lightweight version of the official Node.js image.
- **Working Directory**: `/usr/src/app` - The directory where your application files will be stored.
- **Copying Files**: `COPY package*.json ./` and `COPY . .` - Copies the `package.json` and `package-lock.json` to the container and the rest of your application files to the same directory.
- **Installing Dependencies**: `RUN npm install` - Installs all dependencies specified in `package.json`.
- **Exposing Port**: `EXPOSE 3000` - Makes port 3000 available to the container.
- **Environment Variable**: `ENV NODE_ENV=production` - Sets the environment variable `NODE_ENV` to `production` to optimize your application for production.
- **Command**: `CMD ["node", "app.js"]` - Specifies the command to run the application, assuming it is named `app.js`.

### How to Use:
1. Ensure you have a `package.json` file in the root of your project with the necessary dependencies.
2. Replace `app.js` with the entry point of your application.
3. Build the Docker image:
   ```bash
   docker build -t your-image-name .
   ```
4. Run the Docker container:
   ```bash
   docker run -p 3000:3000 your-image-name
   ```
