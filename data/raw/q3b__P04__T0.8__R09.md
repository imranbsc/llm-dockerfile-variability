Certainly! Below is a simple Dockerfile for a command-line tool built in Node.js using Commander.js. This Dockerfile assumes you have a Node.js application with Commander.js installed.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the working directory
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code to the working directory
COPY . .

# Expose the default port your application listens on
EXPOSE 3000

# Make port 3000 available to the world outside this container
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the `node:14` image, which is a lightweight Node.js image based on Debian. This is a good choice for development environments.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`. This is where your application will be stored and executed.

3. **Copy Dependencies**: The `COPY package*.json .` command copies the `package.json` and `package-lock.json` files into the working directory. These files contain the dependencies and their versions for your application.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` command copies the entire contents of your application into the working directory.

6. **Expose Port**: The `EXPOSE 3000` instruction informs Docker that the application is listening on port 3000, which is the default port for most web applications.

7. **CMD Command**: The `CMD ["node", "index.js"]` instruction specifies the command to run when the container starts. Replace `index.js` with the entry point of your application if it's different.

### How to Build and Run the Docker Image

1. **Build the Docker Image**:
   ```bash
   docker build -t my-command-line-tool .
   ```

2. **Run the Docker Container**:
   ```bash
   docker run -p 3000:3000 my-command-line-tool
   ```

This will start a container from the built image, mapping port 3000 on the host to port 3000 in the container, so you can access your application using `http://localhost:3000`.
