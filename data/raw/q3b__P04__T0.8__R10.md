Certainly! Below is a Dockerfile for a command-line tool built in Node.js using Commander.js. This Dockerfile assumes that you have a `package.json` file in your project directory with the necessary dependencies.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your project files to the working directory
COPY . .

# Expose the default port your application uses
EXPOSE 3000

# Make port 3000 available to the world outside this container
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies that the container should use the Node.js version 14 image as the base image. You can choose a different version if needed.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory inside the container to `/usr/src/app`.

3. **Copy Dependencies**: The `COPY package*.json ./` command copies the `package.json` and `package-lock.json` files into the container. These files are used by npm to install the project dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Project Files**: The `COPY . .` command copies all the files from your local project directory into the container, including the `index.js` file (which is the entry point of your application).

6. **Expose Port**: The `EXPOSE 3000` line informs Docker that the application listens on port 3000.

7. **Command to Run**: The `CMD ["node", "index.js"]` line specifies the command to run when the container starts. This command tells Node.js to run the `index.js` file, assuming it is the entry point of your application.

Make sure to replace `index.js` with the actual entry point of your application if it is different. Also, ensure that your `package.json` file includes the necessary dependencies for Commander.js and any other packages your application uses.
