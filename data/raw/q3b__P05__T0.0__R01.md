Certainly! Below is a Dockerfile for a scheduled batch job built in Node.js using `node-cron`. This Dockerfile assumes you have a Node.js application that uses `node-cron` to schedule tasks.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Expose the port your application runs on
EXPOSE 3000

# Define environment variables
ENV NODE_ENV=production

# Start the application
CMD ["node", "index.js"]
```

### Explanation:

1. **Base Image**: The `node:14` image is used as the base image, which includes Node.js and npm.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory for the application inside the container.

3. **Copy Dependencies**: The `COPY package*.json .` command copies the `package.json` and `package-lock.json` files into the container. These files are used to install the application dependencies.

4. **Install Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Copy Application Code**: The `COPY . .` command copies the rest of your application code into the container.

6. **Expose Port**: The `EXPOSE 3000` instruction informs Docker that the application listens on port 3000.

7. **Environment Variable**: The `ENV NODE_ENV=production` sets the environment variable `NODE_ENV` to `production`, which is useful for configuring your application for production.

8. **Start Command**: The `CMD ["node", "index.js"]` command specifies the command to run when the container starts, which is to execute the `index.js` file.

### Note:
- Ensure that your `index.js` file is correctly set up to use `node-cron` for scheduling tasks.
- You may need to adjust the `COPY` commands and paths based on your specific application structure.
