Here's a basic Dockerfile for a scheduled batch job built in Node.js using `node-cron`. This Dockerfile sets up a Node.js environment, installs `node-cron`, and includes a sample script to demonstrate how to schedule a job.

```Dockerfile
# Use the official Node.js image as the base image
FROM node:14-slim

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of the application files to the container
COPY . .

# Define the command to run the application
CMD ["node", "cronJob.js"]

# Define a cron job to run every minute
ENTRYPOINT ["cron", "* * * * *", "node", "cronJob.js"]
```

### Explanation:

- **Base Image**: The `node:14-slim` image is used, which is a lightweight version of the Node.js image that includes only necessary dependencies.
- **Working Directory**: The working directory is set to `/usr/src/app` to keep the source code organized.
- **Dependencies**: The `COPY` commands are used to copy the `package.json` and `package-lock.json` files into the container, and `npm install` installs the dependencies.
- **Application Files**: The rest of the application files are copied into the container.
- **CMD**: The `CMD` instruction defines the default command to run when the container starts, which is to execute the `cronJob.js` file.
- **ENTRYPOINT**: The `ENTRYPOINT` instruction is used to define a cron job that runs every minute. The cron job is specified as `cron * * * * * node cronJob.js`, which means it will run at every minute of every hour.

### Note:
- Replace `cronJob.js` with the actual script that defines your scheduled job.
- Ensure that the script is executable (`chmod +x cronJob.js`) before building the Docker image.

To build the Docker image, you can use the following command:

```sh
docker build -t scheduled-batch-job .
```

This will create a Docker image named `scheduled-batch-job` based on the provided Dockerfile. You can then run the container using:

```sh
docker run scheduled-batch-job
```
