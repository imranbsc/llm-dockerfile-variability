Certainly! Below is a Dockerfile for a scheduled batch job built in Node.js using `node-cron`. This Dockerfile assumes you have a Node.js application that uses `node-cron` for scheduling tasks.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code
COPY . .

# Expose the port your application listens on
EXPOSE 3000

# Define environment variables (if any)
ENV NODE_ENV=production

# Define the command to run your application
CMD ["node", "index.js"]
```

### Explanation:
- **Base Image**: `node:14` is used as the base image, which includes the latest Node.js version.
- **Working Directory**: `/usr/src/app` is the directory where your application files will be placed.
- **Dependencies**: The `COPY package*.json .` command copies the `package.json` and `package-lock.json` files into the container. The `RUN npm install` command installs all the dependencies listed in `package.json`.
- **Application Files**: The rest of your application code is copied into the container.
- **Port Exposition**: `EXPOSE 3000` specifies that the application listens on port 3000.
- **Environment Variable**: `NODE_ENV=production` sets the environment variable for production.
- **Command to Run**: `CMD ["node", "index.js"]` specifies the command to run your Node.js application.

### Note:
- Make sure you have a `package.json` file in the root of your project with a `scripts` section that includes a script for starting your application, e.g., `"start": "node index.js"`.
- The `index.js` file should be in the root of your project and should use `node-cron` to schedule tasks.

To build and run this Docker image, use the following commands:

```bash
# Build the Docker image
docker build -t my-node-app .

# Run the Docker container
docker run -d --name my-node-app my-node-app
```

This setup will allow you to run your Node.js application with `node-cron` for scheduling tasks in a Docker container.
