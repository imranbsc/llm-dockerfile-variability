Certainly! Below is a Dockerfile for a scheduled batch job built in Node.js using node-cron. This Dockerfile sets up a basic environment to run a Node.js application that uses node-cron to schedule tasks.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json files to the working directory
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of your application code into the container
COPY . .

# Install any needed packages specified in package.json
RUN npm install

# Expose the default port your application runs on
EXPOSE 3000

# Define environment variables if needed
ENV NODE_ENV=production

# Start the application using the command specified in package.json
CMD ["node", "app.js"]
```

### Explanation:

1. **Base Image**: The `FROM node:14` line specifies the base image to use, which is a Node.js image based on Node.js version 14. You can choose a different version if needed.

2. **Working Directory**: The `WORKDIR /usr/src/app` sets the working directory inside the container where your application will be built and run.

3. **Copying Dependencies**: 
   - `COPY package*.json ./` copies the `package.json` and `package-lock.json` files into the container.
   - `RUN npm install` installs all the dependencies specified in these files.

4. **Copying Application Code**: 
   - `COPY . .` copies the rest of your application code into the container.

5. **Starting the Application**: 
   - `CMD ["node", "app.js"]` specifies the command to run your application. Make sure `app.js` is the entry point of your Node.js application.

### Running the Docker Container

To run the Docker container, you can use the following commands:

```sh
# Build the Docker image
docker build -t my-scheduled-job .

# Run the Docker container
docker run -d --name my-scheduled-job-container -p 3000:3000 my-scheduled-job
```

This setup assumes that `app.js` is your main entry point for your Node.js application. Make sure to adjust the `app.js` path if it's different in your project.
