```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of the application code
COPY . .

# Install node-cron
RUN npm install node-cron

# Define environment variable for CRON schedule
ENV CRON_SCHEDULE="0 0 * * *" # Example: Every day at midnight

# Define the command to run the scheduled batch job
CMD ["node", "index.js"] # Replace "index.js" with your script's name
```

This Dockerfile sets up a basic Node.js environment with the `node-cron` package installed. The `CRON_SCHEDULE` environment variable is set to a default schedule that runs every day at midnight, but you can modify it as needed. The `CMD` directive specifies the command to run your batch job, which should be a JavaScript file in your application. Adjust the `COPY` statements as necessary to include your specific application files and dependencies.
