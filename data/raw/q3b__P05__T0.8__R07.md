Certainly! Below is a Dockerfile for a scheduled batch job built in Node.js using the `node-cron` package.

```Dockerfile
# Use the official Node.js runtime as a parent image
FROM node:16-slim

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files from the host to the container
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Copy the rest of the application code from the host to the container
COPY . .

# Expose the port the application will run on
EXPOSE 3000

# Set the default command to run when the container starts
CMD ["node", "index.js"]

# Add a cron job to run every minute
RUN echo "* * * * * node /usr/src/app/index.js" > /etc/crontabs/root

# Schedule the cron job to run
RUN crontab /etc/crontabs/root
```

### Explanation:

1. **Base Image**: The `node:16-slim` image is used as the base image for the Docker container. This image is based on Debian and is optimized for size.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/usr/src/app`.

3. **Copying Files**: The `COPY` commands are used to copy the `package*.json` files and the rest of the application code from the host machine to the container.

4. **Installing Dependencies**: The `RUN npm install` command installs all the dependencies listed in `package.json`.

5. **Exposing Port**: The `EXPOSE` instruction specifies that the container should listen on port 3000.

6. **Setting Default Command**: The `CMD` instruction sets the default command that runs when the container starts. In this case, it runs `node index.js`.

7. **Cron Job**: The cron job `* * * * * node /usr/src/app/index.js` is added to the crontab file to run the script every minute. The `crontab` command is used to set this cron job.

This Dockerfile can be used to build and run a Node.js application with a scheduled batch job that runs every minute.
