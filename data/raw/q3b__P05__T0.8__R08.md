Certainly! Below is a Dockerfile for a Node.js application that uses `node-cron` to schedule a batch job. This example assumes you have a basic Node.js application set up.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json to the container at /usr/src/app
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code to the container
COPY . .

# Expose the default port for your application
EXPOSE 3000

# Define environment variables
ENV NODE_ENV=production

# Define a command to run your application
CMD ["node", "index.js"]

# Define a job to run periodically using node-cron
SHELL ["crontab", "-l"]
RUN (echo "0 0 * * *" && # Run this job at midnight every day
     echo "*/5 * * * *" && # Run this job every 5 minutes
     echo "*/10 * * * *") | # Run this job every 10 minutes
RUN crontab -

# Define a startup script to start node-cron
ENTRYPOINT ["node-cron", "start"]
```

### Explanation:
- **Base Image**: The Dockerfile starts with an official Node.js 14 image.
- **Working Directory**: The working directory is set to `/usr/src/app`.
- **Dependencies**: The `package.json` and `package-lock.json` are copied to the container and installed using `npm install`.
- **Copy Application**: The rest of the application code is copied into the container.
- **Port Exposition**: The container listens on port 3000.
- **Environment**: The environment variable `NODE_ENV` is set to `production`.
- **Node Application**: The default command to run is `node index.js`.
- **Cron Jobs**: The `node-cron` library is used to schedule tasks. The `crontab` command is used to define a job to run at midnight every day, every 5 minutes, and every 10 minutes.
- **Startup Script**: The `ENTRYPOINT` is set to `node-cron start`, which starts the cron scheduler to execute the scheduled tasks.

### How to Use:
1. Build the Docker image:
   ```sh
   docker build -t my-node-app .
   ```
2. Run the Docker container:
   ```sh
   docker run -d --name my-node-app -p 3000:3000 my-node-app
   ```

This setup allows your Node.js application to run with scheduled batch jobs using `node-cron`. Adjust the cron expressions in the `crontab` command to fit your specific needs.
