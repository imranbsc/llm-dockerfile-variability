Certainly! Below is a simple Dockerfile for a scheduled batch job built in Node.js using `node-cron`. This Dockerfile assumes you have a Node.js project set up and that you want to run a cron job in it.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . /usr/src/app

# Install any needed packages specified in package.json
RUN npm install

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NODE_ENV=production

# Run app.js when the container launches
CMD ["node", "app.js"]

# Schedule a cron job to run every minute
SCHEDULE="@every 1 minute"
CRONJOB="* * * * * node /usr/src/app/app.js"
```

### Explanation:
- **FROM node:14**: This line specifies the base image for the Docker container, using Node.js version 14.
- **WORKDIR /usr/src/app**: Sets the working directory in the container to `/usr/src/app`.
- **COPY . /usr/src/app**: Copies the contents of the current directory to the container at `/usr/src/app`.
- **RUN npm install**: Installs all dependencies listed in `package.json`.
- **EXPOSE 3000**: Makes port 3000 available to the world outside the container.
- **ENV NODE_ENV=production**: Sets the environment variable `NODE_ENV` to `production`.
- **CMD ["node", "app.js"]**: Specifies the command to run the application, which is `node app.js`.
- **SCHEDULE="@every 1 minute"**: Schedules the cron job to run every minute. You can change this to any valid cron expression as per your requirements.

To use this Dockerfile, save it in the root of your Node.js project directory, and then build and run your Docker container using:

```sh
docker build -t my-scheduled-batch-job .
docker run -d --name my-scheduled-container my-scheduled-batch-job
```

This will build a Docker image named `my-scheduled-batch-job` and run a container from it. The container will run the Node.js application and the cron job as specified in the Dockerfile.
