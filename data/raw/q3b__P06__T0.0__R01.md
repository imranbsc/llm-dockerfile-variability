Certainly! Below is a simple Dockerfile for a REST API built in Python using Flask. This Dockerfile assumes you have a basic Flask application set up in a directory named `app`.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:

1. **Base Image**: The `FROM python:3.9-slim` line specifies the base image to use. `python:3.9-slim` is a lightweight version of the Python 3.9 image, which is ideal for production environments.

2. **Working Directory**: The `WORKDIR /app` sets the working directory inside the container to `/app`. This is where your application files will be located.

3. **Copy Files**: The `COPY . /app` line copies all files from the current directory (where the Dockerfile is located) to the `/app` directory inside the container.

4. **Install Dependencies**: The `RUN pip install --no-cache-dir -r requirements.txt` line installs the Python dependencies listed in the `requirements.txt` file. The `--no-cache-dir` flag ensures that the cache is not used, which can help in reproducibility.

5. **Expose Port**: The `EXPOSE 5000` line tells Docker that the application listens on port 5000, which is the default port for Flask applications.

6. **Environment Variable**: The `ENV NAME World` line sets an environment variable named `NAME` with the value `World`. This can be accessed within your application.

7. **Command to Run**: The `CMD ["python", "app.py"]` line specifies the command to run when the container starts. This is the entry point for your application.

### Next Steps:

- Ensure you have a `requirements.txt` file in your project directory listing all the Python packages your application depends on.
- Create a `app.py` file in your project directory with your Flask application code.
- Build the Docker image using the command `docker build -t my-flask-app .`.
- Run the container using `docker run -p 5000:5000 my-flask-app`.
