Certainly! Below is a simple Dockerfile for a REST API built in Python using Flask. This Dockerfile assumes you have a basic Flask application set up in a directory named `app`.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:

1. **Base Image**: The `python:3.9-slim` image is used as the base image, which is a lightweight version of Python 3.9.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`.

3. **Copy Files**: The `COPY` instruction copies all files from the current directory to the `/app` directory inside the container.

4. **Install Dependencies**: The `RUN` instruction installs the dependencies listed in `requirements.txt` using `pip`. The `--no-cache-dir` flag is used to avoid caching dependencies, which can be useful for development.

5. **Expose Port**: The `EXPOSE` instruction informs Docker that the application listens on port 5000.

6. **Command to Run**: The `CMD` instruction specifies the command to run when the container starts, which is `python app.py`.

### Next Steps:

- Ensure you have a `requirements.txt` file in your project directory listing all the Python packages your application depends on.
- Create a `app.py` file in your project directory with your Flask application code.
- Build the Docker image using `docker build -t my-flask-app .`.
- Run the container using `docker run -p 5000:5000 my-flask-app`.
