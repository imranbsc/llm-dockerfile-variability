Here is a Dockerfile for a simple REST API built in Python using Flask. This Dockerfile will install the necessary dependencies and create an entrypoint to run the Flask application.

```dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

Please note that this Dockerfile assumes you have a `requirements.txt` file in your project directory that lists the Python dependencies your Flask application needs. Also, ensure that `app.py` is your main Flask application file.
