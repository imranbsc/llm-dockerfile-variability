Certainly! Below is a simple Dockerfile for a REST API built in Python using Flask. This Dockerfile assumes you have a Flask application with a `main.py` file.

```dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run app.py when the container launches
CMD ["python", "main.py"]
```

### Explanation:

1. **Base Image**: The `python:3.8-slim` image is used as the base image, which is a lightweight version of the Python 3.8 runtime. This is efficient for environments where memory usage is a concern.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory in the container to `/app`, which is where your application files will be located.

3. **Copy Files**: The `COPY . /app` command copies all files from the current directory to the `/app` directory in the container. This includes your `requirements.txt` file and any other necessary files.

4. **Install Dependencies**: The `RUN pip install --no-cache-dir -r requirements.txt` command installs all the Python dependencies listed in your `requirements.txt` file. The `--no-cache-dir` option ensures that the installation process is faster by not caching previous installs.

5. **Expose Port**: The `EXPOSE 5000` command informs Docker that the application will listen on port 5000, which is the default port for Flask.

6. **Run Command**: The `CMD ["python", "main.py"]` command specifies that the container should run the `main.py` file when it starts.

### Additional Steps:

- Ensure you have a `requirements.txt` file in your project root that lists all the Python packages your application depends on.
- Replace `main.py` with the name of your main Flask application file.
- If you have any additional configuration or setup steps, you can add them after the `CMD` line.

This Dockerfile should help you containerize your Flask application and make it easy to run and deploy.
