Certainly! Below is a simple Dockerfile to create a Docker image for a REST API built in Python using Flask.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:
- **FROM**: Uses the Python 3.8-slim image as the base image.
- **WORKDIR**: Sets the working directory in the container to `/app`.
- **COPY**: Copies the contents of the current directory to the `/app` directory in the container.
- **RUN**: Installs the necessary packages from `requirements.txt` in the container.
- **EXPOSE**: Specifies that port 5000 is exposed to the world outside this container.
- **CMD**: Specifies the command to run when the container starts, which is to run `python app.py`.

### Additional Considerations:
1. **requirements.txt**: Ensure you have a `requirements.txt` file in your project directory that lists all the Python packages your application depends on.
2. **app.py**: Ensure your Flask application is set up to run on port 5000.

To build and run this Docker image, you would typically follow these steps:

1. Ensure you have Docker installed on your machine.
2. Navigate to your project directory in the terminal.
3. Build the Docker image using the command:
   ```sh
   docker build -t my-flask-app .
   ```
4. Run the Docker container using the command:
   ```sh
   docker run -p 5000:5000 my-flask-app
   ```

This will start a container and make your Flask application accessible at `http://localhost:5000`.
