Certainly! Below is a simple Dockerfile to create a Docker image for a REST API built in Python using Flask.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:
- **FROM**: Uses the Python 3.8-slim image as the base image. The `slim` version is smaller than the full image and is recommended for production use.
- **WORKDIR**: Sets the working directory inside the container to `/app`.
- **COPY**: Copies the current directory contents into the container at `/app`.
- **RUN**: Installs any packages listed in `requirements.txt` using `pip`. The `--no-cache-dir` option avoids using cached dependencies, which is useful for development.
- **EXPOSE**: Declares that port 5000 is exposed to the outside world.
- **CMD**: Specifies the command to run when the container starts, which is running the `app.py` script.

Make sure to have a `requirements.txt` file in your project directory, which lists all the Python packages your application needs.
