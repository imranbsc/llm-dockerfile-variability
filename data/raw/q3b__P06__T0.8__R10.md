Certainly! Below is a simple Dockerfile for a REST API built in Python using Flask. This Dockerfile includes instructions to build a Docker image and run a container.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:
- **FROM**: Specifies the base image to use, in this case, a Python 3.9 slim image.
- **WORKDIR**: Sets the working directory inside the container.
- **COPY**: Copies the current directory contents into the container at `/app`.
- **RUN**: Installs the Python dependencies listed in `requirements.txt`.
- **EXPOSE**: Declares that the container listens on port 5000.
- **CMD**: Specifies the default command to run when the container starts, which is the Python script `app.py`.

### Next Steps:
1. **Create a `requirements.txt` file** to list all the Python packages your application needs.
2. **Create a `app.py` file** with your Flask application code.
3. **Build the Docker image** by running `docker build -t my-flask-app .` in your project directory.
4. **Run the Docker container** by executing `docker run -p 5000:5000 my-flask-app`.

This setup provides a basic structure for a Flask application running in a Docker container. You can further customize the Dockerfile and application code as needed for your specific project.
