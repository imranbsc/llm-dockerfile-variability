Certainly! Below is a Dockerfile for a server-rendered web application built in Python using Django. This Dockerfile sets up a development environment for running a Django project.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Install any needed packages specified in requirements.txt
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy the current directory contents into the container at /app
COPY . .

# Make port 8000 available to the world outside this container
EXPOSE 8000

# Define environment variable
ENV DJANGO_SETTINGS_MODULE config.settings

# Run the application
CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]
```

### Explanation:
- **FROM python:3.9-slim**: This line specifies the base image for the Docker container. `python:3.9-slim` is a lightweight version of the Python 3.9 image.
- **WORKDIR /app**: This sets the working directory in the container where the application will be stored.
- **COPY requirements.txt .**: Copies the `requirements.txt` file into the container and installs all dependencies listed in it using `pip`.
- **COPY . .**: Copies the rest of the application code into the container.
- **EXPOSE 8000**: This tells Docker that the container will listen on port 8000.
- **ENV DJANGO_SETTINGS_MODULE config.settings**: This sets the environment variable for Django to use the correct settings module.
- **CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]**: This command runs the Django development server.

### Prerequisites:
- You should have a `requirements.txt` file in your Django project directory listing all the Python packages needed.
- Ensure you have a Django project structure with a `config/settings.py` file that Django can use to configure the settings.

### Building the Docker Image:
To build the Docker image, navigate to the directory containing your Dockerfile and run the following command:

```sh
docker build -t my-django-app .
```

This will create a Docker image named `my-django-app`.

### Running the Docker Container:
To run the Docker container, use the following command:

```sh
docker run -d -p 8000:8000 my-django-app
```

This command will start a container from the `my-django-app` image, mapping port 8000 on the host to port 8000 in the container.
