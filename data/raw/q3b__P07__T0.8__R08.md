Certainly! Below is a basic Dockerfile for a server-rendered web application built in Python using Django. This Dockerfile assumes you are using Python 3.8 and Django 3.2.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Install any needed packages specified in requirements.txt
COPY requirements.txt /app/
RUN pip install --no-cache-dir -r requirements.txt

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8000 available to the world outside this container
EXPOSE 8000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]
```

### Explanation:

1. **Base Image**: 
   - `FROM python:3.8-slim`: This uses the official Python 3.8 slim image, which is a lightweight version of the base Python image.

2. **Working Directory**:
   - `WORKDIR /app`: Sets the working directory inside the container to `/app`.

3. **Install Dependencies**:
   - `COPY requirements.txt /app/`: Copies the `requirements.txt` file into the `/app` directory inside the container.
   - `RUN pip install --no-cache-dir -r requirements.txt`: Installs the Python dependencies listed in `requirements.txt` without caching them, which can help keep the image size smaller.

4. **Copy Application Code**:
   - `COPY . /app`: Copies the current directory (your Django project) into the `/app` directory inside the container.

5. **Expose Port**:
   - `EXPOSE 8000`: Makes port 8000 available to the world outside this container. This is necessary for the Django development server to listen on this port.

6. **Set Environment Variable**:
   - `ENV NAME World`: Sets an environment variable `NAME` to `World`. This can be accessed within your Django application as `os.getenv('NAME')`.

7. **Run Command**:
   - `CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]`: Specifies the command to run when the container starts, which is to run the Django development server on all network interfaces (`0.0.0.0`) at port 8000.
