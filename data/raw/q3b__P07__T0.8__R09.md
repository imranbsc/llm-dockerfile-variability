Certainly! Below is a simple Dockerfile for a server-rendered web application built in Python using Django. This Dockerfile assumes you have a Django project set up with a `requirements.txt` file and a `manage.py` file.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the requirements file into the container
COPY requirements.txt /app/

# Install dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Copy the rest of the project into the container
COPY . /app

# Expose the port the Django app is running on
EXPOSE 8000

# Command to run the Django development server
CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]
```

### Explanation:
- **FROM python:3.9-slim**: This line specifies the base image to use. The `slim` variant is used to reduce the size of the image.
- **WORKDIR /app**: This sets the working directory inside the container where the application files will be stored.
- **COPY requirements.txt /app/**: This copies the `requirements.txt` file into the `/app` directory in the container.
- **RUN pip install --no-cache-dir -r requirements.txt**: This installs the Python dependencies listed in `requirements.txt`.
- **COPY . /app**: This copies all the files from the local directory into the `/app` directory in the container.
- **EXPOSE 8000**: This tells Docker that the container should listen on port 8000 for incoming connections.
- **CMD ["python", "manage.py", "runserver", "0.0.0.0:8000"]**: This sets the default command to run when the container starts, which is the Django development server on port 8000.

### Building and Running the Docker Container:
To build the Docker image, run the following command in the directory containing your `Dockerfile`:

```bash
docker build -t my-django-app .
```

To run the container and expose the Django development server, use:

```bash
docker run -p 8000:8000 my-django-app
```

This will start the Django development server on `http://localhost:8000` inside the container.
