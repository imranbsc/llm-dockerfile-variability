Certainly! Below is a Dockerfile for a server-rendered web application built in Python using Django. This Dockerfile assumes you have a Django project structure and dependencies set up.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "manage.py", "runserver", "0.0.0.0:80"]
```

### Explanation:

- **FROM python:3.9-slim**: This line specifies the base image for the container, using Python 3.9 with a slim version to reduce image size.
- **WORKDIR /app**: Sets the working directory inside the container to `/app`, where your Django project will be located.
- **COPY . /app**: Copies the current directory contents into the container at `/app`.
- **RUN pip install --no-cache-dir -r requirements.txt**: Installs the Python dependencies listed in `requirements.txt`. The `--no-cache-dir` flag ensures that the pip cache is not used during installation, which can help in managing dependencies more effectively.
- **EXPOSE 80**: Makes port 80 available to the world outside this container.
- **ENV NAME World**: Sets an environment variable named `NAME` to `World`. This can be used in your Django application to customize behavior.
- **CMD ["python", "manage.py", "runserver", "0.0.0.0:80"]**: Specifies the default command to run when the container starts, which is to run the Django development server on all network interfaces at port 80.

### Usage:

1. Save this Dockerfile in the root of your Django project.
2. Create a `requirements.txt` file with your Django and other project dependencies.
3. Build the Docker image by running `docker build -t my-django-app .` in your project directory.
4. Run the container with `docker run -p 8000:80 my-django-app`.

This setup is a basic development environment and should be adjusted according to your production needs, such as using a different base image, setting up environment variables for database configuration, or using a volume for persistent storage.
