Certainly! Below is a Dockerfile for a background worker built in Python using Celery. This Dockerfile assumes you have a basic understanding of Docker and Celery.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5672 available to the world outside this container
EXPOSE 5672

# Define environment variable
ENV CELERY_BROKER_URL=redis://redis:6379/0

# Run celery worker
CMD ["celery", "worker", "--loglevel=info", "--broker=redis://redis:6379/0"]
```

### Explanation:

1. **Base Image**: The `python:3.9-slim` image is used as the base image, which is a lightweight version of Python 3.9.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`.

3. **Copy Files**: The `COPY` instruction copies the current directory contents into the container at `/app`.

4. **Install Dependencies**: The `RUN` instruction installs the dependencies listed in `requirements.txt` using `pip`. The `--no-cache-dir` flag is used to avoid caching dependencies, which can be useful for development.

5. **Expose Port**: The `EXPOSE` instruction makes port 5672 available to the world outside this container. This is the default port for RabbitMQ, which is used as the broker for Celery.

6. **Environment Variable**: The `ENV` instruction sets the `CELERY_BROKER_URL` environment variable to the Redis broker URL. This is where Celery will connect to for task execution.

7. **Command**: The `CMD` instruction runs the Celery worker with the specified log level and broker URL.

### Notes:

- Ensure you have a `requirements.txt` file in your project directory that lists all the Python packages your application depends on.
- You will need a Redis server running to connect to for Celery. You can run a Redis container using Docker if needed.
- This Dockerfile assumes you have a Redis container named `redis` running on the default port 6379. Adjust the `CELERY_BROKER_URL` if your Redis setup is different.
