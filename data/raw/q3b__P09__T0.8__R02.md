Certainly! Below is a simple Dockerfile for a Python command-line tool built using Click. This example assumes you have a Python script named `main.py` that uses Click for defining command-line arguments.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "main.py"]
```

### Explanation:

- **Base Image**: The `python:3.8-slim` image is used as the base image. It is a lightweight version of Python that only includes the necessary components.
- **Working Directory**: The `WORKDIR /app` command sets the working directory inside the container to `/app`, which is where your application files will be placed.
- **Copy Files**: The `COPY . /app` command copies all the files from the current directory to the `/app` directory inside the container.
- **Install Dependencies**: The `RUN pip install --no-cache-dir -r requirements.txt` command installs the dependencies listed in `requirements.txt`. The `--no-cache-dir` option prevents caching of the `pip` installation to save space.
- **Expose Port**: The `EXPOSE 80` command makes port 80 available to the outside world.
- **Set Environment Variable**: The `ENV NAME World` command sets the environment variable `NAME` to `World`.
- **Run Command**: The `CMD ["python", "main.py"]` command specifies the command to run when the container starts, which is to execute `main.py` with Python.

### Additional Steps:

1. **Create `requirements.txt`**: This file should list all the Python packages you need, e.g., `Click` and `Flask` if your application uses them.
2. **Create `main.py`**: This is the entry point of your command-line tool, where you define your commands using Click.

Make sure to replace `main.py` and `requirements.txt` with your actual application files and dependencies.
