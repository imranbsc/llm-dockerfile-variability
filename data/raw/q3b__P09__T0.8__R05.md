Certainly! Below is a simple Dockerfile that builds a Python command-line tool using Click, which is a popular library for building command line interfaces in Python.

```Dockerfile
# Use the official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:

- **FROM python:3.8-slim**: This line specifies the base image to use. The `python:3.8-slim` image is a lightweight version of the official Python image that includes only the necessary dependencies.

- **WORKDIR /app**: This sets the working directory inside the container to `/app`. This is where your application files will be stored.

- **COPY . /app**: This copies the contents of the current directory (assuming this is your local directory) into the `/app` directory inside the container.

- **RUN pip install --no-cache-dir -r requirements.txt**: This installs the required Python packages listed in the `requirements.txt` file. The `--no-cache-dir` flag prevents the installation of packages from the cache, which can be useful for development purposes.

- **EXPOSE 5000**: This exposes port 5000 on the container, allowing it to be accessed from outside the container.

- **ENV NAME World**: This sets an environment variable named `NAME` with the value `World`. You can change this value in your environment or in `app.py` to customize the greeting.

- **CMD ["python", "app.py"]**: This specifies the command to run when the container starts. In this case, it runs the `app.py` script.

### Additional Steps:

1. **Create a `requirements.txt` file** in the root of your project to list all the Python dependencies your application needs.

2. **Create your `app.py` script** with the logic for your command-line tool. For example:

   ```python
   import click

   @click.command()
   @click.option('--name', prompt='Your name', default='World')
   def hello(name):
       click.echo(f'Hello, {name}!')

   if __name__ == '__main__':
       hello()
   ```

3. **Build the Docker image** using the following command:

   ```sh
   docker build -t my-python-tool .
   ```

4. **Run the Docker container**:

   ```sh
   docker run -it my-python-tool
   ```

This setup provides a basic framework for a Python command-line tool built with Click, using Docker for containerization.
