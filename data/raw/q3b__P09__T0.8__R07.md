Certainly! Below is a simple Dockerfile for a Python command-line tool built using Click, which is a popular library for building command-line interfaces.

```Dockerfile
# Use the official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:

1. **Base Image**: The `python:3.9-slim` image is used as the base image. It is a lightweight version of the standard Python image, which is suitable for production environments.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`. This is where the code will be copied and executed.

3. **Copy Code**: The `COPY` instruction copies all files and directories from the current directory to the `/app` directory inside the container.

4. **Install Dependencies**: The `RUN pip install --no-cache-dir -r requirements.txt` command installs all dependencies listed in the `requirements.txt` file. The `--no-cache-dir` flag avoids using cached dependencies to ensure the latest versions are installed.

5. **Expose Port**: The `EXPOSE` instruction informs Docker that the application listens on port 5000.

6. **Set Environment Variable**: The `ENV` instruction sets the environment variable `NAME` to "World".

7. **Define Command**: The `CMD` instruction specifies the default command to run when the container starts. In this case, it runs the `app.py` script.

### Additional Notes:

- Ensure that your `app.py` script is in the same directory as your `Dockerfile`.
- The `requirements.txt` file should list all the Python packages your application depends on.
- Adjust the base image version (`python:3.9-slim`) if you need a different version of Python.
