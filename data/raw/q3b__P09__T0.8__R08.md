Certainly! Below is a Dockerfile for a simple command-line tool built in Python using the Click library. This Dockerfile assumes you have a Python script that uses Click for command-line interface (CLI) functionality.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:

- **FROM python:3.9-slim**: This line specifies the base image as Python 3.9 with a slim version, which is smaller and uses less resources.
- **WORKDIR /app**: Sets the working directory inside the container to `/app`.
- **COPY . /app**: Copies the current directory contents into the container at the `/app` directory.
- **RUN pip install --no-cache-dir -r requirements.txt**: Installs the required Python packages specified in the `requirements.txt` file. The `--no-cache-dir` flag prevents caching of the dependencies, which is useful if you are developing and want changes to take effect immediately.
- **EXPOSE 80**: Declares that the container listens on port 80, which is commonly used for web servers.
- **ENV NAME World**: Sets the environment variable `NAME` to `World`.
- **CMD ["python", "app.py"]**: Specifies the command to run when the container starts, which is `python` followed by `app.py`, the main script of your command-line tool.

### Additional Considerations:

- If you need to install additional dependencies, add them to the `requirements.txt` file.
- If your application has a `requirements.txt` file, ensure you have one in your project root.
- If your application requires specific system-level packages, you might need to install them using `RUN apt-get install` or other package management tools, depending on the base image.

This Dockerfile is a basic setup and should be tailored to your specific application requirements.
