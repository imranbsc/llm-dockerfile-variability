Here is a basic Dockerfile for a Python application that uses APScheduler to run scheduled batch jobs. This example assumes you are using a Python 3 environment.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

**Note**: This Dockerfile assumes that you have a `requirements.txt` file in your project directory, which lists the Python packages required for your application. You also need to replace `app.py` with the actual entry point of your application.
