Certainly! Below is a Dockerfile that creates a container for a scheduled batch job built in Python using APScheduler. This Dockerfile sets up a base image, installs necessary dependencies, and defines how to run the batch job.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV APSCHEDULER_JOBSTORES='memory://'

# Define environment variable for APScheduler interval
ENV APSCHEDULER_INTERVAL='5'

# Run the app when the container launches
CMD ["python", "batch_job.py"]
```

### Explanation:

- **Base Image**: The Dockerfile uses the `python:3.9-slim` image as the base, which is a minimal Python environment.
- **Working Directory**: The working directory is set to `/app` to manage the application files.
- **Copy Files**: The current directory contents (your project files) are copied into the container at `/app`.
- **Install Dependencies**: The `pip install` command installs the necessary packages listed in `requirements.txt`.
- **Expose Port**: The container exposes port 5000, which is the default port for APScheduler.
- **Environment Variables**: Two environment variables are set:
  - `APSCHEDULER_JOBSTORES='memory://'`: This sets the job store to memory, meaning the scheduler will store job data in memory.
  - `APSCHEDULER_INTERVAL='5'`: This sets the interval between job executions to 5 seconds.
- **Command**: The container runs the `batch_job.py` file using Python.

### Notes:
- Replace `batch_job.py` with the actual Python file that contains your scheduled batch job.
- Ensure that `requirements.txt` contains all the necessary Python packages for your application.
- The `batch_job.py` file should be configured to use APScheduler for scheduling tasks.
