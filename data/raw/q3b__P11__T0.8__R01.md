Here's a Dockerfile for a REST API built in Java using Spring Boot. This Dockerfile sets up a Java runtime environment and deploys a Spring Boot application.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the jar file
CMD ["java", "-jar", "your-application.jar"]
```

Replace `your-application.jar` with the actual name of your Spring Boot application's JAR file. This Dockerfile sets up a minimal environment with Java and exposes port 8080, which is the default port for Spring Boot applications. The `CMD` instruction specifies how to run the application when it is started inside the container.
