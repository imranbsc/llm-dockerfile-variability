Certainly! Below is a simple Dockerfile to build a Docker image for a REST API built in Java using Spring Boot. This example assumes you have a basic Spring Boot application set up with Maven.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Make port 8080 available to the world outside this container
ENV SERVER_PORT 8080

# Run application using Maven
CMD ["mvn", "spring-boot:run"]
```

### Explanation:

1. **FROM openjdk:17-jdk-slim**: This line specifies the base image to use. The `openjdk:17-jdk-slim` image is a lightweight version of OpenJDK with a smaller size, suitable for container use.

2. **WORKDIR /app**: This sets the working directory inside the container where all the application files will be placed.

3. **COPY . /app**: This copies all files from the current directory to the `/app` directory in the container.

4. **EXPOSE 8080**: This exposes port 8080 on the container, which is where the Spring Boot application will listen for incoming requests.

5. **ENV SERVER_PORT 8080**: This sets the `SERVER_PORT` environment variable to 8080, which is necessary for the application to know which port to bind to.

6. **CMD ["mvn", "spring-boot:run"]**: This command runs the Spring Boot application using Maven. The `spring-boot:run` goal is a Maven plugin that compiles and runs the Spring Boot application.

### Building and Running the Docker Image:

To build the Docker image, run the following command in the same directory as your `Dockerfile`:

```sh
docker build -t my-spring-boot-app .
```

This command will create a Docker image named `my-spring-boot-app` using the Dockerfile in the current directory.

To run the container, use the following command:

```sh
docker run -p 8080:8080 my-spring-boot-app
```

This command maps port 8080 of the container to port 8080 on your host machine, allowing you to access your Spring Boot application via `http://localhost:8080`.
