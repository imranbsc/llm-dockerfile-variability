Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes you have a basic Spring Boot application set up with Thymeleaf templates.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the Spring Boot executable
CMD ["java", "-jar", "target/your-application.jar"]
```

### Explanation:

1. **Base Image**: The `openjdk:17-jdk-slim` image is used as the base image. This image is lightweight and includes the OpenJDK runtime and a small footprint.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory inside the container to `/app`. This is where your application files will be placed.

3. **Copy Files**: The `COPY . /app` command copies all files from the current directory (where the Dockerfile is located) to the `/app` directory inside the container.

4. **Expose Port**: The `EXPOSE 8080` command informs Docker that the application listens on port 8080, which is the default port for Spring Boot applications.

5. **Run Command**: The `CMD ["java", "-jar", "target/your-application.jar"]` command specifies the command to run when the container starts. Replace `"target/your-application.jar"` with the actual name of your compiled Spring Boot JAR file.

### Building the Docker Image:

To build the Docker image, navigate to the directory containing your Dockerfile and run the following command:

```sh
docker build -t your-image-name .
```

Replace `your-image-name` with a name for your Docker image.

### Running the Docker Container:

To run the Docker container, use the following command:

```sh
docker run -p 8080:8080 your-image-name
```

This will start a container and map port 8080 of the host to port 8080 of the container, allowing you to access your application at `http://localhost:8080` in your web browser.
