Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes you have a Spring Boot application structure and dependencies configured.

```dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using Spring Boot's embedded Tomcat server
CMD ["java", "-jar", "target/your-application-name.jar"]
```

### Explanation:

1. **Base Image**: `openjdk:11-jdk-slim` is used as the base image. It is a lightweight Java runtime environment.

2. **Working Directory**: `WORKDIR /app` sets the working directory inside the container to `/app`.

3. **Copy Files**: `COPY . /app` copies the current directory contents (your Spring Boot application) into the container at `/app`.

4. **Expose Port**: `EXPOSE 8080` makes port 8080 available to the world outside this container. This is where your Spring Boot application will listen for incoming requests.

5. **Run Command**: `CMD ["java", "-jar", "target/your-application-name.jar"]` specifies the command to run when the container starts. Replace `your-application-name.jar` with the actual name of your JAR file.

### Note:
- Ensure your application has a `pom.xml` or `build.gradle` file in the `src/main/resources` directory to build your JAR file.
- Replace `your-application-name.jar` with the actual name of your JAR file when using the `CMD` instruction.
- This Dockerfile assumes you are using Maven to build your application. If you are using Gradle, you might need to adjust the build command accordingly.
