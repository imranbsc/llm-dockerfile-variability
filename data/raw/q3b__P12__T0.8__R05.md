Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the Spring Boot CLI
CMD ["java", "-jar", "target/your-spring-boot-app.jar"]
```

### Explanation:
- **Base Image**: `openjdk:17-jdk-slim` - This is a lightweight Java 17 runtime image.
- **Working Directory**: `/app` - This is the directory where the application code will be placed.
- **Copy Application**: `COPY . /app` - Copies the current directory contents into the container at the `/app` directory.
- **Expose Port**: `EXPOSE 8080` - Makes port 8080 available for incoming connections.
- **Run Application**: `CMD ["java", "-jar", "target/your-spring-boot-app.jar"]` - This runs the Spring Boot application using the JAR file located in the `target` directory.

### Note:
- Replace `your-spring-boot-app.jar` with the actual name of your JAR file.
- Ensure that your `pom.xml` or `build.gradle` is correctly configured to package the application as a JAR and place it in the `target` directory.
- You might need to adjust the base image if your application requires a specific version or additional dependencies.
