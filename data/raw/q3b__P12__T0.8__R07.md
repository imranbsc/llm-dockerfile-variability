Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes you have a basic Spring Boot project set up with Thymeleaf templates.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV SPRING_APPLICATION_JSON='{"server":{"port":8080}}'

# Run the application using Thymeleaf
CMD ["java", "-jar", "target/your-application-name.jar"]
```

### Explanation:

1. **FROM openjdk:11-jdk-slim**: This line specifies the base image for the Docker container. It uses the OpenJDK 11 runtime with a slim version to reduce the image size.

2. **WORKDIR /app**: This sets the working directory in the container to `/app`, which is where the application will be copied and executed.

3. **COPY . /app**: This copies all files from the current directory (where the Dockerfile is located) to the `/app` directory inside the container.

4. **EXPOSE 8080**: This makes port 8080 available to other containers or to the host machine.

5. **ENV SPRING_APPLICATION_JSON='{"server":{"port":8080}}'**: This sets the environment variable `SPRING_APPLICATION_JSON` to configure the server port. You can replace `"your-application-name.jar"` with the actual name of your jar file.

6. **CMD ["java", "-jar", "target/your-application-name.jar"]**: This command specifies the command to run when the container starts. It starts the Spring Boot application from the `target` directory using the `your-application-name.jar`.

### Building and Running the Docker Container:

1. **Build the Docker image**:
   ```sh
   docker build -t your-image-name .
   ```

2. **Run the Docker container**:
   ```sh
   docker run -p 8080:8080 your-image-name
   ```
