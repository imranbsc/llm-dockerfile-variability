Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes you have a Spring Boot application with Thymeleaf templates and dependencies defined in your `pom.xml`.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the specified command
CMD ["java", "-jar", "your-application-name.jar"]
```

### Explanation:
- **FROM openjdk:11-jdk-slim**: This line specifies the base image to use. OpenJDK is used because it's lightweight and suitable for production environments. The `slim` variant is used to reduce the size of the image.
- **WORKDIR /app**: Sets the working directory inside the container to `/app`.
- **COPY . /app**: Copies the contents of the current directory (which should contain your `pom.xml` and `your-application-name.jar`) into the container at `/app`.
- **EXPOSE 8080**: Makes port 8080 available to other containers, which is where your Spring Boot application will run.
- **CMD ["java", "-jar", "your-application-name.jar"]**: Specifies the command to run when the container starts. Replace `"your-application-name.jar"` with the actual name of your JAR file.

### How to Build and Run the Docker Image:
1. **Build the Docker Image**:
   ```sh
   docker build -t your-image-name .
   ```
2. **Run the Docker Container**:
   ```sh
   docker run -p 8080:8080 your-image-name
   ```

This setup will run your Spring Boot application inside a Docker container, making it easy to deploy and manage.
