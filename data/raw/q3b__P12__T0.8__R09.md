Certainly! Below is a basic Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes that your application is a Spring Boot application with a `pom.xml` file.

```dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using Java command
CMD ["java", "-jar", "target/your-spring-boot-app.jar"]
```

### Key Points:
- **OpenJDK 11**: The image uses the latest version of OpenJDK 11. You can change this to a specific version if needed.
- **WORKDIR /app**: Sets the working directory to `/app` inside the container.
- **COPY . /app**: Copies the current directory contents into the container at `/app`.
- **EXPOSE 8080**: Makes port 8080 available to the world outside this container.
- **CMD ["java", "-jar", "target/your-spring-boot-app.jar"]**: Specifies the command to run the application when the container starts. Replace `"your-spring-boot-app.jar"` with the actual name of your JAR file.

### Build and Run the Docker Image:
1. **Build the Docker image**:
   ```sh
   docker build -t your-spring-boot-app .
   ```

2. **Run the Docker container**:
   ```sh
   docker run -p 8080:8080 your-spring-boot-app
   ```

This will start your Spring Boot application using the Docker container, making it accessible at `http://localhost:8080` in your host machine. Make sure your application has a `pom.xml` file for Maven to build the JAR, and that the application is configured to listen on port 8080.
