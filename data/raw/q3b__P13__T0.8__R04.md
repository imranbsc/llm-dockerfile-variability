```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:8-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Make port 5672 available to the world outside this container
EXPOSE 5672

# Define environment variable
ENV RABBITMQ_HOST rabbitmq

# Run the application using the executable
ENTRYPOINT ["java", "-jar", "target/your-application.jar"]
```

In this Dockerfile, we start with an official OpenJDK runtime, set the working directory, copy the project files into the container, expose necessary ports, define an environment variable for the RabbitMQ host, and then run the application using the provided executable. The `target/your-application.jar` should be replaced with the actual name of your compiled JAR file.
