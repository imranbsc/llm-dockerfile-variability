Certainly! Below is a Dockerfile for a background worker built in Java using Spring Boot and RabbitMQ. This Dockerfile assumes you are using OpenJDK 11 as the base image.

```Dockerfile
# Use an official OpenJDK 11 base image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the application JAR file into the container
COPY target/your-application.jar your-application.jar

# Expose the port on which the application will run
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "your-application.jar"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official OpenJDK 11 base image, which is optimized for running Java applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory for the application inside the container. In this case, it's set to `/app`.

3. **Copy Application JAR**: The `COPY` instruction copies the compiled Spring Boot JAR file (`your-application.jar`) into the `/app` directory inside the container.

4. **Expose Port**: The `EXPOSE` instruction informs Docker that the application is listening on port 8080, which is the default port for Spring Boot applications.

5. **Command to Run the Application**: The `CMD` instruction specifies the command to run the application when the container starts. It uses `java -jar` to execute the JAR file.

### Building the Docker Image:

To build the Docker image, navigate to the directory containing your Dockerfile and run the following command:

```sh
docker build -t your-application .
```

Replace `your-application` with the desired tag for your Docker image.

### Running the Docker Container:

Once the Docker image is built, you can run it using:

```sh
docker run -d --name your-application-container -p 8080:8080 your-application
```

Replace `your-application-container` with a name for your container and ensure that the port mapping matches the exposed port in your Dockerfile.

This setup provides a minimal and efficient environment for running a Spring Boot application with RabbitMQ in a Docker container.
