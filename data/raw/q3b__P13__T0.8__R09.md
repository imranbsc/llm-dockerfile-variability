Certainly! Below is a simple Dockerfile for a background worker built in Java using Spring Boot and RabbitMQ. This Dockerfile assumes you have a basic Spring Boot project with RabbitMQ dependencies.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV SPRING_APPLICATION_JSON='{"spring.rabbitmq.host": "rabbitmq", "spring.rabbitmq.port": 5672}'

# Run the application using the executable jar
CMD ["java", "-jar", "target/your-application-name.jar"]
```

### Explanation:
1. **Base Image**: `openjdk:17-jdk-slim` is used as the base image, which includes the OpenJDK runtime and a slim version to reduce the size of the image.
2. **Working Directory**: The working directory is set to `/app` where the application's files will be copied.
3. **Copy Files**: The `COPY` command copies all files from the current directory into the `/app` directory in the container.
4. **Expose Port**: `EXPOSE 8080` makes port 8080 available for the application to listen on.
5. **Environment Variable**: `ENV SPRING_APPLICATION_JSON='{"spring.rabbitmq.host": "rabbitmq", "spring.rabbitmq.port": 5672}'` sets the environment variable `SPRING_APPLICATION_JSON` which contains the RabbitMQ connection details.
6. **Run Command**: `CMD ["java", "-jar", "target/your-application-name.jar"]` starts the Spring Boot application using the jar file located in the `target` directory.

### How to Build and Run the Docker Image:
1. Build the Docker image:
   ```sh
   docker build -t your-application-name .
   ```
2. Run the Docker container:
   ```sh
   docker run -d --name your-application-name -p 8080:8080 your-application-name
   ```

Make sure to replace `your-application-name` with the actual name of your project and adjust the paths and configurations as needed for your specific project.
