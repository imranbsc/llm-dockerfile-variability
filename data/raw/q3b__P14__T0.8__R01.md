Here is a basic Dockerfile for a command-line tool built in Java using Picocli. This example assumes you have a `main` class that is annotated with `@CommandLine.Command` and that your project is structured with a `src/main/java` directory containing your source files.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV PORT 8080

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using picocli
CMD ["java", "-jar", "your-tool.jar"]
```

### Key Points:
- **Base Image**: Uses the official OpenJDK image with Java 11.
- **Working Directory**: Sets the working directory to `/app`.
- **Copy Files**: Copies the entire project directory into the container at `/app`.
- **Expose Ports**: Exposes port 8080, which is typically used for HTTP servers.
- **Environment Variable**: Defines the `PORT` environment variable to 8080.
- **Command**: Runs the application using the `java` command with the specified JAR file.

### Notes:
- Replace `your-tool.jar` with the actual name of your JAR file.
- Ensure that your `main` class is correctly annotated with `@CommandLine.Command` and that your `pom.xml` (or `build.gradle`) has the necessary dependencies for Picocli.
- You may need to adjust the Dockerfile based on your specific requirements, such as using a different base image or adjusting the port if your application uses a different port.
