Certainly! Below is a Dockerfile for a Java command-line tool built using Picocli. This Dockerfile assumes you have a Java application with a `main` class and a `pom.xml` file for Maven or a `build.gradle` file for Gradle.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in pom.xml/gradle.build
RUN mvn install || gradle build

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application, mapping port 8080 of the container to port 8080 of the host
CMD ["java", "-jar", "target/your-application.jar"]
```

### Explanation:
- **FROM openjdk:11-jdk-slim**: This line uses the OpenJDK 11 JDK image with a slim version, which is lightweight and efficient.
- **WORKDIR /app**: Sets the working directory inside the container to `/app`.
- **COPY . /app**: Copies the current directory contents (your project) into the `/app` directory inside the container.
- **RUN mvn install || gradle build**: Executes the `mvn install` command if you're using Maven or `gradle build` if you're using Gradle. Adjust the command based on your build tool.
- **EXPOSE 8080**: Makes port 8080 available to the world outside the container.
- **CMD ["java", "-jar", "target/your-application.jar"]**: Specifies the command to run the application. Replace `your-application.jar` with the actual name of your JAR file.

### Building the Docker Image:
To build the Docker image, navigate to the directory containing your `Dockerfile` and run:
```sh
docker build -t your-image-name .
```

### Running the Docker Container:
To run the container, use:
```sh
docker run -p 8080:8080 your-image-name
```

Make sure to replace `your-application.jar` and `your-image-name` with the actual names of your JAR file and the name you want to give to your Docker image, respectively.
