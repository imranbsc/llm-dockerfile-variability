Certainly! Below is a Dockerfile for building a Java command-line tool using picocli. This Dockerfile assumes you have a Maven project set up with picocli dependencies.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the compiled JAR file from the build directory to the container
COPY target/your-tool-1.0.0-SNAPSHOT.jar app.jar

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV APP_PORT 8080

# Define command to run the application
CMD ["java", "-jar", "app.jar"]
```

### Instructions:

1. **Replace `your-tool-1.0.0-SNAPSHOT.jar`**: This should be replaced with the actual name of your compiled JAR file.
2. **Build the Docker image**: Use the following command to build the Docker image:

   ```sh
   docker build -t your-tool-image .
   ```

3. **Run the Docker container**: Use the following command to run the container:

   ```sh
   docker run -p 8080:8080 your-tool-image
   ```

This Dockerfile sets up a minimal environment with OpenJDK 17, copies your compiled JAR file into the container, and exposes port 8080 for your application to listen on. Adjust the paths and environment variables as needed for your specific project setup.
