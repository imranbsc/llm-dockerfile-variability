```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Make port 5005 available to the world outside this container
EXPOSE 5005

# Define environment variable
ENV JAVA_OPTS="-Xmx512m"

# Make port 9090 available to the world outside this container
EXPOSE 9090

# Run the application using picocli
CMD ["java", "-jar", "your-application.jar"]
```

### Instructions to Use the Dockerfile

1. **Ensure you have a Java project set up**:
   - Make sure your project is structured and includes a `pom.xml` or `build.gradle` file with picocli dependencies.
   - Build your Java application using `mvn clean package` or `./gradlew build`.

2. **Place your Dockerfile**:
   - Place the Dockerfile in the root directory of your Java project.

3. **Build the Docker image**:
   - Run the following command in your project directory:
     ```sh
     docker build -t your-image-name .
     ```
   - Replace `your-image-name` with a suitable name for your Docker image.

4. **Run the Docker container**:
   - Run the following command to start your Docker container:
     ```sh
     docker run -p 8080:8080 -p 5005:5005 -p 9090:9090 your-image-name
     ```
   - This command maps the ports of your container to your host machine so you can interact with it.

5. **Run your application**:
   - Open a web browser or use a tool like `curl` to test your application:
     ```sh
     curl http://localhost:8080/your-endpoint
     ```
