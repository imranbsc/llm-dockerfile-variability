Certainly! Below is a simple Dockerfile for a command-line tool built in Java using the picocli library. This Dockerfile assumes you have a Java application packaged as a JAR file.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the packaged application JAR to the container
COPY target/your-application.jar /app/app.jar

# Expose the default port your application is running on
EXPOSE 8080

# Define environment variables if needed

# Run the application
CMD ["java", "-jar", "app.jar"]
```

### Instructions to Build and Run the Docker Image

1. **Build the Docker Image:**
   ```bash
   docker build -t your-app-name .
   ```

2. **Run the Docker Container:**
   ```bash
   docker run -p 8080:8080 your-app-name
   ```

### Notes

- Replace `your-application.jar` with the actual name of your JAR file.
- If your application has specific dependencies or additional configuration files, you might need to adjust the COPY command to include them in the Docker image.
- You can further customize the Dockerfile by adding instructions to install dependencies, set environment variables, or run other setup commands.
