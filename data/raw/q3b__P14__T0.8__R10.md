Certainly! Below is a Dockerfile for a command-line tool built in Java using Picocli. This Dockerfile assumes that you have a Java application that uses Picocli for command-line parsing.

```Dockerfile
# Use an official OpenJDK image as the base image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the Picocli main class
CMD ["java", "-jar", "your-application.jar"]
```

### Explanation:
- **Base Image**: `openjdk:17-jdk-slim` is used as the base image. This image is lightweight and contains the OpenJDK runtime with Java 17.
- **Working Directory**: `/app` is set as the working directory in the container.
- **Copying Files**: The current directory contents are copied into the container at `/app`.
- **Expose Port**: Port 8080 is exposed, which is commonly used for HTTP services. You can change this if your application uses a different port.
- **Running the Application**: The application is executed using the `java` command with the `-jar` option, assuming your application is a JAR file named `your-application.jar`.

### Building and Running the Docker Image:
1. Build the Docker image:
   ```sh
   docker build -t your-image-name .
   ```

2. Run the Docker container:
   ```sh
   docker run -p 8080:8080 your-image-name
   ```

Make sure to replace `your-application.jar` with the actual name of your JAR file and `your-image-name` with a name of your choice.
