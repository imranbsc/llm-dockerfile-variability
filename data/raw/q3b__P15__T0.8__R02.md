Certainly! Below is a Dockerfile for a scheduled batch job built in Java using Spring Batch. This Dockerfile assumes you have a basic understanding of Docker and Spring Batch.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the local project files into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Build the Spring Batch application
RUN ./mvnw clean package

# Copy the built JAR file into the container
COPY --from=0 /app/target/your-spring-batch-app-*.jar app.jar

# Expose the port that the Spring Batch application will run on
EXPOSE 8080

# Run the Spring Batch application
CMD ["java", "-jar", "app.jar"]
```

### Explanation:
- **Base Image**: The `openjdk:11-jdk-slim` image is used as the base image, which is lightweight and optimized for running Java applications.
- **Working Directory**: The `WORKDIR` instruction sets the working directory to `/app` where the application will be built and run.
- **Copy Files**: The `COPY` instructions copy the project files from your local machine to the container. Make sure your project structure includes a `pom.xml` for Maven or `build.gradle` for Gradle.
- **Build the Application**: The `RUN ./mvnw clean package` command builds the application using Maven.
- **Copy the JAR**: The `COPY --from=0 /app/target/your-spring-batch-app-*.jar app.jar` instruction copies the built JAR file into the container.
- **Expose Port**: The `EXPOSE` instruction informs Docker that the application listens on port 8080.
- **Run the Application**: The `CMD` instruction starts the Spring Batch application using the `java` command.

### Notes:
- Replace `your-spring-batch-app-*.jar` with the actual name of your JAR file.
- Ensure that all necessary dependencies are included in your `pom.xml` or `build.gradle` file.
- You may need to adjust the Maven or Gradle commands based on your project setup.

This Dockerfile should provide a basic setup for running a Spring Batch application in a Docker container.
