```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:8-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the jar file
CMD ["java", "-jar", "your-spring-batch-job.jar"]
```

Please replace `your-spring-batch-job.jar` with the actual name of your jar file containing the Spring Batch application. This Dockerfile sets up a basic Java environment with OpenJDK, copies your Spring Batch application into it, and runs it when the container is started.
