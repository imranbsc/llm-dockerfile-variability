Certainly! Below is a Dockerfile for a scheduled batch job built in Java using Spring Batch. This Dockerfile assumes you have a simple Spring Batch application with a job definition.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the application build artifacts into the container
COPY target/your-spring-batch-app.jar /app/your-spring-batch-app.jar

# Expose the port your application listens on
EXPOSE 8080

# Define environment variables
ENV SPRING_BATCH_JOB_NAME=your-spring-batch-job
ENV SPRING_BATCH_JOB_NAME_SCHEDULE=0 0 * * * ?  # Example cron schedule for daily at midnight

# Start the Spring Boot application
CMD ["java", "-jar", "your-spring-batch-app.jar"]
```

### Explanation:

1. **Base Image**: The `openjdk:11-jdk-slim` image is used as the base image, which is a lightweight Java runtime environment.
2. **Working Directory**: The `WORKDIR /app` sets the working directory within the container to `/app`.
3. **Copy Artifact**: The `COPY target/your-spring-batch-app.jar /app/your-spring-batch-app.jar` command copies the built JAR file from your local build into the container.
4. **Expose Port**: The `EXPOSE 8080` command informs Docker that the application listens on port 8080.
5. **Environment Variables**: 
   - `SPRING_BATCH_JOB_NAME` is set to the name of your Spring Batch job.
   - `SPRING_BATCH_JOB_NAME_SCHEDULE` is set to the cron schedule for when the job should run. You can modify this to suit your needs.
6. **Command**: The `CMD ["java", "-jar", "your-spring-batch-app.jar"]` command runs the Spring Boot application.

### Build and Run:

To build the Docker image, run the following command from the directory containing the Dockerfile:

```sh
docker build -t your-spring-batch-app .
```

After building, you can run the container using:

```sh
docker run -d --name your-spring-batch-container your-spring-batch-app
```

This will start your Spring Batch application in a Docker container, which will automatically run the job according to the cron schedule defined.
