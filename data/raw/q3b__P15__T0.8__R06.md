Here is a Dockerfile for a scheduled batch job built in Java using Spring Batch:

```dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the application JAR file from your local machine to the container
COPY target/your-application.jar your-application.jar

# Expose the port on which your Spring Batch job will run
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "your-application.jar"]
```

Make sure to replace `your-application.jar` with the actual name of your JAR file. Additionally, you may need to add other dependencies or configurations depending on your application's requirements.
