Certainly! Below is a simple Dockerfile to create a Docker image for a scheduled batch job built in Java using Spring Batch. This example assumes you have a basic Spring Boot application with Spring Batch configured.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN apt-get update && \
    apt-get install -y curl && \
    curl -L https://repo.spring.io/maven2/org/springframework/boot/spring-boot-cli/2.6.7/spring-boot-cli-2.6.7.jar -o /usr/local/bin/spring

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Define environment variable
ENV SPRING_APPLICATION_JSON '{"server":{"port":8080}}'

# Run the application using the specified main class
CMD ["java", "-jar", "target/your-application.jar"]
```

### Key Points:
- **Java Version**: The Dockerfile uses OpenJDK 17. You can change this to any other version of Java if needed.
- **Working Directory**: The `WORKDIR` instruction sets the working directory to `/app` within the container.
- **Copy Files**: The `COPY` instruction copies all files from your current directory to `/app` in the container.
- **Spring Boot CLI**: The Dockerfile installs the Spring Boot CLI, which is necessary to run Spring Boot applications.
- **Environment Variable**: The `ENV` instruction sets the `SPRING_APPLICATION_JSON` environment variable to configure the port.
- **Exposing Port**: The `EXPOSE` instruction makes port 8080 available to the outside world.
- **Running the Application**: The `CMD` instruction runs the Spring Boot application using the specified main class.

### Notes:
- Ensure that your `Dockerfile` is in the same directory as your `pom.xml` or `build.gradle` (or equivalent) file, and that your Spring Boot application is built using Maven or Gradle.
- Update the `ENV SPRING_APPLICATION_JSON` if you need to configure other Spring Boot properties.
- Adjust the `COPY` instruction if your application is located in a different directory.
