Certainly! Below is a simple Dockerfile for a REST API built in Go using the Gin framework. This Dockerfile assumes you have Go installed on your host machine and that you have a Go project set up with a main.go file.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go get -u github.com/gin-gonic/gin

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the app
CMD ["go", "run", "main.go"]
```

### Explanation:

1. **Base Image**: The `golang:1.16-alpine` image is used as the base image. This is a lightweight version of the Go image that includes Alpine Linux, which is known for its small size and fast build times.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory inside the container to `/app`. This is where your Go application will be built and run.

3. **Copy Files**: The `COPY . /app` command copies all files from the current directory (where the Dockerfile is located) to the `/app` directory inside the container.

4. **Install Dependencies**: The `RUN go get -u github.com/gin-gonic/gin` command installs the Gin framework. The `-u` flag ensures that the latest version is installed.

5. **Expose Port**: The `EXPOSE 8080` command tells Docker that the application listens on port 8080, which is the default port for HTTP.

6. **Run Command**: The `CMD ["go", "run", "main.go"]` command specifies the command to run when the container starts. This command runs the Go application from the `main.go` file in the `/app` directory.

### Building and Running the Docker Image:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-gin-api .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -p 8080:8080 my-gin-api
   ```

This will start a container running your Go application, and you can access it at `http://localhost:8080` in your web browser or using a tool like `curl`.
