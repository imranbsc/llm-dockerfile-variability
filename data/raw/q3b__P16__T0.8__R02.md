Certainly! Below is a simple Dockerfile for a REST API built in Go using the Gin framework.

```Dockerfile
# Use the official Go image as the base image
FROM golang:1.21-alpine as builder

# Set the working directory in the container
WORKDIR /go/src/api

# Copy the Go source files into the container
COPY . .

# Build the Go application
RUN go build -o api .

# Use the official Alpine image as the base image for the final image
FROM alpine:latest

# Set the working directory in the container
WORKDIR /app

# Copy the built application from the builder image
COPY --from=builder /go/src/api/api .

# Expose the default port for the API
EXPOSE 8080

# Run the application
CMD ["./api"]
```

### Explanation:
- **Builder Stage**: The first stage uses the official Go image to build the Go application. The `golang:1.21-alpine` image is used for its minimal size and includes the necessary tools to build Go applications.
- **Copy Source Files**: The `COPY . .` command copies all the files from the local directory to the `/go/src/api` directory in the container.
- **Build the Application**: The `go build -o api .` command compiles the Go application into an executable named `api`.
- **Final Stage**: The second stage uses the Alpine image to create the final image. This image is smaller than the Go image and only contains the necessary files for running the application.
- **Set Working Directory**: The `WORKDIR /app` command sets the working directory in the container to `/app`.
- **Copy Built Application**: The `COPY --from=builder /go/src/api/api .` command copies the compiled application from the builder stage into the final image.
- **Expose Port**: The `EXPOSE 8080` command exposes port 8080, which is the default port for Gin.
- **Run the Application**: The `CMD ["./api"]` command runs the application when the container is started.

You can build this Dockerfile using the following command:

```sh
docker build -t my-go-api .
```

Then, you can run the container using:

```sh
docker run -p 8080:8080 my-go-api
```

This will start a container and make your REST API accessible at `http://localhost:8080`.
