Certainly! Below is a simple Dockerfile for a REST API built in Go using Gin:

```Dockerfile
# Use the official Golang image as the base image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /go/src/api

# Copy the current directory contents into the container at /go/src/api
COPY . .

# Install any needed packages specified in requirements.txt
RUN apk add --no-cache git

# Build the Go binary
RUN go build -o api .

# Expose the port the Go app will listen on
EXPOSE 8080

# Run the built Go binary
CMD ["./api"]
```

### Explanation:
- **Base Image**: The `golang:1.16-alpine` image is used as the base image, which is lightweight and optimized for production use.
- **Working Directory**: The `WORKDIR` instruction sets the directory for the Docker container to work in.
- **Copy Dependencies**: The `COPY` command copies the current directory contents into the container at the `/go/src/api` directory.
- **Install Git**: The `apk add --no-cache git` command installs Git in the container, which is needed for running `go get` if there are any dependencies.
- **Build the Go Binary**: The `RUN go build -o api .` command compiles the Go application and outputs it as a binary named `api`.
- **Expose Port**: The `EXPOSE 8080` instruction informs Docker that the application is listening on port 8080.
- **Run the Application**: The `CMD ["./api"]` instruction specifies the default command to run when the container starts.

You can then build and run the Docker image using the following commands:

```sh
docker build -t my-go-api .
docker run -p 8080:8080 my-go-api
```

This will build an image named `my-go-api` and run it, mapping port 8080 of the container to port 8080 of your host machine.
