```Dockerfile
# Use the official Golang image as the base image
FROM golang:1.16-alpine AS build

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go get -u ./...

# Build the Go application
RUN go build -o app

# Use the multi-stage build to create a smaller final image
FROM alpine:3.14

# Set the working directory in the container
WORKDIR /app

# Copy the pre-built Go application from the build stage
COPY --from=build /app/app .

# Expose the port the application is listening on
EXPOSE 8080

# Run the application
CMD ["./app"]
```

This Dockerfile sets up a Go environment, builds the application, and then uses a minimal Alpine-based image to run the application.
