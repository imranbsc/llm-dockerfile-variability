Certainly! Below is a simple Dockerfile to build a Go REST API using Gin. This Dockerfile assumes you have Go installed and your Go application code is located in the `/app` directory within the Docker container.

```Dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.16-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go mod download && \
    go build -o api main.go

# Use an official Alpine runtime as a parent image
FROM alpine:3.14

# Copy the executable from the builder image to the new image
COPY --from=builder /app/api /api

# Set the entry point for the container
ENTRYPOINT ["/api"]
```

### Explanation:

1. **Builder Stage**:
   - `FROM golang:1.16-alpine as builder`: Uses the official Go 1.16 image as the base image for the builder stage.
   - `WORKDIR /app`: Sets the working directory to `/app` within the container.
   - `COPY . /app`: Copies all files from the local directory to `/app` in the container.
   - `RUN go mod download && go build -o api main.go`: Downloads the dependencies using `go mod download` and builds the Go application into an executable named `api`.

2. **Final Stage**:
   - `FROM alpine:3.14`: Uses an official Alpine image as the base image for the final stage.
   - `COPY --from=builder /app/api /api`: Copies the `api` executable from the builder stage to the `/api` directory in the final stage.
   - `ENTRYPOINT ["/api"]`: Sets the entry point of the container to run the `api` executable.

To build and run this Dockerfile, you can use the following commands:

```sh
# Build the Docker image
docker build -t go-rest-api .

# Run the Docker container
docker run -p 8080:8080 go-rest-api
```

This will start a container running your Go REST API, accessible at `http://localhost:8080`.
