Certainly! Below is a Dockerfile for a simple REST API built in Go using the Gin framework. This Dockerfile assumes you have a Go project set up with a main.go file that serves as the entry point for your API.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.21.5-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go mod download

# Build the Go app
RUN CGO_ENABLED=0 go build -o app main.go

# Use an official lightweight runtime as a parent image
FROM alpine:3.17

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the builder stage to the new image
COPY --from=builder /app/app .

# Expose the default port for Gin
EXPOSE 8080

# Define environment variable
ENV PORT=8080

# Run the app
CMD ["./app"]
```

### Explanation:

- **Base Image**: The `golang:1.21.5-alpine` image is used as a base image for the builder stage. This image includes the Go toolchain and is optimized for small size.

- **Work Directory**: The `WORKDIR` directive sets the working directory to `/app` where the application code will be located.

- **Copy Source Code**: The `COPY` command copies the entire contents of the current directory (including the `main.go` file) into the container at the `/app` directory.

- **Go Build**: The `go build` command compiles the Go application into an executable binary named `app`. The `CGO_ENABLED=0` flag disables CGO, which is useful for building standalone binary without C dependencies.

- **Base Runtime Image**: The `alpine:3.17` image is used as a base image for the production stage. This image is lightweight and is suitable for running production applications.

- **Copy Binary**: The `COPY --from=builder /app/app .` command copies the compiled binary from the builder stage to the new image.

- **Expose Port**: The `EXPOSE` directive specifies that port 8080 is exposed on the container.

- **Environment Variable**: The `ENV` directive sets the `PORT` environment variable to 8080, which is commonly used by web servers.

- **CMD**: The `CMD` directive specifies the default command to run when the container starts, which is the binary `./app`.

This Dockerfile provides a minimal setup for a Go application using Gin and can be extended with additional configurations as needed.
