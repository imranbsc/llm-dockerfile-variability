Certainly! Below is a simple Dockerfile for a REST API built in Go using Gin. This Dockerfile sets up a basic environment to build and run a Gin application.

```Dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.17-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN apk add --no-cache git

# Build the Go app
RUN go build -o main

# Use an official Alpine Linux runtime as a parent image for the final image
FROM alpine:3.15

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the builder stage
COPY --from=builder /app/main .

# Expose the port your application runs on
EXPOSE 8080

# Run the app
CMD ["./main"]
```

### Explanation:

1. **Base Image**: The `golang:1.17-alpine` image is used as the base image for the builder stage, which contains Go and the necessary tools to build the application.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`.

3. **Copy Source Code**: The `COPY` instruction copies the current directory contents into the container at the `/app` directory.

4. **Install Dependencies**: The `apk add` command installs Git, which is useful for fetching dependencies if your application uses them.

5. **Build the Application**: The `go build` command compiles the Go application into an executable named `main`.

6. **Final Image**: The `alpine:3.15` image is used as the base image for the final image. This image is smaller and more efficient than the Go runtime.

7. **Working Directory in Final Image**: The `WORKDIR` instruction is set again to `/app` to ensure consistency.

8. **Copy Binary**: The binary from the builder stage is copied into the final image.

9. **Expose Port**: The `EXPOSE` instruction informs Docker which port the application listens on.

10. **Run Command**: The `CMD` instruction specifies the command to run the application, which is the binary `./main`.

### Building and Running:

- Build the Docker image:
  ```sh
  docker build -t my-gin-app .
  ```

- Run the Docker container:
  ```sh
  docker run -p 8080:8080 my-gin-app
  ```

This will start a container running your Go application on port 8080, making it accessible from your host machine.
