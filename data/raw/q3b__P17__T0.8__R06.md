```Dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in go.mod
RUN go mod download

# Build the Go app
RUN go build -o app main.go

# Make port 80 available to the world outside this container
EXPOSE 80

# Run the app when the container launches
CMD ["./app"]
```

This Dockerfile sets up a Golang environment, copies the application code into the container, installs dependencies, builds the application, and exposes port 80 for HTTP traffic.
