Certainly! Below is a Dockerfile for a server-rendered web application built in Go using the `html/template` package. This Dockerfile assumes you have a simple Go application that renders HTML templates.

```Dockerfile
# Use the official Go image as the base image
FROM golang:1.17-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN apk add --no-cache git

# Build the Go application
RUN go build -o app server.go

# Use an official lightweight image for the runtime
FROM alpine:3.14

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the builder stage to the runtime stage
COPY --from=builder /app/app .

# Expose the port on which the application will run
EXPOSE 8080

# Run the application
CMD ["./app"]
```

### Explanation:

1. **Base Image**: The `golang:1.17-alpine` image is used as the base image for the builder stage. This image is lightweight and includes the necessary tools to build Go applications.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory in the container to `/app`.

3. **Copying Sources**: The `COPY . /app` command copies the current directory contents into the container at `/app`.

4. **Building the Application**: The `RUN go build -o app server.go` command builds the Go application and outputs it as `app` in the `/app` directory.

5. **Runtime Image**: The `alpine:3.14` image is used as the base image for the runtime stage. This is a minimal and secure Alpine Linux distribution.

6. **Copying the Binary**: The `COPY --from=builder /app/app .` command copies the built application binary from the builder stage to the runtime stage.

7. **Exposing the Port**: The `EXPOSE 8080` command makes port 8080 available to the world outside this container.

8. **Running the Application**: The `CMD ["./app"]` command specifies the command to run the application when the container starts.

### Notes:

- Replace `server.go` with the name of your main Go file.
- Ensure that your application logic is correctly structured to use the `html/template` package for rendering HTML templates.
- The `apk add --no-cache git` line is included if your application needs to run Git commands, which is not typically the case for a simple web server. You can remove this line if it's not needed.
