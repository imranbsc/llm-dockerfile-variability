```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go mod download

# Build the Go application
RUN CGO_ENABLED=0 go build -o asynq-worker main.go

# Use an official Alpine image as a parent image for the final image
FROM alpine:3.15

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the builder stage
COPY --from=builder /app/asynq-worker .

# Expose the port the application runs on
EXPOSE 8080

# Run the application
CMD ["./asynq-worker"]
```

1. **Base Image**: The Dockerfile starts with an official Go runtime image (`golang:1.17-alpine`) as the base image. This image is lightweight and includes the Go toolchain.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`, which is where the application code will be placed.

3. **Copy Application Files**: The `COPY` instruction copies the current directory contents into the container at `/app`. This includes your Go source code and any other necessary files.

4. **Install Dependencies**: The `RUN go mod download` command installs the dependencies specified in your `go.mod` file.

5. **Build the Application**: The `RUN CGO_ENABLED=0 go build -o asynq-worker main.go` command builds the Go application into an executable named `asynq-worker`.

6. **Final Image**: The Dockerfile uses an Alpine image as the final base image. This is a lightweight version of Alpine Linux that is optimized for size and performance.

7. **Working Directory**: The `WORKDIR` instruction is set again to `/app` in the final image.

8. **Copy Binary**: The `COPY --from=builder /app/asynq-worker .` command copies the built binary from the builder stage into the final image.

9. **Expose Port**: The `EXPOSE 8080` instruction informs Docker that the application listens on port 8080.

10. **Run the Application**: The `CMD ["./asynq-worker"]` instruction specifies the command to run the application when the container starts.
