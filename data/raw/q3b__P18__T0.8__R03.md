Certainly! Below is a Dockerfile for a background worker built in Go using the Asynq library. This Dockerfile assumes you have Go installed on your system.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in go.mod
RUN go get -v ./...

# Expose the port the application will run on
EXPOSE 6317

# Define environment variable for database URL
ENV DATABASE_URL=postgres://username:password@host:port/database?sslmode=disable

# Make port 6317 available to the world outside this container
CMD ["./worker"]
```

### Explanation:
1. **Base Image**: The Dockerfile starts with the official Go runtime image. This is a lightweight image based on Alpine Linux, which is small and efficient.
2. **Working Directory**: The `WORKDIR` instruction sets the working directory in the container to `/app`.
3. **Copy Files**: The `COPY` instruction copies the current directory contents into the container at `/app`.
4. **Install Dependencies**: The `RUN go get -v ./...` command installs any Go dependencies specified in your `go.mod` file.
5. **Expose Port**: The `EXPOSE 6317` instruction informs Docker that the container listens on port 6317 for HTTP traffic.
6. **Environment Variable**: The `ENV DATABASE_URL` instruction sets an environment variable for the database connection URL.
7. **Command to Run**: The `CMD ["./worker"]` instruction specifies the command to run when the container starts. In this case, it runs the `worker` binary located in the `/app` directory.

### Note:
- Replace `username`, `password`, `host`, `port`, and `database` with your actual database credentials.
- Ensure that your `worker` binary is named `worker` and is located in the root of your project directory.

To build and run the Docker container, you can use the following commands:

```sh
docker build -t my-worker .
docker run -d --name my-worker-container my-worker
```
