Certainly! Below is a Dockerfile for a command-line tool built in Go using Cobra. This Dockerfile assumes you have a Go project set up with Cobra and you want to build and run it in a Docker container.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the current directory contents into the container at /go/src/app
COPY . /go/src/app

# Install any needed packages specified in requirements.txt
RUN go get -u github.com/spf13/cobra

# Build the Go app
RUN CGO_ENABLED=0 go build -o app main.go

# Expose the port the app runs on
EXPOSE 8080

# Run the app
CMD ["./app"]
```

### Explanation:

1. **Base Image**: The `golang:1.17-alpine` image is used as the base image, which is a lightweight version of the Go runtime optimized for Alpine Linux.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/go/src/app`, where your Go source code will be located.

3. **Copy Source Code**: The `COPY` instruction copies all files from the current directory to the `/go/src/app` directory inside the container.

4. **Install Cobra**: The `RUN go get -u github.com/spf13/cobra` command installs Cobra, which is a library for building command-line interfaces in Go.

5. **Build the Go App**: The `RUN CGO_ENABLED=0 go build -o app main.go` command builds the Go application. The `-o app` flag specifies the output binary name.

6. **Expose Port**: The `EXPOSE 8080` instruction tells Docker that the application listens on port 8080.

7. **Run the App**: The `CMD ["./app"]` instruction specifies the command to run the application when the container starts.

### Building and Running the Docker Image:

To build the Docker image, navigate to the directory containing the Dockerfile and run:

```sh
docker build -t my-cobra-app .
```

To run the Docker container:

```sh
docker run -p 8080:8080 my-cobra-app
```

This will start a container and map port 8080 of the host to port 8080 of the container, allowing you to access your command-line tool.
