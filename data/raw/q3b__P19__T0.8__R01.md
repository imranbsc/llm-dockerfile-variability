Here is a basic Dockerfile for a command-line tool built in Go using Cobra:

```dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.17

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the Go application source code into the container
COPY . .

# Install any needed packages specified in go.mod
RUN go get -u -v ./...

# Build the Go application
RUN CGO_ENABLED=0 go build -o /app/app

# Expose the port the application listens on
EXPOSE 8080

# Run the application when the container launches
CMD ["/app/app"]
```

### Explanation:
- **FROM golang:1.17**: This line sets the base image to an official Go 1.17 runtime.
- **WORKDIR /go/src/app**: Sets the working directory inside the container where the application will be built.
- **COPY . .**: Copies the current directory contents into the container at the working directory.
- **RUN go get -u -v ./...**: Installs any Go dependencies listed in `go.mod` and `go.sum`.
- **RUN CGO_ENABLED=0 go build -o /app/app**: Compiles the Go application into an executable named `app` and places it in the `/app` directory.
- **EXPOSE 8080**: Exposes port 8080, which is the default port for the application.
- **CMD ["/app/app"]**: Specifies the default command to run when the container starts, which is the compiled application.
