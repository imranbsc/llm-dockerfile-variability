Certainly! Below is a Dockerfile for a command-line tool built in Go using Cobra. This example assumes you have a Go project set up with Cobra and a `main.go` file as the entry point.

```Dockerfile
# Use the official Golang image as the base image
FROM golang:latest

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the Go application source code into the container
COPY . .

# Install dependencies
RUN go get -u github.com/spf13/cobra@v1.7.1

# Build the Go application
RUN CGO_ENABLED=0 go build -o app main.go

# Expose the port that the application listens on
EXPOSE 8080

# Run the application
CMD ["./app"]
```

### Explanation:

1. **Base Image**: The `golang:latest` image is used as the base image, which contains the Go toolchain.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/go/src/app`, which is where the Go application source code will be copied.

3. **Copy Source Code**: The `COPY . .` instruction copies all files and directories from the host to the container's working directory.

4. **Install Dependencies**: The `RUN go get -u github.com/spf13/cobra@v1.7.1` command installs Cobra and its dependencies.

5. **Build the Application**: The `RUN CGO_ENABLED=0 go build -o app main.go` command compiles the Go application. The `-o` flag specifies the output binary name.

6. **Expose Port**: The `EXPOSE 8080` instruction tells Docker that the application listens on port 8080.

7. **Run the Application**: The `CMD ["./app"]` instruction specifies the command to run when the container starts, which is the compiled binary.

### Building and Running the Docker Image:

To build the Docker image, you can use the following command:

```sh
docker build -t your-image-name .
```

To run the Docker container, you can use the following command:

```sh
docker run -p 8080:8080 your-image-name
```

This will start a container and map port 8080 on the host to port 8080 in the container, allowing you to access your command-line tool.
