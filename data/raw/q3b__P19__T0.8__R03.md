Certainly! Below is a Dockerfile for a command-line tool built in Go using Cobra.

```Dockerfile
# Use the official Golang image as the base image
FROM golang:1.16-alpine AS build-env

# Set the working directory in the container
WORKDIR /go/src/github.com/yourusername/yourtool

# Copy the go.mod and go.sum files to the container
COPY go.mod go.sum .

# Download all dependencies specified in go.mod
RUN go mod download

# Copy the source code into the container
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 go build -o yourtool

# Use the official Alpine image as the final image
FROM alpine:3.12

# Copy the binary from the build-env to the final image
COPY --from=build-env /go/src/github.com/yourusername/yourtool/yourtool /usr/local/bin/yourtool

# Set the default command to run when the container starts
CMD ["yourtool"]
```

### Explanation:
1. **Base Image**: The `golang:1.16-alpine` image is used as the base image for building the Go application. Alpine is lightweight and has a small footprint, which is ideal for production environments.
2. **Working Directory**: The `WORKDIR` instruction sets the working directory in the container to `go/src/github.com/yourusername/yourtool`.
3. **Copying Dependencies**: The `COPY go.mod go.sum .` command copies the `go.mod` and `go.sum` files to the container. The `go mod download` command downloads all dependencies specified in `go.mod`.
4. **Building the Application**: The `RUN go build -o yourtool` command compiles the Go application and outputs it as `yourtool`.
5. **Final Image**: The `alpine:3.12` image is used as the final image. The `COPY --from=build-env /go/src/github.com/yourusername/yourtool/yourtool /usr/local/bin/yourtool` command copies the compiled binary from the build environment to the final image.
6. **Default Command**: The `CMD ["yourtool"]` instruction sets the default command to run when the container starts, which is the executable built in the previous step.

Make sure to replace `yourusername` and `yourtool` with your actual GitHub username and the name of your tool.
