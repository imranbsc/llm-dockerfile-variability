Certainly! Below is a Dockerfile for building a Go application using Cobra, which is a popular library for building command-line interfaces. This Dockerfile uses the official Go image and sets up a simple environment to build and run the application.

```Dockerfile
# Use the official Go image
FROM golang:1.16-alpine as build

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the current directory contents into the container at /go/src/app
COPY . /go/src/app

# Install any needed packages specified in requirements.txt
RUN go get -u github.com/spf13/cobra

# Build the Go application
RUN CGO_ENABLED=0 go build -o app ./cmd/main

# Use the official Alpine image as a parent image
FROM alpine:3.13

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the build stage
COPY --from=build /go/src/app/app .

# Expose the application port
EXPOSE 8080

# Command to run the application
CMD ["./app"]
```

### Explanation:

- **Build Stage**: The `build` stage uses the official Go image to compile the application. The `COPY` command places the application's source code into the container, and `go get` installs Cobra.
- **Final Stage**: The `alpine:3.13` image is used as the final stage to create a lean and efficient Docker image. The binary from the build stage is copied into this image, and it is exposed on port 8080. The default command (`CMD ["./app"]`) specifies the entry point for the container when it is run.
