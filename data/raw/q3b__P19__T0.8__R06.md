```Dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.16-alpine

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the current directory contents into the container at /go/src/app
COPY . /go/src/app

# Build the Go app
RUN go build -o app main.go

# Expose the port the app runs on
EXPOSE 8080

# Run the app when the container launches
CMD ["./app"]
```

**Explanation**:
- **FROM golang:1.16-alpine**: This line specifies the base image for the Docker container, using the official Golang image with version 1.16 and Alpine Linux as the base OS, which is lightweight.
- **WORKDIR /go/src/app**: This sets the working directory inside the container to `/go/src/app`, which is where the source code for the Go application will be stored.
- **COPY . /go/src/app**: This copies all files from the local directory to the specified location inside the container.
- **RUN go build -o app main.go**: This command builds the Go application using the `go build` command and outputs the binary to a file named `app`.
- **EXPOSE 8080**: This line makes the container listen on port 8080, which is the default port for HTTP servers.
- **CMD ["./app"]**: This sets the default command to run when the container starts, which is the binary built from the Go application.
