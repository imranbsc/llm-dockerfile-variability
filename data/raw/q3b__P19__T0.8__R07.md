Certainly! Below is a Dockerfile for a command-line tool built in Go using Cobra. This Dockerfile assumes you have a Go project set up with Cobra as a dependency.

```dockerfile
# Use an official Golang runtime as a parent image
FROM golang:1.16

# Set the working directory in the container
WORKDIR /go/src/github.com/yourusername/yourproject

# Copy the current directory contents into the container at /go/src/github.com/yourusername/yourproject
COPY . /go/src/github.com/yourusername/yourproject

# Install any needed packages specified in go.mod
RUN go mod download

# Build the Go app. This will create an executable called "yourproject" in the current directory
RUN go build -o yourproject

# Make port 80 available to the world outside this container
EXPOSE 80

# Run the command inside the container
CMD ["./yourproject"]
```

### Explanation:
- **Base Image**: The `golang:1.16` image is used as the base image, which includes the Go environment and tools.
- **Working Directory**: The working directory is set to `/go/src/github.com/yourusername/yourproject`.
- **Copy Files**: The current directory contents are copied into the container at the specified working directory.
- **Module Download**: The `go mod download` command installs all the necessary dependencies specified in the `go.mod` file.
- **Build the App**: The `go build -o yourproject` command compiles the Go application, resulting in an executable named `yourproject`.
- **Expose Port**: The container exposes port 80, which you can map to your host machine if needed.
- **Run the App**: The `CMD ["./yourproject"]` command specifies the entrypoint of the container, running the `yourproject` executable.

### Building and Running the Docker Image:
1. **Build the Image**:
   ```sh
   docker build -t yourusername/yourproject .
   ```
   Replace `yourusername` with your Docker Hub username and `yourproject` with the name of your project.

2. **Run the Image**:
   ```sh
   docker run -p 8080:80 yourusername/yourproject
   ```
   This command maps port 8080 on your host machine to port 80 in the container and runs the application.

### Note:
- Replace `yourusername` and `yourproject` with your actual Docker Hub username and project name.
- Ensure you have the necessary permissions to push the image to Docker Hub.
