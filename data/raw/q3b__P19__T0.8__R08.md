Certainly! Below is a simple Dockerfile to create a Docker image for a command-line tool built in Go using Cobra. This Dockerfile assumes that your Go application is structured in a typical Go module format.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine as build-env

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the current directory contents into the container at /go/src/app
COPY . /go/src/app

# Install any needed packages specified in requirements.txt
RUN go mod download

# Build the Go application
RUN CGO_ENABLED=0 go build -o app

# Use an official lightweight base image
FROM alpine:latest

# Set the working directory in the container
WORKDIR /app

# Copy the binary from the build-env to the new image
COPY --from=build-env /go/src/app/app .

# Expose the port that the application runs on
EXPOSE 8080

# Run the application
CMD ["./app"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the `golang:1.17-alpine` image, which is a lightweight Go runtime with Alpine Linux as the base.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory to `/go/src/app`, where your Go code will be compiled.

3. **Copying Source Code**: The `COPY` command copies the current directory contents to the `/go/src/app` directory in the container.

4. **Building the Application**: The `RUN` command runs `go mod download` to download the required dependencies and `go build -o app` to build the application, resulting in an executable named `app`.

5. **Base Image for Production**: The Dockerfile then moves to `alpine:latest`, which is a lightweight Linux distribution.

6. **Final Working Directory**: The `WORKDIR` instruction is set again to `/app` for consistency.

7. **Copying the Binary**: The `COPY --from=build-env` command copies the compiled binary from the build environment to the production image.

8. **Exposing Ports**: The `EXPOSE` instruction specifies that the application listens on port 8080.

9. **Running the Application**: The `CMD` instruction specifies the default command to run when the container starts, which is the binary `./app`.

This Dockerfile can be used to build a container that runs your Go application. Make sure to adjust the port number and any other details as needed for your specific application.
