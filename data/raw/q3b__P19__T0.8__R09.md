Certainly! Below is a basic Dockerfile for a command-line tool built in Go using the Cobra framework. This Dockerfile assumes that your Go application is named `your-app` and is located in the root directory of your project.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . .

# Install any needed packages specified in requirements.txt
RUN go get -u github.com/spf13/cobra@latest

# Build the Go application
RUN go build -o your-app

# Make port 80 available to the world outside this container
EXPOSE 80

# Run your app
CMD ["/usr/src/app/your-app"]
```

### Key Points:
- **Base Image**: The `golang:1.17-alpine` image is used, which is a lightweight Go image based on Alpine Linux.
- **Working Directory**: The `WORKDIR` instruction sets the working directory to `/usr/src/app` where your application will be built and run.
- **Copy Files**: The `COPY` instruction copies all files from the current directory into the container.
- **Install Dependencies**: The `go get` command installs the Cobra library.
- **Build Application**: The `go build` command compiles the Go application into an executable named `your-app`.
- **Expose Port**: The `EXPOSE` instruction makes port 80 available to the outside world.
- **Run Command**: The `CMD` instruction specifies the default command to run when the container starts.

### Building the Docker Image:
To build the Docker image, navigate to the directory containing your `Dockerfile` and run the following command:

```sh
docker build -t your-app .
```

### Running the Docker Container:
To run the Docker container, use the following command:

```sh
docker run -p 80:80 your-app
```

This will run the container and map port 80 on the host to port 80 in the container, allowing you to access your application via `http://localhost:80`.
