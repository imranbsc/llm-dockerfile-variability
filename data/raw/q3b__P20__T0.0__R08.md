Certainly! Below is a Dockerfile for a scheduled batch job built in Go using the `robfig/cron` package. This Dockerfile assumes you have a Go application that uses `robfig/cron` to schedule tasks.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN go get -u github.com/robfig/cron/v3

# Make port 80 available to the world outside this container
EXPOSE 80

# Run the app
CMD ["go", "run", "main.go"]
```

### Explanation:

1. **Base Image**: The `golang:1.17-alpine` image is used as the base image, which is a lightweight version of the Go runtime optimized for Alpine Linux.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`.

3. **Copy Files**: The `COPY` instruction copies the current directory contents into the container at `/app`. This is where your Go application and any dependencies will be stored.

4. **Install Dependencies**: The `RUN` instruction uses `go get` to install the `robfig/cron` package. This is necessary because the package is not included in the base Go image.

5. **Expose Port**: The `EXPOSE` instruction informs Docker that the application listens on port 80, which is the default port for HTTP.

6. **Run Command**: The `CMD` instruction specifies the command to run when the container starts. In this case, it runs the Go application using `go run main.go`.

### Note:
- Ensure that your Go application has a `main.go` file and that it uses `robfig/cron` to schedule tasks.
- You may need to adjust the Go version and other dependencies based on your specific requirements.
