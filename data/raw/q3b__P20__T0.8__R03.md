Certainly! Below is a Dockerfile for a scheduled batch job built in Go using the `robfig/cron` package. This Dockerfile sets up a Go environment, installs the `robfig/cron` package, and defines a simple batch job that runs every minute.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.19

# Set the working directory in the container
WORKDIR /app

# Copy the Go application source code into the container
COPY . /app

# Install the robfig/cron package
RUN go get github.com/robfig/cron/v3

# Install dependencies
RUN go mod download

# Expose the port where the application will listen
EXPOSE 8080

# Define the command to run the batch job
CMD ["go", "run", "main.go"]
```

### Explanation:

1. **Base Image**: The `golang:1.19` image is used as the base image, which contains the Go runtime and tools.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory inside the container to `/app`.

3. **Copy Source Code**: The `COPY . /app` command copies the current directory's contents into the `/app` directory inside the container.

4. **Install robfig/cron**: The `RUN go get github.com/robfig/cron/v3` command installs the `robfig/cron` package.

5. **Install Dependencies**: The `RUN go mod download` command downloads the project's dependencies.

6. **Expose Port**: The `EXPOSE 8080` command specifies that the container listens on port 8080.

7. **Define Command**: The `CMD ["go", "run", "main.go"]` command specifies the command to run the batch job when the container starts. This assumes there is a `main.go` file in the application.

### Running the Container:

To run the container, you can use the following command:

```sh
docker build -t my-go-batch-job .
docker run -d --name my-go-batch-job -p 8080:8080 my-go-batch-job
```

This will build the Docker image and run a container in detached mode (`-d`). The container will listen on port 8080, and the batch job will be executed every minute due to the cron configuration in your Go application.
