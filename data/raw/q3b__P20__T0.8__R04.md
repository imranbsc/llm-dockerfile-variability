```Dockerfile
# Use the official Go image as the base image
FROM golang:1.21-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install dependencies
RUN apk add --no-cache git

# Build the application
RUN CGO_ENABLED=0 go build -o main main.go

# Expose the port your application is listening on
EXPOSE 8080

# Run the application
CMD ["./main"]
```

This Dockerfile sets up a Go application using the official Go image, copies the project files into the container, installs dependencies, builds the application, and exposes the port it listens on. The CMD command runs the application once it's built.
