Certainly! Below is a simple Dockerfile for a scheduled batch job written in Go using `robfig/cron`. This Dockerfile assumes you have a Go program set up to be run by `cron`.

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Build the Go application
RUN CGO_ENABLED=0 go build -o app .

# Use an official lightweight base image
FROM alpine:3.14

# Copy the binary from the builder stage to the final image
COPY --from=builder /app/app /app

# Expose the port your application runs on
EXPOSE 8080

# Define environment variables
ENV APP_ENV=production

# Set the entry point for the application
CMD ["/app/app"]
```

### Explanation:

1. **Builder Stage**:
   - The `golang:1.17-alpine` image is used as the builder stage to compile the Go application.
   - The current directory is set as the working directory in the container.
   - The project files are copied from the host to the container.
   - The Go application is built using `CGO_ENABLED=0` to ensure static linking, and `go build -o app .` compiles the binary.

2. **Final Stage**:
   - The `alpine:3.14` image is used as the final stage.
   - The compiled binary from the builder stage is copied from the builder stage to the final image.
   - The application is exposed on port 8080, which is typically the default port for Go applications.
   - Environment variables are set for the application (in this case, `APP_ENV=production`).
   - The binary is set as the entry point for the application.

### How to Use the Dockerfile:

1. **Build the Image**:
   ```sh
   docker build -t my-scheduled-batch-job .
   ```

2. **Run the Container**:
   ```sh
   docker run -d --name my-running-job -p 8080:8080 my-scheduled-batch-job
   ```

### Scheduling with Cron:

To schedule the job with `cron`, you can use the `cron` utility available in the Alpine image. You can mount a volume to a directory inside the container where your cron job script is located.

1. **Create a Cron Job Script**:
   Create a script named `cronjob.sh` in your project directory:

   ```sh
   #!/bin/bash
   ./app
   ```

2. **Modify the Dockerfile**:
   Add a volume mount to the final stage to allow cron to access the script:

   ```Dockerfile
   FROM alpine:3.14

   COPY --from=builder /app/app /app
   COPY cronjob.sh /cronjob.sh

   EXPOSE 8080

   ENV APP_ENV=production

   CMD ["/cronjob.sh"]
   ```

3. **Build and Run the Container**:
   ```sh
   docker build -t my-scheduled-batch-job .
   docker run -d --name my-running-job -p 8080:8080 my-scheduled-batch-job
   ```

4. **Set Up Cron**:
   Add a cron job to execute the script at the desired time. For example, to run it every minute, add the following line to `/etc/crontabs/root`:

   ```sh
   * * * * * /cronjob.sh
   ```

5. **Restart the Container**:
   If you have the container running, restart it to apply the new cron job:

   ```sh
   docker restart my-running-job
   ```

This setup will run your Go application every minute (or any other schedule you define in the cron job script).
