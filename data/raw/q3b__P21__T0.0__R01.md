Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a PHP environment with Composer and Nginx, and it also includes a command to run Laravel's development server.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary dependencies
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    unzip \
    && docker-php-ext-install zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Laravel dependencies
RUN composer install

# Expose the default port for Laravel
EXPOSE 80

# Run Laravel's development server
CMD ["php", "artisan", "serve", "--host=0.0.0.0"]
```

### How to Use the Dockerfile

1. **Create a Laravel Project**: If you haven't already, create a new Laravel project using Composer:
   ```bash
   composer create-project --prefer-dist laravel/laravel my-laravel-app
   ```

2. **Navigate to the Project Directory**: Change into the directory of your Laravel project:
   ```bash
   cd my-laravel-app
   ```

3. **Build the Docker Image**: Use the Dockerfile to build the image:
   ```bash
   docker build -t my-laravel-app .
   ```

4. **Run the Docker Container**: Start the container and map port 80 to the host:
   ```bash
   docker run -d -p 8080:80 --name my-laravel-container my-laravel-app
   ```

5. **Access the Laravel Application**: Open your web browser and go to `http://localhost:8080` to see your Laravel application running.

This setup provides a basic environment for developing and running a Laravel application using Docker. You can further customize the Dockerfile to suit your specific needs, such as adding additional PHP extensions or configuring Nginx settings.
