Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a PHP environment with Composer and Nginx, and it also includes a volume to persist data.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary dependencies
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    unzip \
    && docker-php-ext-install zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Laravel dependencies
RUN composer install

# Expose the default port for Laravel
EXPOSE 80

# Start Nginx
CMD ["nginx", "-g", "daemon off;"]
```

### Explanation:
- **Base Image**: The `php:7.4-fpm` image is used as the base image, which includes PHP and Nginx.
- **Working Directory**: The `WORKDIR` directive sets the working directory inside the container to `/var/www/html`.
- **Dependencies**: The `apt-get` command installs necessary dependencies for PHP and Nginx, including `libzip-dev` and `zip`.
- **Composer**: Composer is installed using a one-liner script.
- **Laravel Installation**: The `COPY` command copies the current directory contents into the container at `/var/www/html`, and `composer install` installs Laravel dependencies.
- **Port Expose**: The `EXPOSE` directive exposes port 80, which is the default port for Nginx.
- **Command**: The `CMD` directive starts Nginx in the foreground.

### Usage:
1. Save the Dockerfile to a file named `Dockerfile` in your Laravel project directory.
2. Build the Docker image using the command: `docker build -t my-laravel-app .`
3. Run the container using the command: `docker run -d -p 8080:80 --name my-laravel-container my-laravel-app`.

This setup will give you a running Laravel application accessible at `http://localhost:8080` when you run the container.
