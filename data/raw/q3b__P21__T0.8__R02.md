Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a PHP environment with Composer, Nginx, and MySQL for a typical Laravel application.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    libpng-dev \
    zip \
    && docker-php-ext-install zip pdo_mysql

# Set working directory
WORKDIR /var/www/html

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Expose the default port for Laravel
EXPOSE 80

# Define environment variable
ENV APP_ENV=local

# Start Nginx and PHP-FPM
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP 8.1 and a FastCGI server.

2. **Dependencies**: The `apt-get` command installs necessary packages for PHP extensions, such as `zip` and `libpng-dev`, which are required for image processing.

3. **Composer Installation**: The `composer` binary is installed into the container's `/usr/local/bin` directory.

4. **Working Directory**: The container's working directory is set to `/var/www/html`, where the Laravel application code will be stored.

5. **Composer Install**: The `composer install` command installs all project dependencies. The `--no-dev` flag excludes development dependencies, and `--optimize-autoloader` optimizes the autoloader for better performance.

6. **Port Expose**: The container exposes port 80, which is the default port used by Nginx.

7. **Environment Variable**: The `APP_ENV` environment variable is set to `local` to indicate that this is a development environment.

8. **Command**: The `CMD` instruction runs the PHP-FPM service, which is the FastCGI process manager for PHP.

This Dockerfile is a basic setup and can be extended with additional configurations or volumes as needed for your specific application.
