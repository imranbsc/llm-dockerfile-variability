Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a PHP environment with Composer, Nginx, and PHP-FPM to serve your Laravel application.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.0-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary packages
RUN apt-get update && apt-get install -y \
    libzip-dev \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    zip \
    unzip \
    git \
    && apt-get clean && rm -rf /var/lib/apt/lists/*

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install dependencies
RUN composer install

# Copy the .env file if it exists
COPY .env .env

# Expose the default port for Laravel (80)
EXPOSE 80

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Instructions to Use the Dockerfile

1. **Create a Directory for Your Laravel Project**: First, create a directory for your Laravel project and navigate into it.

    ```bash
    mkdir my-laravel-project
    cd my-laravel-project
    ```

2. **Copy the Dockerfile**: Copy the above Dockerfile into the root of your Laravel project directory.

3. **Create a `.env` File**: Copy your Laravel `.env` file into the project directory.

4. **Build and Run the Docker Container**:

    ```bash
    docker build -t my-laravel .
    docker run -d -p 8080:80 --name my-laravel-container my-laravel
    ```

    - `-d`: Run the container in detached mode.
    - `-p 8080:80`: Map port 8080 on the host to port 80 in the container.
    - `--name my-laravel-container`: Name the container `my-laravel-container`.

5. **Access the Application**: You can now access your Laravel application by visiting `http://localhost:8080` in your web browser.

This setup will provide a secure and efficient environment for running your Laravel application using Docker.
