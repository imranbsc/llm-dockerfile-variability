Certainly! Below is a Dockerfile for building a REST API using PHP with Laravel. This Dockerfile sets up a development environment using Composer and NPM to install dependencies.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm-alpine

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install dependencies using Composer
RUN apk add --no-cache curl git
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer
RUN composer install

# Install NPM dependencies
RUN apk add --no-cache npm
RUN npm install

# Expose the default port for Laravel (8000)
EXPOSE 8000

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### How to Use the Dockerfile

1. **Create a `docker-compose.yml` file**: This file is used to define the services and networks for your application. Here's an example of how it might look:

    ```yaml
    version: '3.8'

    services:
      laravel:
        build: .
        volumes:
          - .:/var/www/html
        ports:
          - "8000:8000"
        environment:
          - DB_HOST=db
          - DB_DATABASE=laravel
          - DB_USERNAME=laravel
          - DB_PASSWORD=secret

      db:
        image: mysql:5.7
        volumes:
          - db_data:/var/lib/mysql
        environment:
          - MYSQL_DATABASE=laravel
          - MYSQL_USER=laravel
          - MYSQL_PASSWORD=secret
          - MYSQL_ROOT_PASSWORD=secret

    volumes:
      db_data:
    ```

2. **Build and run the containers**: You can build and run your containers using the following commands:

    ```sh
    docker-compose build
    docker-compose up -d
    ```

3. **Access the API**: You can access your Laravel application by going to `http://localhost:8000` in your web browser.

### Additional Notes

- **Environment Variables**: The Dockerfile uses environment variables to configure the database connection. You can modify these in your `docker-compose.yml` file or pass them directly when running the containers.
- **Volumes**: The `docker-compose.yml` file also mounts the current directory to the container, allowing you to edit your application files directly while developing.
- **PHP Configuration**: Adjustments can be made to the PHP configuration by modifying the `php.ini` file located at `/usr/local/etc/php/php.ini` inside the container.
