Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a basic development environment for Laravel.

```Dockerfile
# Use the official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install

# Expose the port the Laravel application is running on
EXPOSE 8000

# Define environment variable
ENV APP_ENV development

# Start the artisan server
CMD ["php", "artisan", "serve", "--host=0.0.0.0"]
```

### Explanation:
- **FROM php:8.1-fpm**: This line specifies the base image for the container, using the official PHP 8.1 FPM image.
- **WORKDIR /var/www/html**: Sets the working directory inside the container to `/var/www/html`.
- **COPY . /var/www/html**: Copies the current directory contents into the container at `/var/www/html`.
- **RUN composer install**: Installs the dependencies listed in the `composer.json` file.
- **EXPOSE 8000**: Specifies that the container should expose port 8000.
- **ENV APP_ENV development**: Sets the `APP_ENV` environment variable to `development`, which is useful for configuring Laravel development settings.
- **CMD ["php", "artisan", "serve", "--host=0.0.0.0"]**: Specifies the default command to run when the container starts, which is to start the Laravel development server on all network interfaces.

To build and run the Docker image, you can use the following commands:

```sh
# Build the Docker image
docker build -t my-laravel-app .

# Run the Docker container
docker run -d -p 8000:8000 --name my-laravel-container my-laravel-app
```

This will start a Laravel development server running on port 8000 inside the container. You can access the application by navigating to `http://localhost:8000` in your web browser.
