Certainly! Below is a basic Dockerfile for a REST API built in PHP using Laravel.

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install

# Expose the application port
EXPOSE 80

# Run the application
CMD ["php-fpm"]
```

### Explanation:

- **Base Image**: The `FROM php:7.4-fpm` line specifies the base image to use, which is PHP 7.4 with the FPM (FastCGI Process Manager) server.
- **Working Directory**: The `WORKDIR /var/www/html` line sets the working directory inside the container where the application files will be placed.
- **Copy Application Files**: The `COPY . /var/www/html` line copies the contents of the current directory (where the Dockerfile is located) to the `/var/www/html` directory inside the container.
- **Install Dependencies**: The `RUN apt-get update && apt-get install -y libpq-dev && docker-php-ext-install pdo pdo_pgsql` line installs necessary packages for PostgreSQL support and installs the PDO PostgreSQL extension for PHP.
- **Install Composer**: The `RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer` line downloads and installs Composer, the PHP dependency manager.
- **Install Composer Dependencies**: The `RUN composer install` line runs Composer to install project dependencies.
- **Expose Port**: The `EXPOSE 80` line exposes port 80 so that the application can be accessed externally.
- **Run the Application**: The `CMD ["php-fpm"]` line starts the PHP-FPM service to run the Laravel application.

This Dockerfile is a starting point and can be further customized based on your specific requirements, such as adding additional packages or customizing environment variables.
