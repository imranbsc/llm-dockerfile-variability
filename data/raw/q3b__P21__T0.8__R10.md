Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel. This Dockerfile sets up a PHP environment with Composer and Nginx, and it also includes a Laravel application.

```Dockerfile
# Use the official PHP image from the Docker Hub
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary packages
RUN apt-get update && apt-get install -y \
    libzip-dev \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libldap2-dev \
    libpq-dev \
    zlib1g-dev \
    && docker-php-ext-install -j$(nproc) zip pdo_mysql gd mbstring bcmath exif pcntl intl

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the composer.lock and composer.json files to the container
COPY composer.lock composer.json ./

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Copy the rest of the Laravel application to the container
COPY . .

# Set environment variables for Laravel
ENV APP_ENV=local
ENV DB_CONNECTION=mysql
ENV DB_HOST=db
ENV DB_PORT=3306
ENV DB_DATABASE=laravel
ENV DB_USERNAME=laravel
ENV DB_PASSWORD=secret

# Expose the port that Laravel expects for its web server
EXPOSE 80

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP 8.1 and the FPM (FastCGI Process Manager) server.

2. **Working Directory**: The working directory inside the container is set to `/var/www/html`, where the Laravel application will be installed.

3. **Package Installation**: The necessary PHP extensions are installed using `apt-get`, including those required for various database drivers and other functionalities.

4. **Composer Installation**: Composer is installed and then used to install the Laravel dependencies.

5. **Laravel Files**: The `composer.lock` and `composer.json` files are copied to the container, and then Composer installs the dependencies.

6. **Application Copy**: The rest of the Laravel application files are copied from the local machine to the container.

7. **Environment Variables**: Environment variables are set to configure the database connection for Laravel.

8. **Port Exposition**: The container is exposed on port 80, which is the default port for Laravel's web server.

9. **Command Execution**: The PHP-FPM service is started as the default command when the container starts.

This Dockerfile is a basic setup and can be extended with additional configurations as needed, such as adding volumes to persist data, setting up a database, or optimizing the application further.
