Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile assumes you have a Laravel project set up and you want to run it in a Docker container.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    unzip \
    && docker-php-ext-install zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel dependencies
RUN composer install

# Expose the default port for Laravel
EXPOSE 80

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP 8.1 and the FPM (FastCGI Process Manager) server.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/var/www/html`, where your Laravel application will be stored.

3. **Copy Files**: The `COPY` instruction copies the contents of the current directory (where the Dockerfile is located) into the container at `/var/www/html`.

4. **Install Dependencies**: The `apt-get` command installs necessary packages for PHP extensions like `zip` and `unzip`. It also installs Composer, which is used to manage PHP dependencies.

5. **Install Laravel Dependencies**: The `composer install` command installs all the dependencies specified in your `composer.json` file.

6. **Expose Port**: The `EXPOSE` instruction tells Docker that the application listens on port 80, which is the default port for HTTP.

7. **Start PHP-FPM**: The `CMD` instruction starts the PHP-FPM service, which is the FastCGI process manager for PHP.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-laravel-app .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 8080:80 --name my-laravel-container my-laravel-app
   ```

3. **Access the Application**:
   Open a web browser and go to `http://localhost:8080` to access your Laravel application.

This Dockerfile provides a basic setup for running a Laravel application in a Docker container. You can further customize it based on your specific requirements, such as adding environment variables, volumes, or additional configurations.
