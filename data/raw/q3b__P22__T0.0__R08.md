Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile assumes you have a Laravel project set up and you want to run it in a Docker container.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    && docker-php-ext-install zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel dependencies
RUN composer install

# Expose the default port for Laravel
EXPOSE 80

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP-FPM, a web server that can serve PHP applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/var/www/html`, where your Laravel application will be located.

3. **Copy Files**: The `COPY` instruction copies the contents of the current directory (where the Dockerfile is located) into the container at `/var/www/html`.

4. **Install Dependencies**: The `apt-get` command installs necessary packages, including `libzip-dev` and `zip`, which are required for Laravel's Zip functionality. The `docker-php-ext-install` command installs the PHP zip extension.

5. **Install Composer**: Composer is installed using a one-liner script that downloads and runs the Composer installer.

6. **Install Laravel Dependencies**: Laravel dependencies are installed using Composer.

7. **Expose Port**: The `EXPOSE` instruction specifies that the container should listen on port 80, which is the default port for HTTP.

8. **Start PHP-FPM**: The `CMD` instruction starts the PHP-FPM service, which is the web server that will serve your Laravel application.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-laravel-app .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 8080:80 --name my-laravel-container my-laravel-app
   ```

3. **Access the Application**:
   Open a web browser and go to `http://localhost:8080` to see your Laravel application running in the Docker container.
