Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile sets up a basic environment with PHP, Apache, and the necessary dependencies for Laravel.

```Dockerfile
# Use the official PHP runtime as a parent image
FROM php:8.2-apache

# Set the working directory in the container
WORKDIR /var/www/html

# Install additional dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libpq-dev \
    git \
    libzip-dev && \
    docker-php-ext-configure gd --with-freetype && \
    docker-php-ext-install pdo pdo_mysql gd zip && \
    apt-get clean && rm -rf /var/lib/apt/lists/*

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel
RUN composer install

# Expose the default port for Apache
EXPOSE 80

# Start Apache
CMD ["apache2-foreground"]
```

### Explanation:

1. **Base Image**: The `php:8.2-apache` image is used as the base image, which includes PHP 8.2 and Apache 2.4.

2. **Working Directory**: The `WORKDIR` command sets the working directory inside the container to `/var/www/html`, which is the typical document root for Apache.

3. **Dependencies**: The `apt-get install` command installs necessary packages such as `libpng-dev`, `libpq-dev` (for PostgreSQL), `git`, and `libzip-dev`. It also configures the GD library for image processing and installs the required PHP extensions.

4. **Composer Installation**: The `curl` command downloads and installs Composer, which is a dependency manager for PHP.

5. **Laravel Installation**: The `composer install` command installs all the dependencies specified in your `composer.json` file.

6. **Exposed Port**: The `EXPOSE 80` command exposes port 80, which is the default port for HTTP traffic.

7. **CMD Command**: The `CMD ["apache2-foreground"]` command starts Apache and keeps it running.

This Dockerfile can be used to create a container that runs a Laravel application. You can build the container using the following command:

```sh
docker build -t my-laravel-app .
```

And then run it with:

```sh
docker run -d -p 8080:80 my-laravel-app
```

This will start the container and make your Laravel application accessible at `http://localhost:8080`.
