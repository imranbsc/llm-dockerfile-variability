Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile sets up a basic environment with PHP and Apache, and installs necessary dependencies to run a Laravel application.

```Dockerfile
# Use the official PHP image from the Docker Hub
FROM php:8.1-apache

# Set the working directory
WORKDIR /var/www/html

# Install necessary packages
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libjpeg-dev \
    libpq-dev \
    libzip-dev \
    unzip \
    curl \
    git \
    && docker-php-ext-configure gd \
    && docker-php-ext-install gd \
    && docker-php-ext-install pdo pdo_mysql pdo_pgsql mbstring \
    && docker-php-ext-install zip \
    && curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Laravel dependencies
RUN composer install --no-dev

# Run Laravel's built-in server
CMD ["php", "artisan", "serve", "--host=0.0.0.0", "--port=8000"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official PHP image version 8.1 with Apache.
2. **Working Directory**: Sets the working directory to `/var/www/html`, where Laravel will be installed.
3. **Package Installation**: Installs essential PHP extensions and packages such as GD, PDO for MySQL and PostgreSQL, and Zip.
4. **Composer Installation**: Installs Composer globally and copies it to `/usr/local/bin`.
5. **Laravel Copy**: Copies the current directory contents into the container at `/var/www/html`.
6. **Composer Dependencies**: Installs Laravel dependencies using Composer without development dependencies.
7. **Command**: Runs the Laravel development server on port 8000, accessible from all interfaces.

### To Use This Dockerfile:

1. Save the above Dockerfile to a file named `Dockerfile` in the root directory of your Laravel project.
2. Run `docker build -t your-laravel-image-name .` to build the Docker image.
3. Run `docker run -d -p 8000:8000 your-laravel-image-name` to start a container and map port 8000 to the container's port 8000.

This setup provides a basic environment for deploying a Laravel application using Docker. You can further customize the Dockerfile to include additional configurations or volumes as needed.
