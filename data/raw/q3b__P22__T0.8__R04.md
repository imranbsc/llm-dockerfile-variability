```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-apache

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN composer install

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV APP_ENV=local

# Run app
CMD ["php", "artisan", "serve", "--host=0.0.0.0"]
```

This Dockerfile uses the official PHP 8.1 image with Apache as the web server. It sets the working directory and copies the application files into the container. It installs the required PHP dependencies using Composer, configures the environment variable, and sets the port to be exposed and available to the world outside the container. The `CMD` instruction runs the Laravel artisan serve command to start the server.
