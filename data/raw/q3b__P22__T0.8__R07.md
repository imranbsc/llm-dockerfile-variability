Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile assumes you have a Laravel project set up and you want to run it in a Docker container.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zlib1g-dev \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    git \
    && docker-php-ext-install zip gd \
    && docker-php-ext-install pdo_mysql \
    && docker-php-ext-install pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel
RUN composer install

# Run Migrations to create the database schema
RUN php artisan migrate

# Expose the default Laravel port
EXPOSE 80

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:
- **Base Image**: The Dockerfile starts with the official PHP 7.4-FPM image, which includes PHP, a web server, and a FastCGI process manager.
- **Working Directory**: The `WORKDIR` instruction sets the working directory in the container to `/var/www/html`, where the Laravel application will be placed.
- **Copying Files**: The `COPY` instruction copies the entire contents of the current directory to the `/var/www/html` directory inside the container.
- **Installing Dependencies**: The `apt-get` commands install necessary PHP extensions and libraries such as `zip`, `gd`, `pdo_mysql`, and `pdo_pgsql`.
- **Composer Installation**: The Dockerfile downloads and installs Composer, Laravel's dependency manager.
- **Laravel Installation**: The `composer install` command installs all dependencies specified in the `composer.json` file.
- **Database Migrations**: The `php artisan migrate` command runs Laravel's migration commands to create the database schema.
- **Port Exposing**: The `EXPOSE` instruction tells Docker that the container should expose port 80, which is the default port for web servers.
- **Starting PHP-FPM**: The `CMD` instruction starts the PHP-FPM service, which is responsible for processing PHP requests.

### Usage:
1. Create a `docker-compose.yml` file in your Laravel project root to manage multiple containers if needed.
2. Build the Docker image by running `docker build -t my-laravel-app .` in the same directory as your `Dockerfile`.
3. Run the container with `docker run -p 8080:80 -d my-laravel-app`.
4. Access your Laravel application at `http://localhost:8080` in your web browser.
