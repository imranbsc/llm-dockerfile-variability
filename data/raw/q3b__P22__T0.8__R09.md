Certainly! Below is a basic Dockerfile for a server-rendered PHP application built with Laravel and Blade. This Dockerfile assumes you have a Laravel project set up.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in composer.json
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libxml2-dev \
    zip \
    unzip \
    git \
    curl \
    libpq-dev \
    && docker-php-ext-configure gd --with-freetype --with-png --with-jpeg \
    && docker-php-ext-install gd \
    && docker-php-ext-install pdo_mysql \
    && docker-php-ext-install pdo_pgsql \
    && docker-php-ext-install zip \
    && docker-php-ext-install xml \
    && docker-php-ext-install intl \
    && docker-php-ext-install mbstring \
    && docker-php-ext-install bcmath \
    && docker-php-ext-install opcache \
    && docker-php-ext-install xdebug

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Run Composer install
RUN composer install

# Expose the port that your application runs on
EXPOSE 80

# Define environment variables
ENV APP_ENV=local

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP with the FastCGI Process Manager (FPM) for running PHP applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/var/www/html`, which is the default root directory for Laravel applications.

3. **Copy Files**: The `COPY` command copies all files from the current directory to the container at `/var/www/html`.

4. **Install Extensions**: The `RUN` command installs necessary PHP extensions using `apt-get`. This includes GD for image processing, PDO for database connectivity, and various extensions like mbstring, intl, and xdebug for additional functionality.

5. **Install Composer**: Composer is installed using a `curl` command, and then it's run to install the dependencies defined in the `composer.json` file.

6. **Expose Port**: The `EXPOSE` command informs Docker that the application listens on port 80.

7. **Environment Variable**: The `ENV` command sets the `APP_ENV` variable to `local`, which is useful for configuring Laravel settings.

8. **Start FPM**: The `CMD` instruction starts the PHP-FPM service, which is the PHP web server.

This Dockerfile provides a solid foundation for deploying a Laravel application using PHP-FPM. You can customize it further based on your specific needs, such as adding additional PHP extensions or configurations.
