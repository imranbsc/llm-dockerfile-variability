Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade. This Dockerfile assumes you have a basic understanding of Docker and Laravel.

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    libpng-dev \
    zlib1g-dev \
    libpq-dev \
    && docker-php-ext-install zip \
    && docker-php-ext-install pdo \
    && docker-php-ext-install pdo_pgsql \
    && docker-php-ext-install mbstring \
    && docker-php-ext-install exif \
    && docker-php-ext-install gd \
    && docker-php-ext-install bcmath

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install --no-dev

# Expose port 80
EXPOSE 80

# Start the PHP-FPM server
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `FROM php:7.4-fpm` line specifies the base image for the container. This is a production-ready PHP 7.4 FPM image.

2. **Working Directory**: The `WORKDIR /var/www/html` sets the working directory in the container to `/var/www/html`, which is the default directory where Laravel projects are typically set up.

3. **Copy Files**: The `COPY . /var/www/html` line copies the contents of the current directory (your project) into the container at the specified working directory.

4. **Install Dependencies**: The `RUN` commands install necessary PHP extensions and dependencies using `apt-get`. This includes `zip`, `png`, `zlib`, `pgsql`, `gd`, `bcmath`, and `exif`. It also installs Composer and installs the project dependencies using Composer.

5. **Expose Port**: The `EXPOSE 80` line makes port 80 available to the container, which is the default port for HTTP traffic.

6. **Start FPM**: The `CMD ["php-fpm"]` line runs the PHP-FPM service, which is responsible for serving static files and executing PHP scripts.

This Dockerfile is a basic setup and can be expanded with additional configurations, such as environment variables for database connection details, or additional services like Nginx for serving static files.
