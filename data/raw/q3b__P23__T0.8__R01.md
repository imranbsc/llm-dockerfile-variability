Here's a simple Dockerfile for a Laravel application with a background worker using Supervisor:

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install

# Create a directory for the queue database
RUN mkdir -p storage/framework/queues

# Copy Supervisor configuration
COPY supervisord.conf /etc/supervisor/conf.d/supervisord.conf

# Copy the run script
COPY run.sh /run.sh

# Make the run script executable
RUN chmod +x /run.sh

# Define environment variables
ENV DB_HOST db
ENV DB_DATABASE your_database
ENV DB_USERNAME your_username
ENV DB_PASSWORD your_password

# Expose the default port
EXPOSE 80

# Start Supervisor
CMD ["supervisord", "-c", "/etc/supervisor/conf.d/supervisord.conf"]
```

And here's the `supervisord.conf` file:

```ini
[program:laravel-worker]
command=php artisan queue:work --daemon
autorestart=true
stdout_logfile=/var/log/laravel-worker.log
stderr_logfile=/var/log/laravel-worker.err.log
```

And the `run.sh` script to start the Laravel queue worker:

```bash
#!/bin/bash

# Start the Laravel queue worker
php artisan queue:work --daemon
```

To build and run this Docker image, you would typically use the following commands:

```bash
docker build -t laravel-worker .
docker run --rm -v /path/to/your/project:/var/www/html -p 80:80 --name laravel-worker laravel-worker
```

Make sure to replace `/path/to/your/project` with the path to your Laravel project on your host machine, and adjust the environment variables (`DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`) according to your database configuration.
