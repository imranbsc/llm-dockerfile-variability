Certainly! Below is a Dockerfile for a background worker built in PHP using Laravel queues. This Dockerfile assumes you are using the official PHP image from Docker Hub and installs Laravel and its dependencies.

```Dockerfile
# Use the official PHP image from Docker Hub
FROM php:8.1-fpm

# Install necessary packages
RUN apt-get update && apt-get install -y \
    libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
WORKDIR /var/www/html

# Copy the project into the container
COPY . /var/www/html

# Install project dependencies
RUN composer install --no-dev

# Set environment variables
ENV APP_ENV=production
ENV QUEUE_CONNECTION=database
ENV QUEUE_DISPATCH_LIMIT=500
ENV QUEUE_TTL=60

# Define environment variable for database connection
ENV DB_CONNECTION=mysql
ENV DB_HOST=database
ENV DB_PORT=3306
ENV DB_DATABASE=laravel_queue
ENV DB_USERNAME=your_database_user
ENV DB_PASSWORD=your_database_password

# Define environment variable for mail configuration
ENV MAIL_HOST=smtp.example.com
ENV MAIL_PORT=587
ENV MAIL_USERNAME=your_email@example.com
ENV MAIL_PASSWORD=your_email_password
ENV MAIL_ENCRYPTION=tls

# Expose port 9000 for the FPM server
EXPOSE 9000

# Start the FPM server
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The image `php:8.1-fpm` is used as the base image, which includes the PHP-FPM server.
2. **Dependencies**: Packages like `libpq-dev` are installed to support PostgreSQL databases. `pdo_pgsql` is the PHP extension for PostgreSQL.
3. **Composer**: Composer is installed to manage project dependencies.
4. **Working Directory**: The directory `/var/www/html` is set as the working directory.
5. **Project Copy**: The project files are copied into the container.
6. **Dependencies Install**: Composer is used to install the project dependencies.
7. **Environment Variables**: Environment variables are set for Laravel, such as database connection, queue configuration, and mail settings.
8. **Port Expose**: The container exposes port 9000, which is the default port for PHP-FPM.
9. **Command**: The `php-fpm` command is run to start the FPM server.

### Usage:

- Build the Docker image:
  ```sh
  docker build -t my-laravel-worker .
  ```
- Run the container:
  ```sh
  docker run -d --name my-laravel-worker my-laravel-worker
  ```

Make sure to replace placeholders like `your_database_user`, `your_database_password`, `your_email@example.com`, and `smtp.example.com` with your actual database credentials and email settings.
