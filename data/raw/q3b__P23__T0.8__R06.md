Here is a Dockerfile for a background worker built in PHP using Laravel queues. This Dockerfile sets up a PHP environment with Composer, Nginx, and PHP-FPM to handle incoming requests and process Laravel queues.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install dependencies
RUN apt-get update && apt-get install -y \
    curl \
    libzip-dev \
    libpng-dev \
    zlib1g-dev \
    git \
    libpq-dev \
    libxml2-dev \
    && docker-php-ext-install zip gd xml

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Run Composer install
RUN composer install --no-dev --prefer-dist

# Copy the database configuration file to the container
COPY .env /var/www/html/.env

# Create a symbolic link for the database
RUN ln -s /var/www/html/storage/database.sqlite /var/www/html/database.sqlite

# Expose the default PHP port
EXPOSE 9000

# Start PHP-FPM
CMD ["php-fpm"]
```

### Explanation:

- **Parent Image**: The `php:7.4-fpm` image is used as the base, which includes PHP-FPM and other necessary PHP extensions for web development.
- **Working Directory**: The `WORKDIR` directive sets the working directory for subsequent commands in the Dockerfile.
- **Dependencies**: The `apt-get` command installs various development packages required for building PHP extensions and running Nginx.
- **Composer**: Composer is installed to handle PHP package management.
- **Copy Files**: The current directory contents are copied into the container, replacing the existing files in the `/var/www/html` directory.
- **Composer Install**: Composer is run with `--no-dev` to exclude development dependencies and `--prefer-dist` to download dependencies from the Composer repository.
- **Environment File**: The `.env` file is copied to the container.
- **Symbolic Link**: A symbolic link is created for the SQLite database file to allow persistent storage.
- **Exposing Ports**: The `EXPOSE` directive specifies that port 9000 is exposed for PHP-FPM.
- **CMD**: The default command to run when the container starts, which is to start PHP-FPM.
