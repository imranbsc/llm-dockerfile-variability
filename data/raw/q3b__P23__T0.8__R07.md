Certainly! Below is a Dockerfile for a background worker built in PHP using Laravel queues. This Dockerfile sets up a Laravel application with a worker that listens for messages on a queue, such as Redis.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm-alpine

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apk add --no-cache \
    curl \
    git \
    zip \
    libpng-dev \
    libxml2-dev \
    libpq-dev \
    redis \
    && docker-php-ext-install pdo_mysql \
    && docker-php-ext-install pdo_pgsql \
    && docker-php-ext-install gd \
    && docker-php-ext-install bcmath \
    && docker-php-ext-install mbstring \
    && docker-php-ext-install zip \
    && curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel
RUN composer create-project --prefer-dist laravel/laravel .

# Install dependencies
RUN composer install --no-dev

# Copy Laravel .env file if it exists
COPY .env.example .env

# Copy and compile assets (if necessary)
# RUN php artisan config:cache
# RUN php artisan view:clear
# RUN php artisan route:clear
# RUN php artisan optimize

# Expose the default port for Laravel
EXPOSE 80

# Define environment variable for Redis host
ENV REDIS_HOST redis

# Start the worker
CMD ["php", "artisan", "queue:work", "--tries=3"]
```

### Explanation:
- **Base Image**: The `php:8.1-fpm-alpine` image is used as the base image, which includes PHP 8.1 and a lightweight Alpine Linux environment.
- **Working Directory**: The `/var/www/html` directory is set as the working directory where the Laravel application will be installed.
- **Dependencies**: The necessary PHP extensions are installed using `apk add`.
- **Composer Installation**: Laravel is installed using Composer, and dependencies are installed.
- **Environment Variables**: The `REDIS_HOST` environment variable is set to the Redis server's hostname, which is useful for the Laravel queue driver.
- **Exposed Port**: The container exposes port 80, which is the default port for Laravel.
- **Worker Command**: The `CMD` directive runs the Laravel queue worker with the `--tries=3` option, which means the worker will try to retry a failed job three times before giving up.

This Dockerfile is a basic setup for a Laravel queue worker. You may need to adjust it based on your specific requirements, such as additional environment variables, configurations, or dependencies.
