Certainly! Below is a basic Dockerfile for a background worker built in PHP using Laravel queues. This Dockerfile assumes you have a Laravel application set up and a RabbitMQ server configured.

```Dockerfile
# Use the official PHP runtime as the parent image
FROM php:8.1-fpm

# Install necessary packages
RUN apt-get update && apt-get install -y \
    libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install

# Copy Laravel configuration file
COPY .env.example .env

# Configure PHP settings
RUN php artisan key:generate

# Create a directory for the queue
RUN mkdir -p storage/framework/queues

# Expose the default PHP port
EXPOSE 9000

# Run artisan queue:work command to start the queue worker
CMD ["php", "artisan", "queue:work", "--queue=laravel"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which is a PHP FastCGI Process Manager.

2. **Dependencies**: `libpq-dev` is installed for PostgreSQL support, and `docker-php-ext-install pdo pdo_pgsql` adds the PostgreSQL PDO extension.

3. **Working Directory**: The container's working directory is set to `/var/www/html`.

4. **Copy Files**: The application files are copied into the container at the `/var/www/html` directory.

5. **Composer Installation**: Composer is installed to manage dependencies.

6. **Composer Install**: Dependencies are installed using Composer.

7. **Environment File**: A copy of the `.env.example` file is copied to `.env` to configure Laravel.

8. **Key Generation**: The Laravel application's key is generated to ensure security.

9. **Queue Directory**: A directory for the queue is created at `storage/framework/queues`.

10. **Port Exposition**: The default PHP port (9000) is exposed.

11. **Queue Worker Command**: The `php artisan queue:work --queue=laravel` command is used to start the Laravel queue worker.

### Usage:

1. Build the Docker image:
   ```sh
   docker build -t laravel-queue-worker .
   ```

2. Run the Docker container:
   ```sh
   docker run -d --name laravel-queue-worker -p 9000:9000 laravel-queue-worker
   ```

### Notes:

- Ensure that RabbitMQ is running and accessible from the container. You can use Docker's network features to link the containers if necessary.
- Adjust the `COMPOSER_MEMORY_LIMIT` and other environment variables as needed based on your application's requirements.
- Consider using a volume mount for the application's directory to persist data between container restarts.
