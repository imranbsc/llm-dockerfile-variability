Certainly! Below is a Dockerfile for a background worker built in PHP using Laravel queues. This Dockerfile sets up a basic environment for running a Laravel application with a worker process.

```Dockerfile
# Use the official PHP image as the base image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install dependencies
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    && docker-php-ext-install zip

# Install composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel dependencies
RUN composer install

# Expose the default PHP FPM port
EXPOSE 9000

# Set environment variables for Laravel
ENV APP_KEY=your-secret-key
ENV QUEUE_CONNECTION=redis

# Run the Laravel worker command
CMD ["php", "artisan", "queue:work"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official PHP 8.1-FPM image, which is a lightweight PHP runtime optimized for web servers.

2. **Working Directory**: The working directory is set to `/var/www/html`, where your Laravel application will be stored.

3. **Copy Files**: The current directory contents are copied into the container at `/var/www/html`. This allows you to mount your Laravel application code into the container.

4. **Install Dependencies**: The `apt-get` command installs necessary packages, including `libzip-dev` and `zip`, which are required for Laravel's `zip` feature.

5. **Install Composer**: Composer is installed to manage PHP dependencies.

6. **Install Laravel Dependencies**: Composer installs Laravel dependencies from your `composer.json` file.

7. **Expose Port**: The container exposes port 9000, which is the default port used by PHP-FPM.

8. **Environment Variables**: Two environment variables are set:
   - `APP_KEY`: This is the secret key for Laravel encryption.
   - `QUEUE_CONNECTION`: This specifies the queue connection used by Laravel.

9. **Run Command**: The `CMD` instruction runs the Laravel worker command, which starts a worker process to process queued jobs.

### Running the Container

To run this container, you can use the following commands:

```sh
docker build -t laravel-worker .
docker run -d --name laravel-worker -v /path/to/your/laravel-app:/var/www/html laravel-worker
```

Replace `/path/to/your/laravel-app` with the path to your Laravel application directory on your host machine.

### Additional Configuration

- **Redis**: If you want to use Redis as the queue driver, you need to install Redis and configure it in your Laravel application.
- **Environment**: You can further customize the environment by setting more variables, such as database connection settings, Redis host, etc., in the `ENV` directive or by mounting a configuration file.
- **Networking**: If your application requires a database or other services, you might need to expose additional ports or configure network settings.
