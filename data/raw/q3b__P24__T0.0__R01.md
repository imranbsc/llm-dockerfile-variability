Certainly! Below is a Dockerfile for a command-line tool built in PHP using Symfony Console. This Dockerfile sets up a PHP environment with Symfony Console and installs the necessary dependencies.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN composer install

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV APP_ENV=production

# Run the application
CMD ["php", "bin/console", "app:run"]
```

### Explanation:

1. **Base Image**: The `FROM php:7.4-cli` line specifies the base image to use, which is a PHP CLI image with version 7.4.

2. **Working Directory**: The `WORKDIR /app` sets the working directory inside the container to `/app`.

3. **Copy Files**: The `COPY . /app` line copies all files from the current directory to the `/app` directory inside the container.

4. **Install Dependencies**: The `RUN composer install` command installs all dependencies specified in the `composer.json` file.

5. **Expose Port**: The `EXPOSE 80` line makes port 80 available to the world outside this container.

6. **Environment Variable**: The `ENV APP_ENV=production` line sets the environment variable `APP_ENV` to `production`.

7. **Run Command**: The `CMD ["php", "bin/console", "app:run"]` line specifies the command to run when the container starts. This assumes you have a Symfony Console application with a command named `app:run`.

### Usage:

To build and run this Docker image, follow these steps:

1. Save the Dockerfile to a directory.
2. Navigate to that directory in your terminal.
3. Run the following commands:

   ```sh
   docker build -t my-php-symfony-app .
   docker run -p 8080:80 my-php-symfony-app
   ```

This will build the Docker image and run it, mapping port 8080 on your host to port 80 in the container. You can then access your application by visiting `http://localhost:8080` in your web browser.
