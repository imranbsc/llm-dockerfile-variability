Certainly! Below is a Dockerfile for a command-line tool built in PHP using Symfony Console. This Dockerfile sets up a PHP environment with Symfony Console and includes a simple command-line script.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN composer install

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.php when the container launches
CMD ["php", "app.php"]
```

### Explanation:

1. **Base Image**: The `FROM php:7.4-cli` line specifies the base image to use, which is a PHP 7.4 command-line interpreter.

2. **Working Directory**: The `WORKDIR /app` sets the working directory inside the container to `/app`.

3. **Copy Files**: The `COPY . /app` line copies all files from the current directory to the `/app` directory inside the container.

4. **Install Composer Dependencies**: The `RUN composer install` command installs all dependencies listed in the `composer.json` file.

5. **Expose Port**: The `EXPOSE 80` line makes port 80 available to the world outside this container.

6. **Environment Variable**: The `ENV NAME World` line sets an environment variable named `NAME` with a default value of `World`.

7. **Command to Run**: The `CMD ["php", "app.php"]` line specifies the command to run when the container starts, which is to execute the `app.php` script using PHP.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t my-php-symfony-app .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -it --rm my-php-symfony-app
   ```

This setup will create a Docker container with a PHP environment, install Symfony Console, and run the `app.php` script when the container starts. You can modify the `app.php` script to include your command-line logic.
