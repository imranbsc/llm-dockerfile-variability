Certainly! Below is a Dockerfile for building a PHP command-line tool using Symfony Console.

```Dockerfile
# Use the official PHP runtime image from Docker Hub
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    build-essential \
    libpng-dev \
    libzip-dev \
    zip \
    unzip \
    && docker-php-ext-install pdo_mysql pdo

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Run Composer to install dependencies
RUN composer install

# Copy the entrypoint script to the container
COPY entrypoint.sh /usr/local/bin/

# Make the entrypoint script executable
RUN chmod +x /usr/local/bin/entrypoint.sh

# Define environment variable
ENV APP_ENV production

# Make port 9000 available to the world outside this container
EXPOSE 9000

# Run the entrypoint script
ENTRYPOINT ["./entrypoint.sh"]
```

### Explanation:

- **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes PHP and a FPM (FastCGI Process Manager) server.
- **Working Directory**: The `WORKDIR` instruction sets the working directory to `/var/www/html`.
- **Copying Files**: The `COPY` command copies the current directory contents into the container at `/var/www/html`.
- **Installing Dependencies**: `apt-get` is used to install necessary packages for building and running the application.
- **Composer Installation**: Composer is installed and used to install project dependencies.
- **Entrypoint Script**: A simple script `entrypoint.sh` is copied to the container. This script can be used to configure the application or start the server.
- **Environment Variable**: The `APP_ENV` environment variable is set to `production` to indicate the environment.
- **Exposing Port**: Port `9000` is exposed to allow access to the application.
- **Running the Entrypoint Script**: The entrypoint script is executed when the container starts.

### `entrypoint.sh`:

```sh
#!/bin/sh

# Check if the app_env environment variable is set
if [ -n "$APP_ENV" ]; then
    echo "Running in $APP_ENV environment"
else
    echo "Running in development environment"
    echo "Setting APP_ENV to development"
    export APP_ENV=development
fi

# Run the Symfony console command
php bin/console
```

This `entrypoint.sh` script sets the environment variable and then runs the Symfony console command. You can modify this script to include additional setup or logic as needed.
