Certainly! Below is a Dockerfile for a command-line tool built in PHP using Symfony Console. This Dockerfile sets up a PHP environment with Symfony Console and installs your application dependencies.

```Dockerfile
# Use the official PHP image as the base image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install dependencies using Composer
RUN apt-get update && apt-get install -y \
    libzip-dev \
    libpng-dev \
    libfreetype6-dev \
    libjpeg-dev \
    libwebp-dev \
    libpq-dev \
    libxml2-dev \
    unzip \
    git && \
    docker-php-ext-configure zip && \
    docker-php-ext-configure gd && \
    docker-php-ext-configure pdo_pgsql && \
    docker-php-ext-install zip gd pdo_pgsql && \
    pecl install -y xdebug && \
    docker-php-ext-enable xdebug && \
    rm -rf /var/lib/apt/lists/*

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install application dependencies
RUN composer install

# Run the application
CMD ["php", "bin/console"]
```

### Explanation:

- **Base Image**: `php:7.4-fpm` is used as the base image, which provides a PHP environment with FPM (FastCGI Process Manager).
- **Working Directory**: `WORKDIR /var/www/html` sets the directory where your application code will be stored.
- **Dependencies**: The necessary PHP extensions are installed using `apt-get`. Additional extensions like `gd` for image processing, `pdo_pgsql` for PostgreSQL, and `xdebug` for debugging are also installed.
- **Composer Installation**: Composer is downloaded and installed in `/usr/local/bin` and used to install project dependencies.
- **Application Code Copy**: The current directory contents are copied into the container at `/var/www/html`.
- **Command**: The `CMD ["php", "bin/console"]` sets the default command to run the application's console commands.

### Usage:

1. Save the Dockerfile in your project directory.
2. Navigate to the directory containing the Dockerfile.
3. Run `docker build -t my-app .` to build the Docker image.
4. Run `docker run -it --rm my-app` to start the container and run the application.

### Notes:

- Ensure that your application has a `composer.json` file with the correct dependencies.
- You may need to adjust the PHP version or additional dependencies based on your project's requirements.
