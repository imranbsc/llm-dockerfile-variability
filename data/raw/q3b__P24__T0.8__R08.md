Certainly! Below is a simple Dockerfile to create a Docker image for a command-line tool built in PHP using Symfony Console.

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN composer install --no-dev

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV APP_ENV=production

# Run app.php when the container launches
CMD ["php", "app.php"]
```

### Explanation:

1. **FROM php:7.4-cli**: This line specifies the base image for the Docker container. In this case, it uses the official PHP 7.4 command-line interface image.

2. **WORKDIR /app**: This sets the working directory inside the container to `/app`. This is where the code will be copied and executed.

3. **COPY . /app**: This copies all the files from the current directory (the directory containing your Dockerfile) to the `/app` directory inside the container.

4. **RUN composer install --no-dev**: This installs all the dependencies specified in your `composer.json` file. The `--no-dev` flag ensures that only the production dependencies are installed.

5. **EXPOSE 80**: This exposes port 80 on the container so that it can be accessed from the host.

6. **ENV APP_ENV=production**: This sets an environment variable for your application to use. You can change `production` to `development` or another environment as needed.

7. **CMD ["php", "app.php"]**: This specifies the command to run when the container starts. In this case, it runs the `app.php` file using PHP.

To build and run this Docker image, follow these steps:

1. Save the Dockerfile in a directory where your PHP application code is located.
2. Run the following commands in the directory containing the Dockerfile:

   ```bash
   docker build -t your-image-name .
   docker run -p 8080:80 your-image-name
   ```

This will build the Docker image and run it, making your command-line tool available on `http://localhost:8080`.
