Certainly! Below is a basic Dockerfile for a command-line tool built in PHP using Symfony Console.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli-alpine

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in composer.json
RUN apk add --no-cache --virtual .build-deps \
        git && \
    apk add --no-cache \
        composer && \
    composer install && \
    apk del .build-deps

# Run the application
CMD ["php", "bin/console", "your-command"]
```

### Explanation:
- **FROM php:7.4-cli-alpine**: Uses the official PHP 7.4 command-line image with Alpine Linux as the base.
- **WORKDIR /app**: Sets the working directory for the container.
- **COPY . /app**: Copies all files from the current directory to `/app` in the container.
- **RUN apk add --no-cache --virtual .build-deps git && apk add --no-cache composer && composer install && apk del .build-deps**: Installs necessary dependencies and runs Composer to install project dependencies. The `--no-cache` flag helps ensure the image is smaller and more efficient.
- **CMD ["php", "bin/console", "your-command"]**: Specifies the command to run when the container starts. Replace `"your-command"` with the actual command you want to execute.

### Notes:
- Ensure that your PHP project has a `composer.json` file in the root directory of the project.
- Replace `"your-command"` with the actual command you want to run when the container starts.
- You can further customize this Dockerfile by adding more dependencies, setting environment variables, or configuring services like a web server or database client.
