Certainly! Below is a Dockerfile for a command-line tool built in PHP using Symfony Console. This Dockerfile assumes you have a basic PHP environment set up and that your project is structured as a Symfony Console application.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . /usr/src/app

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y --no-cache \
    git \
    curl \
    libzip-dev \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libpq-dev \
    libxml2-dev \
    libcurl4-openssl-dev

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV APP_ENV=prod

# Run your application
CMD ["php", "bin/console"]
```

### Explanation:

- **Base Image**: The `php:7.4-cli` image is used as the base image, which includes a PHP CLI environment.
- **Working Directory**: The `WORKDIR` directive sets the working directory inside the container to `/usr/src/app`.
- **Copy Files**: The `COPY` directive copies the current directory contents into the container at `/usr/src/app`.
- **Package Installation**: The `RUN` directive installs necessary packages for PHP extensions and dependencies using `apt-get`.
- **Composer Installation**: Composer is installed by downloading and running the installer.
- **Dependency Installation**: `composer install` installs all dependencies specified in `composer.json`.
- **Port Expose**: The `EXPOSE` directive makes port 80 available to the world outside this container.
- **Environment Variable**: An environment variable `APP_ENV` is set to `prod` for production.
- **Command**: The `CMD` directive specifies the command to run the application, which is `php bin/console`.

This Dockerfile is a basic setup and can be expanded with additional configurations or specific requirements based on your project.
