Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using Laravel's task scheduler. This Dockerfile assumes you have a Laravel application set up and you want to run a scheduled task.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    && docker-php-ext-install zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel dependencies
RUN composer install

# Copy the .env file to the container
COPY .env.example .env

# Copy the database configuration file to the container
COPY .env.database.example .env.database

# Copy the database dump file to the container
COPY database.sql database.sql

# Run the database migrations
RUN php artisan migrate

# Expose the default port for Laravel
EXPOSE 80

# Run the Laravel development server
CMD ["php", "artisan", "serve", "--host=0.0.0.0"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official PHP 7.4 FPM image, which is a lightweight and efficient environment for running PHP applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/var/www/html`, where your Laravel application will be located.

3. **Copy Files**: The `COPY` instructions copy the current directory contents into the container at `/var/www/html`. This includes your Laravel application files, `.env` files, and any other necessary configuration files.

4. **Install Dependencies**: The `apt-get` command installs necessary packages such as `libzip-dev` and `zip`, which are required for Laravel's `zip` functionality. The `docker-php-ext-install` command installs the PHP zip extension.

5. **Install Composer**: Composer is installed to manage PHP dependencies.

6. **Install Laravel Dependencies**: Laravel dependencies are installed using Composer.

7. **Copy Environment Files**: The `.env.example` and `.env.database.example` files are copied to the container, which are used to configure the application.

8. **Database Setup**: The `database.sql` file is copied to the container and used to set up the database.

9. **Run Migrations**: The `php artisan migrate` command runs the database migrations to set up the database schema.

10. **Expose Port**: The `EXPOSE` instruction exposes port 80, which is the default port for Laravel's development server.

11. **Run Development Server**: The `CMD` instruction runs the Laravel development server, making it accessible on the host machine.

This Dockerfile is a basic setup and can be extended with additional configurations as needed, such as setting environment variables, mounting volumes, or adding more services.
