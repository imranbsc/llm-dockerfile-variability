To create a Dockerfile for a scheduled batch job built in PHP using Laravel, you can use the official PHP image as the base. Below is a simple Dockerfile that sets up a Laravel application with a scheduled task.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install any needed packages specified in requirements.txt
COPY composer.lock composer.json /var/www/html/
RUN composer install --no-dev

# Copy the rest of the application code
COPY . /var/www/html

# Install additional dependencies
RUN apt-get update && apt-get install -y --no-install-recommends \
    cron \
    && rm -rf /var/lib/apt/lists/*

# Copy the cron script to the container
COPY cron.sh /etc/cron.d/cronjob

# Configure cron to run the job at the specified interval
RUN crontab -e
# Add your cron job here, e.g., */5 * * * * /usr/bin/php /var/www/html/artisan schedule:run

# Expose the default PHP port
EXPOSE 9000

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm` image is used as the base image, which includes the PHP runtime and the PHP-FPM service.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory for the subsequent instructions in the Dockerfile.

3. **Composer Installation**: The `composer.lock` and `composer.json` files are copied to the container, and `composer install --no-dev` is run to install the application dependencies.

4. **Application Files**: The rest of the application code is copied into the container.

5. **Cron Setup**: The `cron.sh` script is copied to `/etc/cron.d/cronjob`, which contains the cron job to run the Laravel task scheduler. You need to replace `*/5 * * * * /usr/bin/php /var/www/html/artisan schedule:run` with your specific cron job.

6. **Cron Configuration**: The `crontab -e` command opens the crontab for editing, and you need to add your cron job here.

7. **Port Exposure**: The `EXPOSE` instruction specifies that the container will listen on port 9000, which is the default port for PHP-FPM.

8. **CMD**: The `CMD` instruction starts the PHP-FPM service.

### Usage:

- Build the Docker image:
  ```bash
  docker build -t my-laravel-job .
  ```

- Run the Docker container:
  ```bash
  docker run -d --name my-laravel-job -v /path/to/your/laravel/app:/var/www/html my-laravel-job
  ```

Make sure to replace `/path/to/your/laravel/app` with the actual path to your Laravel application on the host machine.
