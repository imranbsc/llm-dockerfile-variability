Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using Laravel's task scheduler. This Dockerfile assumes you have a basic Laravel application set up.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm-alpine

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apk update && \
    apk add --no-cache \
        postgresql-client \
        libpq \
        curl \
        git \
        zip \
        unzip \
        && docker-php-ext-install pdo pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install --no-dev

# Install Laravel scheduler
RUN php artisan schedule:install

# Copy the cron file to the container
COPY cron/cron.php /etc/cron.d/laravel
RUN chmod 0644 /etc/cron.d/laravel

# Set the cron to run every minute
RUN crontab /etc/cron.d/laravel

# Expose the port that Laravel is listening on
EXPOSE 9000

# Start the PHP-FPM service
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The `php:8.1-fpm-alpine` image is used as the base image, which includes PHP and its FPM (FastCGI Process Manager).

2. **Working Directory**: The `WORKDIR` directive sets the working directory inside the container to `/var/www/html`.

3. **Copy Files**: The `COPY . /var/www/html` command copies all files from the local directory to the container's working directory.

4. **Install Dependencies**: The `apk update` and `apk add` commands install necessary packages for PostgreSQL, cURL, Git, and other dependencies.

5. **Install Composer**: Composer is installed by downloading the installer and running it.

6. **Install Laravel Dependencies**: Laravel dependencies are installed using Composer.

7. **Install Laravel Scheduler**: The `php artisan schedule:install` command creates the necessary files for Laravel's task scheduler.

8. **Cron Configuration**: The `cron/cron.php` file is copied to `/etc/cron.d/laravel`, and the `chmod` command ensures it has the correct permissions. The `crontab` command sets the cron to run every minute.

9. **Expose Port**: The `EXPOSE` directive specifies that the container listens on port 9000.

10. **Start PHP-FPM**: The `CMD ["php-fpm"]` command starts the PHP-FPM service.
