Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using Laravel, leveraging the Laravel task scheduler. This Dockerfile includes PHP, Composer, Nginx, and Supervisor to manage the batch job.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary PHP extensions
RUN apt-get update && apt-get install -y \
    libzip-dev \
    zip \
    && docker-php-ext-install zip \
    && docker-php-ext-install pdo pdo_mysql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Run Composer install
RUN composer install

# Copy the Nginx configuration file to the container
COPY nginx/default.conf /etc/nginx/sites-available/default

# Copy the Supervisor configuration file to the container
COPY supervisor/supervisord.conf /etc/supervisor/conf.d/supervisord.conf

# Start Nginx and Supervisor
CMD ["/usr/bin/supervisord", "-c", "/etc/supervisor/conf.d/supervisord.conf"]
```

### Explanation:

- **Base Image**: The image `php:7.4-fpm` is used as the base image, which includes PHP with the FastCGI Process Manager (FPM).
- **Working Directory**: The `WORKDIR` directive sets the working directory to `/var/www/html` where the application files will be placed.
- **PHP Extensions**: `libzip-dev` and `zip` are installed to support ZIP file operations, and `pdo_mysql` is installed for MySQL database support.
- **Composer**: Composer is installed to manage the project dependencies.
- **Application Files**: The `COPY` command copies the current directory contents into the container.
- **Composer Install**: Composer is run to install project dependencies.
- **Nginx Configuration**: A custom Nginx configuration file is copied to handle incoming requests.
- **Supervisor Configuration**: A Supervisor configuration file is copied to manage the supervisor process.
- **Supervisor**: The `CMD` directive starts Nginx and Supervisor, which supervises the Laravel scheduler process.

### Notes:

- Ensure you have the `nginx` and `supervisor` configuration files available in the `nginx/` and `supervisor/` directories relative to the Dockerfile.
- The Laravel batch job is typically scheduled using the `php artisan schedule:run` command, which needs to be executed periodically.
- You may need to adjust the PHP version and other dependencies based on your specific requirements.
