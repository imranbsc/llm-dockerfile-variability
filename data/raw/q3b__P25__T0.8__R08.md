Certainly! Below is a Dockerfile for a PHP application that uses Laravel's task scheduler. This Dockerfile sets up a basic environment, installs PHP and Laravel, and configures the task scheduler to run scheduled tasks.

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Install necessary dependencies
RUN apt-get update && apt-get install -y \
    libpq-dev \
    zip \
    unzip \
    git \
    && docker-php-ext-install pdo pdo_pgsql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . .

# Install any needed packages specified in composer.json
RUN composer install --no-dev --optimize-autoloader

# Install Laravel and its dependencies
RUN composer install --no-dev --optimize-autoloader

# Copy the .env.example file to .env for development
COPY .env.example .env

# Copy the database configuration files
COPY database/database.sqlite .database/database.sqlite

# Set environment variables
ENV DB_CONNECTION sqlite
ENV DB_DATABASE database.sqlite

# Run artisan migrate to create tables
RUN php artisan migrate

# Start the PHP-FPM server
CMD ["php-fpm"]

# Configure the task scheduler
RUN composer require --dev phpunit/phpunit

# Add a cron job to run the task scheduler
RUN echo "* * * * * php artisan schedule:run >> /dev/null 2>&1" >> /etc/crontab

# Set the cron service to run daily
RUN service cron start && crontab -l >> /etc/crontab && cron -l
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official PHP 7.4 FPM image, which is a minimal environment for running PHP applications.

2. **Dependencies**: It installs necessary libraries for PostgreSQL, ZIP, Git, and PHP extensions like `pdo` and `pdo_pgsql`.

3. **Composer**: Composer is installed to manage dependencies, and Laravel is installed using `composer install`.

4. **Working Directory**: The working directory is set to `/var/www/html` where the application files will be placed.

5. **Environment Variables**: The `.env` file is copied, and the database connection details are set.

6. **Database Migrations**: Laravel migrations are run to create the database schema.

7. **Cron Job**: A cron job is added to run the Laravel task scheduler daily.

8. **Service Configuration**: The cron service is started and configured to run the task scheduler.

This Dockerfile provides a basic setup for a Laravel application with a task scheduler that can be run in a container.
