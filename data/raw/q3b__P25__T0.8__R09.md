Certainly! Below is a simple Dockerfile for a scheduled batch job using PHP and Laravel, which is built using the official PHP and Laravel images.

```Dockerfile
# Use the official PHP image from the Docker Hub
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install dependencies
RUN apt-get update && apt-get install -y \
    curl \
    git \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libzip-dev \
    && docker-php-ext-configure gd \
    && docker-php-ext-install pdo_mysql \
    && docker-php-ext-install mysqli \
    && docker-php-ext-install zip \
    && docker-php-ext-install bcmath

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Run Composer to install dependencies
RUN composer install

# Install Laravel and its dependencies
RUN composer require laravel/framework

# Configure Laravel to use the task scheduler
RUN cp .env.example .env

# Copy the Laravel schedule script to the container
COPY schedule.php ./

# Expose port 80 to serve Laravel
EXPOSE 80

# Start the Laravel development server
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with the official PHP 8.1 FPM image.
2. **Working Directory**: The `WORKDIR` command sets the working directory for the container to `/var/www/html`.
3. **Copy Files**: The `COPY . /var/www/html` command copies all files from the local directory to the container at the specified path.
4. **Install Dependencies**: The `RUN` commands install necessary PHP extensions and dependencies using `apt-get`.
5. **Install Composer**: Composer is downloaded and installed to `/usr/local/bin`.
6. **Install Laravel**: Laravel and its dependencies are installed using Composer.
7. **Configuration**: The `.env.example` file is copied to `.env` to configure Laravel.
8. **Schedule Script**: A `schedule.php` file is copied to the container, which should define the scheduled tasks.
9. **Port Exposure**: The container exposes port 80 for serving Laravel.
10. **Command**: The container starts the Laravel development server using `php-fpm`.

This Dockerfile is a basic setup and can be further customized based on your specific requirements, such as adding environment variables, volumes, or more complex configurations.
