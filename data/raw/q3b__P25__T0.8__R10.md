Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using the Laravel task scheduler. This Dockerfile sets up a PHP environment with the necessary dependencies to run Laravel's scheduled tasks.

```Dockerfile
# Use the official PHP image from Docker Hub
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . /var/www/html

# Install any needed packages specified in requirements.txt
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libzip-dev \
    zip \
    unzip \
    && docker-php-ext-install pdo_mysql zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install Laravel
RUN composer create-project --prefer-dist laravel/laravel .

# Set environment variables for Laravel
ENV APP_KEY=your_app_key_here
ENV DB_HOST=your_database_host
ENV DB_DATABASE=your_database_name
ENV DB_USERNAME=your_database_user
ENV DB_PASSWORD=your_database_password

# Expose the default PHP port
EXPOSE 9000

# Start the PHP-FPM server
CMD ["php-fpm"]
```

### Key Points:
- **PHP Version**: The Dockerfile uses PHP 8.1. You can change the version as needed.
- **Work Directory**: The working directory is set to `/var/www/html`, where Laravel will be installed.
- **Composer Installation**: Composer is installed to manage PHP dependencies.
- **Laravel Installation**: Laravel is installed using Composer.
- **Environment Variables**: The necessary environment variables for a database connection are set.
- **PHP-FPM**: The PHP-FPM server is started to handle incoming requests.

### Steps to Use:
1. **Build the Docker Image**:
   ```sh
   docker build -t my-laravel-scheduler .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 9000:9000 --name my-laravel-container my-laravel-scheduler
   ```

3. **Access the Laravel Application**:
   - The Laravel application will be accessible at `http://localhost:9000` in your host machine.

4. **Schedule Tasks**:
   - Use Laravel's command line to schedule tasks. For example:
     ```sh
     php artisan schedule:run
     ```

This Dockerfile provides a basic setup for running a Laravel application with scheduled tasks using PHP-FPM. You can further customize it based on your specific requirements.
