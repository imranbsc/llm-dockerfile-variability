Certainly! Below is a simple Dockerfile for a REST API built in C# using ASP.NET Core. This Dockerfile assumes you have a basic ASP.NET Core application set up.

```Dockerfile
# Use the official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:5.0 AS base

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN dotnet restore

# Build the application
RUN dotnet build -c Release -o /app/out

# Run the application
ENTRYPOINT ["dotnet", "out/YourAppName.dll"]
```

### Explanation:

1. **Base Image**: The `mcr.microsoft.com/dotnet/aspnet:5.0` image is used as the base image. This image contains the ASP.NET Core runtime and is suitable for running ASP.NET Core applications.

2. **Working Directory**: The `WORKDIR` instruction sets the working directory inside the container to `/app`. This is where your application files will be copied and built.

3. **Copy Application Files**: The `COPY . /app` instruction copies all files from the current directory to the `/app` directory inside the container.

4. **Restore Packages**: The `RUN dotnet restore` command restores the project's dependencies specified in `packages.config` or `project.json`.

5. **Build the Application**: The `RUN dotnet build -c Release -o /app/out` command builds the application in release mode and outputs the compiled files to `/app/out`.

6. **Set the Entrypoint**: The `ENTRYPOINT ["dotnet", "out/YourAppName.dll"]` instruction specifies the command to run when the container starts. Replace `YourAppName.dll` with the actual name of your application's DLL file.

### Building and Running the Docker Image:

1. **Build the Docker Image**:
   ```sh
   docker build -t your-app-name .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 5000:80 --name your-app-container your-app-name
   ```

This will start a container running your ASP.NET Core application, mapping port 5000 on the host to port 80 in the container. You can access your application by navigating to `http://localhost:5000` in a web browser.
