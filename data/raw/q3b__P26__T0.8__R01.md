Here's a Dockerfile for a REST API built in C# using ASP.NET Core:

```dockerfile
# Use an official ASP.NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
EXPOSE 5001

# Copy the project and restore dependencies
COPY . .
RUN dotnet restore

# Build the application
RUN dotnet publish -c Release -o /app

# Finally, run the app
ENTRYPOINT ["dotnet", "YourProjectName.dll"]
```

Replace `YourProjectName` with the actual name of your ASP.NET Core project. This Dockerfile starts with an ASP.NET Core runtime image, copies the project files into the container, restores dependencies, builds the application in release mode, and finally runs the application.
