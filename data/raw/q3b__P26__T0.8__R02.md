Certainly! Below is a Dockerfile for a REST API built in C# using ASP.NET Core.

```Dockerfile
# Use an official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/sdk:5.0 AS build-env

# Set the working directory in the container
WORKDIR /src

# Copy csproj and restore packages
COPY *.csproj ./
RUN dotnet restore

# Copy the rest of the application code
COPY . .

# Build the application
RUN dotnet build -c Release -o /app

# Use a multi-stage build to create a smaller final image
FROM mcr.microsoft.com/dotnet/aspnet:5.0 AS runtime-env

# Set the working directory in the container
WORKDIR /app

# Copy the published application from the build environment
COPY --from=build-env /app .

# Expose the port that the application is listening on
EXPOSE 5001

# Run the application
ENTRYPOINT ["dotnet", "YourAppName.dll"]
```

Replace `YourAppName.dll` with the actual name of your compiled application DLL.

### Explanation:
- **Base Image**: The `mcr.microsoft.com/dotnet/sdk:5.0` image is used to build the application. This includes the SDK, which is necessary for compiling the application.
- **Working Directory**: The `WORKDIR` instruction sets the directory where the application will be built.
- **Restore Packages**: The `dotnet restore` command restores the project's NuGet packages.
- **Copy Application Code**: The `COPY` command copies all the application files into the container.
- **Build the Application**: The `dotnet build` command compiles the application into an output directory.
- **Multi-Stage Build**: The `FROM` instruction is used to specify a different base image for the runtime environment, which is `mcr.microsoft.com/dotnet/aspnet:5.0`.
- **Copy Published Application**: The `COPY --from=build-env` command copies the compiled application from the build environment.
- **Expose Port**: The `EXPOSE` instruction specifies the port that the application is listening on.
- **Run the Application**: The `ENTRYPOINT` instruction specifies how the container should start the application.

### Building and Running the Docker Image:
1. **Build the Docker Image**:
   ```sh
   docker build -t your-image-name .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 5001:5001 your-image-name
   ```

This will start a container running your ASP.NET Core application on port 5001.
