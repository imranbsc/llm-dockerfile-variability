Certainly! Below is a simple Dockerfile to create a Docker image for a REST API built in C# using ASP.NET Core.

```Dockerfile
# Use an official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . .

# Restore any necessary packages specified in the project file
RUN dotnet restore

# Build the ASP.NET Core application
RUN dotnet publish -c Release -o out

# Use a multi-stage build to create a smaller final image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS final

# Set the working directory in the container
WORKDIR /app

# Copy the published application from the build-env container
COPY --from=build-env /app/out .

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV ASPNETCORE_ENVIRONMENT=Production

# Run the application
ENTRYPOINT ["dotnet", "YourAppName.dll"]
```

Replace `YourAppName` with the name of your ASP.NET Core project.

### Explanation:

1. **Build-Env Stage:**
   - This stage uses the official .NET SDK image to build your application.
   - The application code is copied into the container, and the necessary NuGet packages are restored.

2. **Final Stage:**
   - This stage uses an official .NET runtime image to create a smaller, production-ready image.
   - The published application is copied from the build-env stage.
   - The container exposes port 80 for HTTP requests.
   - An environment variable `ASPNETCORE_ENVIRONMENT=Production` is set to optimize the application for production.
   - The application is run using the `dotnet` command.

### How to Use:

1. **Build the Docker Image:**
   ```sh
   docker build -t your-image-name .
   ```

2. **Run the Docker Container:**
   ```sh
   docker run -d -p 8080:80 your-image-name
   ```

   This will start a container and map port 8080 on your host to port 80 in the container, so you can access your API at `http://localhost:8080`.

### Notes:

- Make sure your ASP.NET Core application is properly configured in the `appsettings.json` or any other configuration files.
- Adjust the .NET SDK version in the `FROM` directive if needed for your specific requirements.
