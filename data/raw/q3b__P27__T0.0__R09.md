Certainly! Below is a Dockerfile for a server-rendered web application built in C# using ASP.NET Core MVC. This Dockerfile assumes you have a basic ASP.NET Core MVC application set up and that you want to run it in a Docker container.

```Dockerfile
# Use an official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:5.0 AS base

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN dotnet restore

# Build the application
RUN dotnet build --configuration Release

# Run the application
ENTRYPOINT ["dotnet", "YourAppName.dll"]
```

### Explanation:

1. **Base Image**: The `mcr.microsoft.com/dotnet/aspnet:5.0` image is used as the base image. This image contains the ASP.NET Core runtime and is suitable for running ASP.NET Core applications.

2. **Working Directory**: The `WORKDIR /app` command sets the working directory inside the container to `/app`. This is where your application files will be copied and executed.

3. **Copy Application Files**: The `COPY . /app` command copies all files from the current directory (where the Dockerfile is located) to the `/app` directory inside the container.

4. **Restore Packages**: The `RUN dotnet restore` command restores the project's dependencies specified in the `packages.config` or `project.json` file.

5. **Build the Application**: The `RUN dotnet build --configuration Release` command builds the application in release mode. You can change the configuration as needed.

6. **Entrypoint**: The `ENTRYPOINT ["dotnet", "YourAppName.dll"]` command specifies the command to run when the container starts. Replace `YourAppName.dll` with the actual name of your application's DLL file.

### Building and Running the Docker Image:

1. **Build the Docker Image**:
   ```sh
   docker build -t your-app-name .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 8080:80 your-app-name
   ```

This will start a container running your ASP.NET Core application, mapping port 8080 on your host to port 80 in the container. You can then access your application by navigating to `http://localhost:8080` in your web browser.
