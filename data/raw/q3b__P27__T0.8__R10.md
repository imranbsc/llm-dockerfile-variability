Certainly! Below is a Dockerfile for a server-rendered web application built in C# using ASP.NET Core MVC. This Dockerfile assumes you have a .NET Core project set up with ASP.NET Core MVC.

```Dockerfile
# Use an official ASP.NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:5.0 AS base

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN apt-get update && \
    apt-get install -y curl && \
    curl -sSL https://dotnet.microsoft.com/sdk/dotnet-install-script | dotnet-install.sh --channel 5.0 && \
    dotnet restore

# Build the application
RUN dotnet build --no-restore

# Run the application
ENTRYPOINT ["dotnet", "your-project-name.dll"]
```

### Key Points:
- **Base Image**: The image `mcr.microsoft.com/dotnet/aspnet:5.0` is used as the base image, which includes the ASP.NET Core runtime.
- **Working Directory**: The working directory `/app` is set where the application will be built and run.
- **Copy Files**: The contents of the current directory are copied into the container at `/app`.
- **DotNet Installation**: The `dotnet-install.sh` script is used to install the .NET SDK for the specified channel (in this case, `5.0`).
- **Build Command**: The application is built using `dotnet build --no-restore`.
- **Entry Point**: The application is run using `dotnet your-project-name.dll`, where `your-project-name.dll` is the name of your ASP.NET Core application.

### Building and Running the Docker Container:
1. Ensure you have Docker installed on your machine.
2. Navigate to your project directory in the terminal.
3. Build the Docker image using the following command:
   ```sh
   docker build -t your-image-name .
   ```
4. Run the Docker container using the following command:
   ```sh
   docker run -d -p 5000:80 your-image-name
   ```
5. Open a web browser and navigate to `http://localhost:5000` to see your ASP.NET Core MVC application running inside the Docker container.

Make sure to replace `your-project-name` with the actual name of your ASP.NET Core project.
