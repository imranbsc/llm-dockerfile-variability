Here's a basic Dockerfile for a command-line tool built in C# using System.CommandLine. This Dockerfile assumes you have a C# project that uses System.CommandLine for parsing command-line arguments.

```Dockerfile
# Use the official .NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /app

# Copy the csproj and all necessary dependencies to the build environment
COPY *.csproj ./
RUN dotnet restore

# Copy the rest of the project files and build the executable
COPY . ./
RUN dotnet publish -c Release -o out

# Create a new runtime image
FROM mcr.microsoft.com/dotnet/runtime:6.0 AS runtime-env

# Set the working directory in the container
WORKDIR /app

# Copy the published application files from the build environment to the runtime environment
COPY --from=build-env /app/out .

# Expose the port that the application is listening on
EXPOSE 5000

# Run the application
ENTRYPOINT ["./YourApplicationName"]
```

Please replace `YourApplicationName` with the name of your application. This Dockerfile will build a Docker image based on the .NET Core SDK, copy your project files, build the application, and then run it in a container.
