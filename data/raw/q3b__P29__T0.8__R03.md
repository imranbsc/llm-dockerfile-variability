Certainly! Below is a Dockerfile for a command-line tool built in C# using `System.CommandLine`. This Dockerfile assumes you have a C# project that uses `System.CommandLine` for parsing command-line arguments.

```dockerfile
# Use the official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /src

# Copy the current directory contents into the container at /src
COPY . .

# Restore any dependencies specified in your project file
RUN dotnet restore

# Build the application
RUN dotnet build --output ../output

# Use a runtime environment based on the official .NET runtime
FROM mcr.microsoft.com/dotnet/runtime:6.0

# Set the working directory in the container
WORKDIR /app

# Copy the built output from the build-env container
COPY --from=build-env /src/output .

# Expose the port on which your application will run
EXPOSE 5000

# Run the application
ENTRYPOINT ["dotnet", "YourApp.dll"]
```

### Explanation:
- **Base Image**: The Dockerfile starts with the official .NET SDK image. This is used to build the application.
- **Working Directory**: The `WORKDIR` instruction sets the directory in the container where the application will be built and run.
- **Copy Dependencies**: The `COPY` command copies the project files into the container.
- **Restore Dependencies**: The `dotnet restore` command installs all necessary NuGet packages.
- **Build Application**: The `dotnet build` command compiles the application.
- **Runtime Environment**: A new image is created based on the official .NET runtime image to run the application.
- **Working Directory in Runtime**: The `WORKDIR` instruction sets the directory in the runtime image.
- **Copy Built Output**: The `COPY --from=build-env` command copies the built output from the build environment container.
- **Expose Port**: The `EXPOSE` command specifies the port on which the application will run.
- **Entrypoint**: The `ENTRYPOINT` command specifies the command to run when the container starts.

### Notes:
- Replace `YourApp.dll` with the actual name of your C# application DLL.
- Adjust the .NET SDK version (`6.0` in this example) if needed based on your requirements.

To build and run this Docker image, you can use the following commands:

```sh
docker build -t your-app .
docker run -p 5000:5000 your-app
```

This will build the Docker image and then run it, mapping port 5000 on the host to port 5000 in the container.
