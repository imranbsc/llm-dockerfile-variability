Certainly! Below is a Dockerfile for building a C# command-line tool using System.CommandLine. This Dockerfile assumes you have a .NET application set up and a `Program.cs` file that defines the command-line interface.

```Dockerfile
# Use the official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/runtime:6.0-slim-buster

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run the app
CMD ["dotnet", "YourAppName.dll"]
```

Replace `YourAppName.dll` with the name of your .NET application's executable file. If you have additional dependencies or need to install them, you can modify the `COPY` and `RUN` commands accordingly.
