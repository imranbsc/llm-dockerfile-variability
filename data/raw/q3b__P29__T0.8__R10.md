Certainly! Below is a Dockerfile for a C# command-line tool built using `System.CommandLine`. This Dockerfile assumes you have a C# project that uses `System.CommandLine` for command-line parsing.

```Dockerfile
# Use the official .NET SDK image as the base image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /src

# Copy the project file and dependencies
COPY ["YourProject.csproj", "."]
COPY ["YourProject.sln", "."]

# Restore the NuGet packages
RUN dotnet restore

# Build the application
RUN dotnet build --configuration Release

# Create a runtime container
FROM mcr.microsoft.com/dotnet/runtime:6.0 AS runtime-env

# Set the working directory in the container
WORKDIR /app

# Copy the built application from the build environment
COPY --from=build-env /src/bin/Release/net6.0/YourProject /app

# Expose the port the application listens on
EXPOSE 5000

# Run the application
ENTRYPOINT ["dotnet", "YourProject.dll"]
```

### Explanation:
- **Base Image**: The `mcr.microsoft.com/dotnet/sdk:6.0` image is used to build the application.
- **Working Directory**: The working directory is set to `/src` to hold the project files.
- **Dependencies**: The `COPY` command copies the project file and solution file into the container.
- **Restore**: The `dotnet restore` command restores the NuGet packages.
- **Build**: The `dotnet build --configuration Release` command builds the application in Release mode.
- **Runtime Image**: The `mcr.microsoft.com/dotnet/runtime:6.0` image is used to run the application.
- **Working Directory**: The working directory is set to `/app` to hold the built application.
- **Copy**: The built application is copied from the build environment to the runtime environment.
- **Expose**: The application is exposed on port 5000.
- **Entry Point**: The `ENTRYPOINT` command specifies the command to run the application.

Make sure to replace `YourProject.csproj` and `YourProject.sln` with the actual names of your project files. You can also adjust the `EXPOSE` and `ENTRYPOINT` commands if your application runs on a different port.
