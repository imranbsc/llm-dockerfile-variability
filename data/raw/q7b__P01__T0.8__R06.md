Here is a simple Dockerfile for a Node.js application using Express:

```dockerfile
# Use an official Node runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app when the container launches
CMD ["node", "app.js"]
```

Please replace "app.js" with the name of your main application file.

This Dockerfile uses the official Node.js image from Docker Hub, sets the working directory, copies the package.json and package-lock.json files, installs the dependencies, copies the rest of the application code, exposes port 3000, and finally starts the application.
