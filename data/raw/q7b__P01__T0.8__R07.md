```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["node", "app.js"]
```

This Dockerfile sets up a basic Node.js environment for a REST API using Express. It starts with an official Node.js 14 image, sets the working directory, installs dependencies, copies the application code, exposes port 3000, and defines the command to run the application.
