Here's a simple Dockerfile for a Node.js application built with Next.js:

```Dockerfile
# Use an official Node runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Build the app
RUN npm run build

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["npm", "start"]
```

This Dockerfile assumes that your Next.js app is in the same directory as the Dockerfile. It sets up a Node.js environment, installs dependencies, builds your app, and then starts the server. 

Please make sure to build your Next.js app in production mode by running `npm run build` before building your Docker image. This step is crucial as it optimizes the app for production. 

Also, remember to expose the correct port (default is 3000) and adjust the CMD accordingly if your app listens on a different port.
