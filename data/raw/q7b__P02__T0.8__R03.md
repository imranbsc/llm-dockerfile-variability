```dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Build the Next.js application
RUN npm run build

# Set the port number the app listens on
EXPOSE 3000

# Command to run the application
CMD ["npm", "start"]
```

This Dockerfile sets up a Node.js environment for a Next.js application. It installs dependencies, builds the application, and specifies the command to run the server.
