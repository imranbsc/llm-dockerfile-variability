Here's a simple Dockerfile for a Node.js background worker built with BullMQ:

```dockerfile
# Use an official Node runtime as a parent image
FROM node:16

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Define environment variable
ENV NODE_ENV production

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Command to run the app using BullMQ
CMD ["node", "index.js"]
```

Make sure to replace `index.js` with the actual file name of your BullMQ worker script. This Dockerfile assumes that you have all your dependencies listed in `package.json` and that the worker script is set up to listen on port 3000.
