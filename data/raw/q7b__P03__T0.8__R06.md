Here is a basic example of a Dockerfile for a background worker built in Node.js using BullMQ:

```Dockerfile
# Use an official Node runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the current directory contents into the container at /usr/src/app
COPY . .

# Install any needed packages specified in package.json
RUN npm install

# Define the port number the app runs on
EXPOSE 8080

# Command to run the worker
CMD ["node", "worker.js"]
```

This Dockerfile assumes you have a `worker.js` file in the root of your project which is responsible for setting up and running your BullMQ worker.

Please adjust the version of Node.js, the directory where your application is located, and the command to run your worker as per your actual project structure and requirements.
