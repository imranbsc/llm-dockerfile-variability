```dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["node", "index.js"]
```

In this Dockerfile, we start with a Node.js 14 runtime image. We set the working directory to `/usr/src/app`. We then copy the `package.json` and `package-lock.json` files to install the necessary dependencies. After installation, we copy the rest of the application code into the container. We expose port 3000 for the application. Finally, we define an environment variable and set the command to run the application with `node index.js`.
