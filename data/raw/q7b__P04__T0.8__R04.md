Here is a Dockerfile for a command-line tool built in Node.js using Commander.js:

```dockerfile
# Use an official Node runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["node", "index.js"]
```

Please note that you should replace `index.js` with the file name of your main JavaScript file. Also, ensure that your `package.json` includes `commander` as a dependency and that your script is set up to use Commander.js for your command-line interface.
