Here is a simple Dockerfile for a Node.js command-line tool built with Commander.js:

```Dockerfile
# Use an official Node runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Make port 3000 available to the world outside this container
EXPOSE 3000

# Define environment variable
ENV NAME World

# Run app when the container launches
CMD ["node", "app.js"]
```
Please replace `app.js` with the actual file name of your application. Also, ensure that the application is listening on port 3000 if you are exposing port 3000.
