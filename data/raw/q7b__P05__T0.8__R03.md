```dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Install node-cron
RUN npm install node-cron

# Set the command to run the app using cron
CMD ["node", "app.js"]
```

This Dockerfile assumes that your Node.js application is in the root directory of your project and that there is a file named `app.js` that contains the cron job setup using `node-cron`.
