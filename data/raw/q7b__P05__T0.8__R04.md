Certainly! Below is a Dockerfile for a scheduled batch job built in Node.js using `node-cron`.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Expose the port the app runs on
EXPOSE 3000

# Command to run the app using node-cron
CMD ["node", "app.js"]
```

### Explanation:
1. **FROM node:14**: This line specifies the base image to use. In this case, it's Node.js version 14.

2. **WORKDIR /usr/src/app**: This sets the working directory inside the container to `/usr/src/app`.

3. **COPY package*.json ./**: This copies the `package.json` and `package-lock.json` files into the container.

4. **RUN npm install**: This installs all the dependencies listed in `package.json`.

5. **COPY . .**: This copies the rest of your application code into the container.

6. **EXPOSE 3000**: This exposes port 3000, which is where your application is expected to run.

7. **CMD ["node", "app.js"]**: This command specifies the command to run when the container starts. It runs your `app.js` file.

### Notes:
- Make sure your `app.js` file contains the logic for your scheduled batch job using `node-cron`.
- Adjust the `EXPOSE` port if your application runs on a different port.
- Ensure your `package.json` includes the necessary dependencies for `node-cron` and any other packages your application requires.

### Building and Running the Docker Container:
1. Build the Docker image:
   ```bash
   docker build -t scheduled-node-job .
   ```

2. Run the Docker container:
   ```bash
   docker run -d -p 3000:3000 --name my-scheduled-job scheduled-node-job
   ```

This setup will allow you to run a scheduled batch job using Node.js and `node-cron` inside a Docker container.
