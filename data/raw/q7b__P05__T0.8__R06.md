Certainly! Below is an example of a Dockerfile for a scheduled batch job built in Node.js using `node-cron`.

```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy package.json and package-lock.json
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy the rest of your application code
COPY . .

# Expose the port that your application listens on
EXPOSE 3000

# Command to run your application
CMD ["node", "index.js"]
```

### Explanation:

1. **FROM node:14**: This line specifies the base image to use. We're using Node.js 14.
2. **WORKDIR /usr/src/app**: This sets the working directory inside the container.
3. **COPY package*.json ./**: This copies the `package.json` and `package-lock.json` files to the working directory.
4. **RUN npm install**: This installs the dependencies specified in your `package.json`.
5. **COPY . .**: This copies the rest of your application code into the container.
6. **EXPOSE 3000**: This exposes port 3000, which is the port your application is likely listening on.
7. **CMD ["node", "index.js"]**: This is the command that runs your Node.js application.

### Additional Notes:

- Ensure that your `index.js` file is set up to use `node-cron` to schedule your batch job.
- If your batch job requires additional environment variables, you can set them in the Dockerfile using `ENV VARIABLE_NAME=value`.

For example, if your `index.js` looks like this:

```javascript
const cron = require('node-cron');
const fs = require('fs');

cron.schedule('* * * * *', () => {
  console.log('Running scheduled task');
  fs.writeFileSync('output.txt', 'Hello, this is a scheduled task output');
});
```

This Dockerfile will create a container that runs a scheduled task every minute, writing a message to `output.txt`.
