```Dockerfile
# Use an official Node.js runtime as a parent image
FROM node:14

# Set the working directory in the container
WORKDIR /usr/src/app

# Copy the package.json and package-lock.json files
COPY package*.json ./

# Install any needed packages specified in package.json
RUN npm install

# Bundle app source inside Docker image
COPY . .

# Install node-cron for scheduling
RUN npm install node-cron

# Expose the port the app runs on
EXPOSE 3000

# Command to run the application
CMD ["node", "app.js"]
```

**Explanation**:
This Dockerfile sets up a Node.js environment for running a scheduled batch job. It starts with an official Node.js image, sets the working directory, copies the project's package files to install dependencies, and then copies the rest of the project files. It ensures `node-cron` is installed, exposes port 3000, and specifies the command to run the application.
