Certainly! Below is a Dockerfile for a REST API built in Python using Flask:

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

### Explanation:
1. **FROM python:3.9-slim**: Uses an official Python 3.9 image with a slim version for a smaller footprint.
2. **WORKDIR /app**: Sets the working directory inside the container to `/app`.
3. **COPY . /app**: Copies the current directory contents into the container at `/app`.
4. **RUN pip install --no-cache-dir -r requirements.txt**: Installs the Python packages listed in `requirements.txt`.
5. **EXPOSE 5000**: Makes port 5000 available to the world outside this container.
6. **ENV NAME World**: Sets an environment variable `NAME` with a default value of `World`.
7. **CMD ["python", "app.py"]**: Runs the `app.py` file when the container launches.

### Note:
- Ensure that your Flask application is set up correctly in `app.py` and that `requirements.txt` includes all necessary Python packages.
- If your Flask application runs on a different port, update the `EXPOSE` directive accordingly.
