Here is a simple Dockerfile for a Python command-line tool built with Click:

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.8-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --trusted-host pypi.python.org -r requirements.txt

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run app.py when the container launches
CMD ["python", "app.py"]
```

You should replace `app.py` with the name of your Click application. Also, ensure you have a `requirements.txt` file in your project that includes all the Python packages your application depends on.

This Dockerfile assumes your Click application is a simple script named `app.py`. If your application is structured differently (e.g., if it has multiple modules or a package structure), you'll need to adjust the Dockerfile accordingly.
