Certainly! Below is a Dockerfile for a scheduled batch job built in Python using APScheduler. This Dockerfile sets up a basic Python environment, installs necessary packages, and schedules a job using APScheduler.

```Dockerfile
# Use an official Python runtime as a parent image
FROM python:3.9-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Copy the Python script into the container
COPY scheduled_job.py /app/scheduled_job.py

# Command to run the script
CMD ["python", "scheduled_job.py"]
```

### Requirements.txt
Make sure you have a `requirements.txt` file in your project directory that includes the necessary packages:

```
APScheduler
```

### scheduled_job.py
Here is an example of what your `scheduled_job.py` might look like:

```python
from apscheduler.schedulers.background import BackgroundScheduler
import time

def my_job():
    print("Executing job at", time.ctime())

scheduler = BackgroundScheduler()
scheduler.add_job(my_job, 'interval', minutes=1)
scheduler.start()

# To keep the container running
try:
    while True:
        time.sleep(2)
except (KeyboardInterrupt, SystemExit):
    pass
```

### Explanation
1. **Base Image**: The Dockerfile starts with an official Python 3.9 slim image.
2. **Working Directory**: Sets the working directory inside the container to `/app`.
3. **Copy Files**: Copies the current directory contents to `/app`.
4. **Install Packages**: Installs the packages listed in `requirements.txt`.
5. **Copy Script**: Copies the `scheduled_job.py` script to the `/app` directory.
6. **Command**: The `CMD` instruction specifies that the `scheduled_job.py` script should be run when the container starts.

### Running the Docker Container
To build and run the Docker container, use the following commands:

```sh
# Build the Docker image
docker build -t scheduled-job .

# Run the Docker container
docker run -d --name my-job-container scheduled-job
```

This will run your scheduled batch job inside a Docker container, and the job will execute every minute.
