Here is a basic Dockerfile for a Spring Boot REST API:

```Dockerfile
# Use an official openjdk runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Add the compiled JAR file to the container
COPY target/your-application.jar /app/your-application.jar

# Expose the application port
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "your-application.jar"]
```

This Dockerfile assumes that you have a Spring Boot application built into a JAR file in the `target` directory and that the JAR file is named `your-application.jar`. It sets the working directory in the container to `/app`, copies the JAR file into the container, exposes port 8080, and sets the command to run the JAR file as the default command when the container starts. You may need to adjust the version of OpenJDK and the name of the JAR file to match your specific setup.
