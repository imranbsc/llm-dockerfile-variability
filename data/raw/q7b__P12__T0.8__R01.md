Certainly! Below is a Dockerfile for a server-rendered web application built in Java using Spring Boot and Thymeleaf. This Dockerfile assumes you have a Maven project structure and that your Spring Boot application is packaged as a JAR file.

```dockerfile
# Use an official OpenJDK image as the base image
FROM openjdk:17-jdk-slim

# Set the working directory inside the container
WORKDIR /app

# Copy the application JAR file into the container
COPY target/your-spring-boot-app.jar /app/your-spring-boot-app.jar

# Expose the application port
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "your-spring-boot-app.jar"]
```

### Instructions for Use:

1. **Build Your Spring Boot Application**:
   Ensure that your Spring Boot application is built and the JAR file is located in the `target` directory of your Maven project.

2. **Create the Dockerfile**:
   Place the above Dockerfile in the root directory of your project.

3. **Build the Docker Image**:
   Open a terminal, navigate to the root directory of your project, and run the following command to build the Docker image:

   ```sh
   docker build -t your-spring-boot-app .
   ```

4. **Run the Docker Container**:
   After the image is built, you can run the container using the following command:

   ```sh
   docker run -p 8080:8080 your-spring-boot-app
   ```

   This command maps port 8080 of the container to port 8080 on your host machine, allowing you to access your application via `http://localhost:8080`.

### Notes:

- Replace `your-spring-boot-app.jar` with the actual name of your JAR file.
- Ensure that your Spring Boot application is configured to use port 8080 or any other port as needed.
- If you have any other dependencies or configuration that needs to be added to the Docker image, you can modify the Dockerfile accordingly.
