Here is a simple Dockerfile for a Java Spring Boot application that uses RabbitMQ as a background worker:

```dockerfile
# Use the official openjdk image as a parent image
FROM openjdk:11-jre-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY target/my-spring-boot-app.jar /app/my-spring-boot-app.jar

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "my-spring-boot-app.jar"]
```

Please replace `my-spring-boot-app.jar` with the actual name of your jar file.

If you have a `pom.xml` file and you want to build the jar from there, you can use the following Dockerfile:

```dockerfile
# Use the official maven image as a parent image
FROM maven:3.8.4-jdk-11 AS build

# Set the working directory in the container
WORKDIR /app

# Copy the pom.xml and build the project
COPY pom.xml .
RUN mvn clean package

# Use the official openjdk image as a parent image for the final image
FROM openjdk:11-jre-slim

# Set the working directory in the container
WORKDIR /app

# Copy the built jar from the build stage
COPY --from=build /app/target/my-spring-boot-app.jar /app/my-spring-boot-app.jar

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Command to run the application
CMD ["java", "-jar", "my-spring-boot-app.jar"]
```

Again, replace `my-spring-boot-app.jar` with the actual name of your jar file.
