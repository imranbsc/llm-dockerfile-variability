Certainly! Below is a Dockerfile for a command-line tool built in Java using picocli:

```Dockerfile
# Use an official OpenJDK image as the base image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the compiled JAR file into the container
COPY target/your-tool-name.jar /app/your-tool-name.jar

# Define the entry point for the container
ENTRYPOINT ["java", "-jar", "your-tool-name.jar"]
```

### Explanation:

- **FROM openjdk:17-jdk-slim**: This line specifies the base image to use, which is a slim version of OpenJDK 17. You can adjust the version if needed.

- **WORKDIR /app**: This sets the working directory inside the container to `/app`.

- **COPY target/your-tool-name.jar /app/your-tool-name.jar**: This copies the compiled JAR file from your local machine (usually generated by building your Java project) into the `/app` directory inside the container.

- **ENTRYPOINT ["java", "-jar", "your-tool-name.jar"]**: This specifies the command to run when the container starts. It tells the container to run the Java application using the JAR file.

### Usage:

1. Build your Java project to generate the JAR file (if you haven't already):
    ```sh
    mvn clean package
    ```

2. Build the Docker image:
    ```sh
    docker build -t your-tool-name .
    ```

3. Run the Docker container:
    ```sh
    docker run -it your-tool-name
    ```

This Dockerfile assumes that your JAR file is located in the `target` directory of your Maven project. Adjust the path if your build process differs.
