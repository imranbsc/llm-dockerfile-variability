Certainly! Below is a Dockerfile for a scheduled batch job built in Java using Spring Batch.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the maintainer label
LABEL maintainer="your-email@example.com"

# Set the working directory in the container
WORKDIR /app

# Copy the local Maven project to the working directory
COPY . /app

# Build the Spring Batch application
RUN ./mvnw clean package -DskipTests

# Expose the application port
EXPOSE 8080

# Define the environment variable for Spring Batch configuration
ENV SPRING_BATCH_JOB_NAME=scheduledJob

# Command to run the Spring Batch application
CMD ["java", "-jar", "target/your-application-name.jar", "--spring.batch.job.names=${SPRING_BATCH_JOB_NAME}"]
```

### Explanation:
1. **Base Image**: Uses an official OpenJDK 17 image as the base image.
2. **Working Directory**: Sets `/app` as the working directory inside the container.
3. **Copy Project**: Copies the entire project into the `/app` directory.
4. **Build Application**: Uses Maven to clean and package the application, skipping tests.
5. **Expose Port**: Exposes port 8080, which is commonly used for Spring Boot applications.
6. **Environment Variable**: Sets an environment variable `SPRING_BATCH_JOB_NAME` to specify the name of the job to run.
7. **Run Command**: Runs the Spring Boot application with the specified job name as a command-line argument.

### Usage:
1. Replace `your-application-name.jar` with the actual name of your JAR file.
2. Customize the `SPRING_BATCH_JOB_NAME` environment variable as needed.

To build and run the Docker container, you can use the following commands:

```sh
# Build the Docker image
docker build -t your-spring-batch-app .

# Run the Docker container
docker run -p 8080:8080 -e SPRING_BATCH_JOB_NAME=yourJobName your-spring-batch-app
```

This setup will build your Spring Batch application and run it as a Docker container, executing the specified batch job.
