```dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the local src directory contents into the container at /app
COPY target/spring-batch-job-*.jar app.jar

# Make port 8080 available to the world outside this container
EXPOSE 8080

# Run the application using the java command
CMD ["java", "-jar", "app.jar"]
```

This Dockerfile sets up a Java Spring Batch application inside a Docker container. It starts from the `openjdk:17-jdk-slim` image, which is a lightweight version of the OpenJDK. The `WORKDIR` directive sets the working directory inside the container. The `COPY` command copies the built Spring Batch job JAR file into the container. The `EXPOSE` command specifies that the container listens on port 8080, which is the default port for Spring Boot applications. Finally, the `CMD` directive runs the Spring Batch job when the container starts.
