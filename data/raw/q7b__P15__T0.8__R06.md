Certainly! Below is an example of a Dockerfile for a scheduled batch job built in Java using Spring Batch. This Dockerfile assumes you have a Spring Boot project structure with a `src` directory containing your Java source code.

```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the Maven repository to the container to avoid downloading dependencies again
COPY ~/.m2 /root/.m2

# Copy the project's pom.xml and all the dependencies
COPY pom.xml ./

# Build the project using Maven
RUN mvn clean package -DskipTests

# Copy the built JAR file from the target directory to the container
COPY target/*.jar app.jar

# Expose the port that your application is running on
EXPOSE 8080

# Define the environment variable for the Spring Batch configuration
ENV SPRING_BATCH_JOB_NAME=your_job_name

# Define the entry point to run the Spring Boot application
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### Explanation:

1. **Base Image**: `openjdk:17-jdk-slim` - This is a lightweight version of the OpenJDK 17 image.
2. **Working Directory**: `/app` - The working directory inside the container.
3. **Maven Repository**: The Maven repository is copied to avoid downloading dependencies every time the Docker image is built.
4. **Project Files**: The `pom.xml` and all dependencies are copied to the container.
5. **Build Project**: The project is built using Maven with the `-DskipTests` option to skip the test phase.
6. **Copy JAR**: The built JAR file is copied from the `target` directory to the container.
7. **Expose Port**: The port that your application is running on is exposed.
8. **Environment Variable**: The `SPRING_BATCH_JOB_NAME` environment variable is set to specify the job name that should be executed.
9. **Entry Point**: The `ENTRYPOINT` is set to run the Spring Boot application.

### Building and Running the Docker Image:

To build and run the Docker image, follow these steps:

1. Build the Docker image:
   ```sh
   docker build -t spring-batch-job .
   ```

2. Run the Docker container:
   ```sh
   docker run -d --name spring-batch-job-container -p 8080:8080 spring-batch-job
   ```

This will build your Spring Batch job as a Docker image and run it as a container. Make sure to replace `your_job_name` with the actual job name you want to execute.
