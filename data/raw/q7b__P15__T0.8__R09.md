```Dockerfile
# Use an official OpenJDK runtime as a parent image
FROM openjdk:11-jre-slim

# Set the maintainer label
LABEL maintainer="your-email@example.com"

# Set the working directory in the container
WORKDIR /app

# Copy the compiled Java application jar into the container
COPY target/your-application.jar /app/your-application.jar

# Define environment variables
ENV JAVA_OPTS="-Xmx512m"

# Define the command to run the Spring Batch application
CMD ["sh", "-c", "java ${JAVA_OPTS} -jar your-application.jar"]
```

This Dockerfile sets up a lightweight OpenJDK runtime environment and copies the compiled Java application jar file into the container. It defines the working directory and sets the Java options. Finally, it specifies the command to run the Spring Batch application. Make sure to replace `your-application.jar` with the actual name of your compiled Java application.
