Certainly! Below is a Dockerfile for a REST API built in Go using Gin:

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17 AS builder

# Set the working directory in the container
WORKDIR /app

# Copy the go.mod and go.sum files to the working directory
COPY go.mod go.sum ./

# Download all dependencies
RUN go mod download

# Copy the source code to the working directory
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -a -installsuffix cgo -o api .

# Use a lightweight base image for the production environment
FROM alpine:latest

# Copy the compiled binary from the builder stage
COPY --from=builder /app/api /usr/local/bin/api

# Expose the port the app runs on
EXPOSE 8080

# Run the app
CMD ["api"]
```

This Dockerfile includes two stages:

1. **Builder Stage**: This stage builds the Go application.
   - It starts from the official Go 1.17 image.
   - Sets the working directory to `/app`.
   - Copies the `go.mod` and `go.sum` files to download all dependencies.
   - Copies the source code and builds the Go application into a binary named `api`.

2. **Production Stage**: This stage is a lightweight Alpine Linux image that runs the compiled Go application.
   - Copies the compiled binary from the builder stage.
   - Exposes port 8080.
   - Runs the `api` binary.

You can build and run your Docker container using the following commands:

```sh
# Build the Docker image
docker build -t my-go-api .

# Run the Docker container
docker run -p 8080:8080 my-go-api
```

This setup ensures that your Go application is built and run in a lightweight and isolated environment.
