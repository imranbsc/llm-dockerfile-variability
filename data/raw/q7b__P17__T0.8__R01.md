Here's a basic Dockerfile for a Go web application using the html/template package:

```dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine AS builder

# Set the working directory in the container
WORKDIR /go/src/app

# Copy the current directory contents into the container at /go/src/app
COPY . .

# Build the Go app
RUN CGO_ENABLED=0 GOOS=linux go build -o main .

# Use an official lightweight Alpine image for the runtime
FROM alpine:latest

# Set the working directory in the container
WORKDIR /root/

# Copy the built Go app from the builder stage
COPY --from=builder /go/src/app/main .

# Expose port 8080
EXPOSE 8080

# Run the app when the container launches
CMD ["./main"]
```

This Dockerfile does the following:

1. Uses an official Go image as the base image for building the application.
2. Sets the working directory for the Go application.
3. Copies the source code into the container.
4. Builds the Go application.
5. Creates a new stage with a lightweight Alpine image for running the application.
6. Copies the built Go application from the builder stage.
7. Exposes port 8080.
8. Specifies the command to run the Go application when the container starts.

To build and run the Docker container:

1. Save the Dockerfile in the root directory of your Go web application.
2. Build the Docker image by running `docker build -t your-app-name .`.
3. Run the Docker container by executing `docker run -p 8080:8080 your-app-name`.

Make sure to replace "your-app-name" with a meaningful name for your application.
