```dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine as builder

# Set the working directory in the container
WORKDIR /app

# Copy the go.mod and go.sum files
COPY go.mod go.sum ./

# Download all dependencies. Dependencies will be cached if the go.mod and go.sum files are not changed
RUN go mod download

# Copy the content of the local src directory to the working directory
COPY . .

# Build the application
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# Use an official lightweight Alpine image for the production environment
FROM alpine:latest

# Set the working directory in the container
WORKDIR /root/

# Copy the binary to the container image
COPY --from=builder /app/main .

# Define environment variable
ENV NAME World

# Run the application when the container launches
CMD ["./main"]
```

This Dockerfile starts by using an official Go image to build the Go application. It copies the `go.mod` and `go.sum` files to download the necessary dependencies. After that, it copies the rest of the application code and builds the binary.

For the production environment, it uses a lightweight Alpine image and copies the built binary into this image. It sets the `NAME` environment variable and runs the application when the container starts.
