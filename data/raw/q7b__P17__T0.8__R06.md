```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17-alpine AS builder

# Set the working directory in the container
WORKDIR /app

# Copy the go.mod and go.sum files
COPY go.mod go.sum ./

# Download all dependencies
RUN go mod download

# Copy the source code into the container
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# Use an official lightweight Alpine Linux image as a parent image for the final container
FROM alpine:latest

# Set the working directory in the container
WORKDIR /root/

# Copy the binary from the builder stage
COPY --from=builder /app/main .

# Expose the port the application runs on
EXPOSE 8080

# Command to run the application
CMD ["./main"]
```

This Dockerfile first builds the Go application using an official Go image as the parent image. It sets the working directory, copies the `go.mod` and `go.sum` files to download dependencies, copies the source code, and builds the application. The final stage uses a lightweight Alpine Linux image to run the compiled binary, exposing port 8080 and setting the command to run the application.
