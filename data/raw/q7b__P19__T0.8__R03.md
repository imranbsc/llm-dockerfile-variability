```dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17 AS builder

# Set the working directory in the container
WORKDIR /app

# Copy the go.mod and go.sum files
COPY go.mod go.sum ./

# Download all dependencies
RUN go mod download

# Copy the source code into the container
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o mytool .

# Use a smaller image to run the application
FROM alpine:latest

# Create the working directory
WORKDIR /app

# Copy the binary from the builder stage
COPY --from=builder /app/mytool .

# Set the entrypoint of the container
ENTRYPOINT ["/app/mytool"]
```

This Dockerfile sets up a multi-stage build process. The first stage uses the official Go image to build the application. It starts by setting the working directory and copying the Go module files to download all dependencies. Then, it copies the source code and builds the Go application into a binary named `mytool`.

The second stage uses a smaller Alpine Linux image to run the application. It copies the `mytool` binary from the first stage into this image and sets it as the entrypoint. This results in a lightweight container that can execute the Go command-line tool built using Cobra.
