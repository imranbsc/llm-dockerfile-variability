```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17 AS builder

# Set the working directory in the container
WORKDIR /app

# Copy the Go module and vendor files
COPY go.mod go.sum ./
RUN go mod download

# Copy the source code
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o myapp .

# Start a new stage from a smaller base image
FROM alpine:latest

# Copy the built Go application from the builder stage
COPY --from=builder /app/myapp /usr/local/bin/myapp

# Set the command to run the application
CMD ["myapp"]
```

This Dockerfile starts by using an official Go runtime image as the base image for building the Go application. It sets the working directory, copies the Go module and vendor files, downloads the dependencies, and then builds the Go application. In the second stage, it starts from a smaller base image (Alpine) and copies the built Go application into this image. Finally, it sets the command to run the application.
