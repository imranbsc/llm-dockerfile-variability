```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17 AS builder

# Set the working directory in the container
WORKDIR /app

# Copy the go.mod and go.sum files
COPY go.mod go.sum ./

# Download all dependencies
RUN go mod download

# Copy the source code into the container
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# Use a lightweight image for the final container
FROM alpine:latest

# Set the working directory in the container
WORKDIR /root/

# Copy the binary from the builder stage
COPY --from=builder /app/main .

# Set the environment variable for the cron schedule
ENV CRON_SCHEDULE="0 0 * * *"

# Create a cron job file
RUN echo "$CRON_SCHEDULE /root/main" > /etc/crontabs/root

# Set the cron daemon to run in the foreground
CMD ["crond", "-f"]
```

This Dockerfile sets up a Go application that runs as a scheduled batch job using the `robfig/cron` package. It uses a multi-stage build to first compile the Go application and then copy the binary into a lightweight Alpine Linux image. The cron job is configured to run the Go application at midnight every day.
