Certainly! Below is a Dockerfile for a scheduled batch job built in Go using the `robfig/cron` package:

```Dockerfile
# Use an official Go runtime as a parent image
FROM golang:1.17 AS builder

# Set the working directory
WORKDIR /app

# Copy the go.mod and go.sum files
COPY go.mod go.sum ./

# Download all dependencies
RUN go mod download

# Copy the rest of the application code
COPY . .

# Build the Go application
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o main .

# Use a smaller base image for the final image
FROM alpine:latest

# Copy the binary from the builder stage
COPY --from=builder /app/main /app/main

# Set the working directory
WORKDIR /app

# Expose the port that the job will run on
EXPOSE 8080

# Run the job using cron
CMD ["sh", "-c", "cron -f -L 1"]
```

This Dockerfile uses a multi-stage build to first build the Go application and then copy the binary into a smaller base image that only contains the necessary files to run the job. The job is scheduled using cron, and the cron daemon is run in the foreground to keep the container running.

Make sure to configure your cron job in a file (e.g., `cronjob.conf`) and copy it to the container using the `COPY` command. For example:

```Dockerfile
# Copy the cron job configuration file
COPY cronjob.conf /etc/cron.d/mycron

# Ensure the cron daemon has permission to read the cron job configuration
RUN chmod 0644 /etc/cron.d/mycron

# Run the job using cron
CMD ["sh", "-c", "cron -f -L 1"]
```

Your `cronjob.conf` file should contain the cron schedule and the command to run the batch job. For example:

```
* * * * * /app/main
```

This schedule means the job will run every minute. Adjust it according to your needs.
