Here is an example Dockerfile for a scheduled batch job built in Go using robfig/cron:
```bash
# Use an official Go image as a base image
FROM golang:1.17

# Set the working directory in the container
WORKDIR /app

# Copy the Go code into the container
COPY . .

# Install any dependencies
RUN go mod tidy

# Build the Go binary
RUN go build -o main .

# Set the command to run the Go binary
CMD ["./main"]

# Install robfig/cron
RUN go get -u github.com/robfig/cron/v3
```

This Dockerfile assumes that your Go code is in a directory called "src" and that you have a "main.go" file in that directory. The Dockerfile first installs the official Go image as a base image, then sets the working directory in the container to "/app". It then copies your Go code into the container, installs any dependencies, builds the Go binary, and sets the command to run the Go binary.
The Dockerfile also installs robfig/cron by using the "go get" command. This will download and install the robfig/cron package from GitHub.
To build and run the Docker container, you can use the following commands:
```csharp
# Build the Docker image
docker build -t my-scheduled-job .

# Run the Docker container
docker run -d --name my-scheduled-job my-scheduled-job
```

This will build the Docker image and give it the tag "my-scheduled-job". It will then run the Docker container in detached mode and give it the name "my-scheduled-job".
