Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel:

```dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set environment variables
ENV PHP_ALLOW_URL_FOPEN 1
ENV COMPOSER_ALLOW_SUPERUSER 1

# Install system dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libonig-dev \
    zip \
    unzip \
    git \
    curl \
    libxml2-dev \
    libzip-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libwebp-dev \
    && docker-php-ext-install pdo_mysql mbstring bcmath zip gd

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Set working directory
WORKDIR /var/www/html

# Copy composer dependencies
COPY composer.json composer.lock ./

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Copy application code
COPY . .

# Install additional PHP extensions
RUN docker-php-ext-install pcntl

# Expose port 9000 and start PHP-FPM server
EXPOSE 9000
CMD ["php-fpm"]
```

### Explanation:
1. **Base Image**: Uses the official PHP 8.1 FPM image from Docker Hub.
2. **Environment Variables**: Sets `PHP_ALLOW_URL_FOPEN` and `COMPOSER_ALLOW_SUPERUSER` to allow URLs in `php.ini` and using Composer as a superuser.
3. **System Dependencies**: Installs necessary libraries for PHP extensions such as `pdo_mysql`, `mbstring`, `bcmath`, `zip`, `gd`, etc.
4. **Composer Installation**: Installs Composer globally.
5. **Working Directory**: Sets the working directory to `/var/www/html`.
6. **Composer Dependencies**: Copies `composer.json` and `composer.lock` to the working directory and installs dependencies.
7. **Application Code**: Copies the rest of the application code.
8. **PHP Extensions**: Installs additional PHP extensions like `pcntl`.
9. **Exposure and Command**: Exposes port 9000 and starts the PHP-FPM server.

### Usage:
1. Save the above Dockerfile in the root directory of your Laravel project.
2. Build the Docker image:
   ```bash
   docker build -t laravel-api .
   ```
3. Run the Docker container:
   ```bash
   docker run -d -p 9000:9000 --name laravel-api-container laravel-api
   ```

This will build a Docker image for your Laravel application and run it as a PHP-FPM server.
