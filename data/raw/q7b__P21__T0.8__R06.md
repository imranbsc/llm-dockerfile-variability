Certainly! Below is a Dockerfile for a REST API built in PHP using Laravel:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set working directory
WORKDIR /var/www/html

# Install system dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libonig-dev \
    libxml2-dev \
    zip \
    unzip \
    git \
    curl \
    libfreetype6-dev \
    libjpeg62-turbo-dev \
    locales \
    && docker-php-ext-install pdo_mysql mbstring pcntl bcmath gd

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy existing application directory contents
COPY . .

# Install dependencies
RUN composer install --optimize-autoloader --no-dev --no-scripts

# Run database migrations
RUN php artisan migrate --force

# Expose port 9000 and start php-fpm server
EXPOSE 9000
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: The Dockerfile starts with `php:7.4-fpm` which provides a PHP 7.4 environment with PHP-FPM (FastCGI Process Manager).

2. **Working Directory**: The working directory is set to `/var/www/html` where your Laravel application will be located.

3. **System Dependencies**: The Dockerfile installs necessary system dependencies required for Laravel, including libraries for image processing, XML, and other utilities.

4. **Composer**: Composer, the PHP dependency manager, is installed and used to install all dependencies from the `composer.json` file.

5. **Database Migrations**: The `php artisan migrate --force` command is used to run migrations. The `--force` flag is used to bypass environment checks and run migrations even if the app is in production.

6. **Expose and Command**: The Dockerfile exposes port 9000, which is the default port for PHP-FPM, and starts the PHP-FPM server.

### Usage:

1. **Build the Docker Image**:
   ```sh
   docker build -t your-app-name .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d --name your-app-container -p 9000:9000 -v $(pwd):/var/www/html your-app-name
   ```

Replace `your-app-name` and `your-app-container` with your preferred names.

This setup assumes that your Laravel application is correctly configured and that all dependencies are listed in your `composer.json` file. Adjust the Dockerfile as needed based on your specific requirements.
