Certainly! Below is a Dockerfile for a server-rendered web application built in PHP using Laravel and Blade:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy the current directory contents into the container at /var/www/html
COPY . .

# Install dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libonig-dev \
    libxml2-dev \
    zip \
    unzip

# Install PHP extensions
RUN docker-php-ext-install pdo_mysql mbstring exif pcntl bcmath gd

# Install composer
COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

# Install Laravel dependencies
RUN composer install --no-dev --optimize-autoloader

# Build the application
RUN php artisan migrate --no-interaction

# Expose port 9000 and start php-fpm server
EXPOSE 9000

CMD ["php-fpm"]
```

This Dockerfile performs the following steps:

1. Uses an official PHP 8.1 FPM image as the base.
2. Sets the working directory to `/var/www/html`.
3. Copies the current directory contents into the container.
4. Installs necessary dependencies like `libpng-dev`, `libonig-dev`, `libxml2-dev`, `zip`, and `unzip`.
5. Installs PHP extensions required for Laravel.
6. Installs Composer.
7. Installs Laravel dependencies using Composer without dev packages.
8. Runs database migrations.
9. Exposes port 9000.
10. Starts the PHP-FPM server.

Make sure to have a `docker-compose.yml` file to run this Dockerfile effectively. Here is an example `docker-compose.yml` file:

```yaml
version: '3.8'

services:
  web:
    build: .
    ports:
      - "9000:9000"
    volumes:
      - .:/var/www/html
      - ./vendor:/var/www/html/vendor
    depends_on:
      - db

  db:
    image: mysql:8.0
    environment:
      MYSQL_DATABASE: your_database
      MYSQL_USER: your_user
      MYSQL_PASSWORD: your_password
      MYSQL_ROOT_PASSWORD: root_password
    volumes:
      - db_data:/var/lib/mysql

volumes:
  db_data:
```

This `docker-compose.yml` file sets up two services: `web` and `db`. The `web` service builds the Docker image and runs the PHP-FPM server, while the `db` service sets up a MySQL database. Adjust the environment variables and volumes according to your needs.
