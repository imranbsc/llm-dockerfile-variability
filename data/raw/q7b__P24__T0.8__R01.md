Certainly! Below is a Dockerfile for a PHP command-line tool built with Symfony Console:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.2-cli

# Set the working directory in the container
WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    git \
    unzip \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libzip-dev \
    && docker-php-ext-install -j$(nproc) gd zip

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy the project files into the container
COPY . /app

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Set the command to run the Symfony Console tool
CMD ["php", "bin/console"]
```

### Explanation:
1. **Base Image**: The `php:8.2-cli` image is used as the base image, which includes a minimal PHP runtime with the command-line interface.
  
2. **Working Directory**: The working directory is set to `/app`, where your project files will be located.

3. **System Dependencies**: Several system dependencies are installed to ensure that PHP extensions like GD, Zip, and others are available.

4. **Composer**: Composer is installed to manage PHP dependencies.

5. **Project Files**: Your project files are copied into the container.

6. **Install Dependencies**: Composer is used to install the project dependencies. The `--no-dev` flag ensures that development dependencies are not installed, and `--optimize-autoloader` optimizes the autoloader for production use.

7. **Command**: The `CMD` instruction sets the default command to run the Symfony Console tool when the container starts. You can pass arguments to this command as needed.

### Building and Running the Docker Container:
1. Build the Docker image:
   ```sh
   docker build -t my-symfony-tool .
   ```

2. Run the Docker container:
   ```sh
   docker run --rm my-symfony-tool <command>
   ```

Replace `<command>` with the actual command you want to run with your Symfony Console tool. For example, if you want to run a command named `app:command`, you would use:
   ```sh
   docker run --rm my-symfony-tool app:command
   ```
