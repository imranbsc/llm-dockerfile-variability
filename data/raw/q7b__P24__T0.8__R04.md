Here is a simple Dockerfile for a Symfony Console command-line tool:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary extensions for Symfony
RUN docker-php-ext-install pdo_mysql

# Copy your Symfony application source code to the container
COPY . /var/www/html

# Install dependencies
RUN composer install --optimize-autoloader --no-dev

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run command when the container launches
CMD ["php", "bin/console", "your:command"]
```

Replace `your:command` with the actual command you want to run.
