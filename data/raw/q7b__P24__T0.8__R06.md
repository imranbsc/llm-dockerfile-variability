Certainly! Below is an example of a Dockerfile for a command-line tool built in PHP using Symfony Console:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-cli

# Set the working directory in the container
WORKDIR /app

# Install required system packages
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libonig-dev \
    libxml2-dev \
    zip \
    unzip \
    git \
    curl \
    libfreetype6-dev \
    libjpeg-dev \
    libjpeg62-turbo-dev \
    locales \
    && docker-php-ext-configure gd --with-freetype --with-jpeg \
    && docker-php-ext-install pdo_mysql gd mbstring intl opcache

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy project files into the container
COPY . /app

# Install project dependencies
RUN composer install --no-dev --optimize-autoloader --no-interaction

# Make the entrypoint script executable
RUN chmod +x /app/entrypoint.sh

# Set the default command
ENTRYPOINT ["/app/entrypoint.sh"]
```

### Explanation:

1. **Base Image**: The `php:8.1-cli` image is used as the base image, which includes PHP 8.1 and the command-line interface.

2. **Working Directory**: The working directory is set to `/app`.

3. **System Packages**: Required system packages are installed for PHP extensions such as `pdo_mysql`, `gd`, `mbstring`, `intl`, and `opcache`.

4. **Composer**: Composer is installed to manage PHP dependencies.

5. **Project Files**: The project files are copied into the container using the `COPY` command.

6. **Dependencies**: The project dependencies are installed using Composer with options to optimize the autoloader and avoid interactive prompts.

7. **Entry Point**: An entrypoint script (`entrypoint.sh`) is made executable and set as the default command. This script can be used to run your Symfony Console application.

### Entry Point Script (`entrypoint.sh`):

Create an `entrypoint.sh` script in the root of your project:

```sh
#!/bin/bash

# Set the default command to run the Symfony Console application
exec php bin/console "$@"
```

This script will run the Symfony Console application with any command-line arguments passed to it.

### Build and Run:

1. Build the Docker image:
    ```sh
    docker build -t my-php-symfony-app .
    ```

2. Run the Docker container:
    ```sh
    docker run --rm my-php-symfony-app
    ```

This will start the Symfony Console application inside the Docker container, and you can interact with it using the command-line interface.
