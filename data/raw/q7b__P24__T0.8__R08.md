```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-cli

# Install Symfony Console globally
RUN composer global require symfony/console

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Set permissions for the command-line tool
RUN chmod +x /app/bin/your-tool.php

# Make port 80 available to the world outside this container
EXPOSE 80

# Define environment variable
ENV NAME World

# Run your command-line tool when the container launches
CMD ["php", "/app/bin/your-tool.php"]
```

This Dockerfile sets up a basic environment for running a Symfony Console-based PHP command-line tool. It uses the official PHP 7.4 CLI image from Docker Hub, installs Symfony Console globally via Composer, copies the application code into the container, sets the correct permissions for the tool, exposes port 80, and defines an environment variable. Finally, it specifies the command to run the tool when the container starts.
