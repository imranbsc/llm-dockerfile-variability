Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using the Laravel task scheduler:

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Install system dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    zip \
    unzip \
    git \
    cron \
    curl \
    libonig-dev \
    libxml2-dev \
    && docker-php-ext-install pdo_mysql mbstring exif pcntl bcmath gd

# Clear cache
RUN apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# Install Composer
COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

# Set working directory
WORKDIR /var/www/html

# Copy existing application directory contents
COPY . .

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Copy crontab file
COPY crontab /etc/cron.d/laravel-scheduler

# Give permission for cron
RUN chmod 0644 /etc/cron.d/laravel-scheduler \
    && crontab /etc/cron.d/laravel-scheduler \
    && touch /var/log/cron.log

# Expose port 9000 and start php-fpm server
EXPOSE 9000

CMD ["php-fpm"]
```

### Explanation:
1. **Base Image**: Uses the official PHP 7.4-FPM image.
2. **Dependencies**: Installs necessary system dependencies for PHP extensions like `png`, `jpeg`, `freetype`, `zip`, and `unzip`.
3. **Composer**: Installs Composer.
4. **Working Directory**: Sets the working directory to `/var/www/html`.
5. **Copy Application Files**: Copies the application files into the container.
6. **Install Dependencies**: Installs PHP dependencies using Composer.
7. **Cron Job**: Copies a crontab file and sets up the Laravel scheduler to run.
8. **Expose Port**: Exposes port 9000 for the PHP-FPM server.
9. **Command**: Runs the PHP-FPM server.

### Crontab File (`crontab`):
```bash
* * * * * /usr/bin/php /var/www/html/artisan schedule:run >> /var/log/cron.log 2>&1
```

This crontab entry will run the Laravel scheduler every minute. Adjust the schedule as needed.

### Usage:
1. Place your Laravel application files in the same directory as the Dockerfile.
2. Build the Docker image:
   ```sh
   docker build -t your-image-name .
   ```
3. Run the Docker container:
   ```sh
   docker run -d -p 9000:9000 --name your-container-name your-image-name
   ```

This setup will run your Laravel application with the scheduled batch jobs using PHP-FPM and the Laravel task scheduler.
