```dockerfile
# Use an official PHP runtime as a parent image
FROM php:7.4-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Copy local code to the container image
COPY . /var/www/html

# Install PHP extensions required by Laravel
RUN docker-php-ext-install pdo_mysql

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Install dependencies
RUN composer install --optimize-autoloader --no-dev

# Set up the Laravel scheduler
RUN (crontab -l 2>/dev/null; echo "* * * * * php /var/www/html/artisan schedule:run >> /dev/null 2>&1") | crontab -

# Expose port 9000 and start php-fpm server
EXPOSE 9000
CMD ["php-fpm"]
```

**Explanation**:
- The Dockerfile starts with a base image `php:7.4-fpm` which is suitable for PHP applications.
- The working directory is set to `/var/www/html` where your Laravel application will reside.
- The application code is copied into the container.
- The required PHP extension `pdo_mysql` is installed to allow PHP applications to interact with MySQL databases.
- Composer is installed to manage PHP dependencies.
- Dependencies are installed using Composer, with `--optimize-autoloader --no-dev` to ensure the production environment is optimized.
- Laravel's task scheduler is set up to run every minute using a cron job. The output of the scheduler is redirected to `/dev/null` to keep the container's logs clean.
- The container exposes port 9000, which is the default port used by PHP-FPM, and starts the PHP-FPM server when the container runs.
