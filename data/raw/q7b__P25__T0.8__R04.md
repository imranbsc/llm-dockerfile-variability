Certainly! Below is a Dockerfile for a scheduled batch job built in PHP using the Laravel task scheduler. This Dockerfile assumes you have a basic Laravel project set up.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set environment variables
ENV APP_ENV=production
ENV APP_DEBUG=false

# Install dependencies
RUN apt-get update && apt-get install -y \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    zip \
    unzip \
    git

# Install PHP extensions
RUN docker-php-ext-install pdo_mysql mbstring exif pcntl bcmath gd

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

# Copy application files
COPY . /var/www/html

# Install application dependencies
WORKDIR /var/www/html
RUN composer install --no-dev --optimize-autoloader

# Copy Laravel scheduler cron job
COPY crontab /etc/cron.d/laravel-scheduler

# Give permission to laravel scheduler cron job
RUN chmod 0644 /etc/cron.d/laravel-scheduler

# Run cron job
RUN crontab /etc/cron.d/laravel-scheduler

# Expose the port the web server is listening on
EXPOSE 9000

# Start the PHP-FPM server
CMD ["php-fpm"]
```

### Explanation:

1. **Base Image**: We start with the official PHP 8.1 FPM image.
2. **Environment Variables**: Set environment variables for the application environment.
3. **Dependencies**: Install necessary packages for PHP and dependencies.
4. **PHP Extensions**: Install required PHP extensions.
5. **Composer**: Install Composer for PHP dependencies.
6. **Application Files**: Copy your Laravel application files into the container.
7. **Install Dependencies**: Install application dependencies using Composer.
8. **Cron Job**: Copy the Laravel scheduler cron job and set its permissions.
9. **Expose Port**: Expose port 9000 where PHP-FPM is running.
10. **Start Server**: Start the PHP-FPM server.

### Additional Notes:

- Ensure you have a `crontab` file in the root of your project with the appropriate cron job. For example:

```bash
* * * * * root cd /var/www/html && php artisan schedule:run >> /dev/null 2>&1
```

- Make sure your Laravel application's `config/scheduler.php` is set up correctly to schedule your tasks.
- You might need to adjust the PHP extensions and dependencies based on your specific application requirements.
