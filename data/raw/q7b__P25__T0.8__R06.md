Certainly! Below is an example of a Dockerfile for a scheduled batch job built in PHP using the Laravel task scheduler.

```Dockerfile
# Use an official PHP runtime as a parent image
FROM php:8.1-fpm

# Set the working directory in the container
WORKDIR /var/www/html

# Install necessary extensions
RUN docker-php-ext-install pdo_mysql

# Copy the application code into the container
COPY . .

# Install dependencies
RUN composer install --no-dev --optimize-autoloader

# Expose the port that Laravel will use
EXPOSE 9000

# Command to run Laravel's scheduler
CMD ["php", "artisan", "schedule:run"]
```

This Dockerfile sets up a PHP environment with the necessary extensions, copies the Laravel application code into the container, installs dependencies, and sets up the command to run Laravel's scheduler.

To use this Dockerfile, make sure your Laravel application is structured correctly and the Laravel task scheduler is configured. You can then build and run your Docker container using Docker commands.
