Certainly! Below is a Dockerfile for a REST API built in C# using ASP.NET Core:

```dockerfile
# Use the official ASP.NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
EXPOSE 80

# Use the official ASP.NET Core SDK image to build the application
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build
WORKDIR /src
COPY ["YourProjectName.csproj", "./"]
RUN dotnet restore
COPY . .
WORKDIR "/src/."
RUN dotnet build "YourProjectName.csproj" -c Release -o /app/build

# Publish the application to a temporary location
FROM build AS publish
RUN dotnet publish "YourProjectName.csproj" -c Release -o /app/publish

# Use the base image again for the final image
FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "YourProjectName.dll"]
```

### Notes:
1. **Replace `YourProjectName`**: Replace `YourProjectName` with the actual name of your C# project.
2. **Dockerfile Structure**:
   - **Base Image**: Uses the official ASP.NET Core runtime image.
   - **Build Stage**: Uses the SDK image to restore, build, and publish the application.
   - **Final Image**: Uses the runtime image and copies the published application into it.

### Building and Running the Docker Image:

1. **Build the Docker Image**:
   ```sh
   docker build -t your-api-image .
   ```

2. **Run the Docker Container**:
   ```sh
   docker run -d -p 8080:80 --name your-api-container your-api-image
   ```

This will build your ASP.NET Core application into a Docker image and run it in a container, making the application accessible at `http://localhost:8080`.
