Here is a simple Dockerfile for a C# ASP.NET Core REST API:

```Dockerfile
# Use the official .NET Core image from the Microsoft container registry
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env
WORKDIR /app

# Copy csproj and restore as distinct layers
COPY *.csproj ./
RUN dotnet restore

# Copy everything else and build
COPY . ./
RUN dotnet publish -c Release -o out

# Use the official ASP.NET Core runtime image from the Microsoft container registry
FROM mcr.microsoft.com/dotnet/aspnet:6.0
WORKDIR /app
COPY --from=build-env /app/out .
ENTRYPOINT ["dotnet", "YourAppName.dll"]
```

Just replace "YourAppName.dll" with the actual name of your .NET Core application assembly.

This Dockerfile uses multi-stage build to first build the application on a development image and then publish it on a smaller runtime image. This ensures that only the necessary files are included in the final image, reducing its size.
