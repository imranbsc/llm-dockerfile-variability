Certainly! Below is an example of a Dockerfile for a REST API built in C# using ASP.NET Core:

```Dockerfile
# Use the official .NET SDK image from Microsoft as the parent image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env
WORKDIR /app

# Copy all files and restore dependencies
COPY *.csproj ./
RUN dotnet restore

# Copy the project files and build the project
COPY . ./
RUN dotnet publish -c Release -o out

# Use the official .NET runtime image from Microsoft as the final image
FROM mcr.microsoft.com/dotnet/aspnet:6.0
WORKDIR /app

# Copy the published application from the build stage
COPY --from=build-env /app/out .

# Expose the port the app runs on
EXPOSE 80

# Run the application when the container launches
ENTRYPOINT ["dotnet", "YourProjectName.dll"]
```

### Explanation:
- `FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env`: This line sets up a build stage using the official .NET SDK image. The `AS build-env` label names this stage for reference later.

- `WORKDIR /app`: This sets the working directory inside the container.

- `COPY *.csproj .`: This copies the `*.csproj` file(s) to the working directory.

- `RUN dotnet restore`: This restores the dependencies defined in the `*.csproj` file.

- `COPY . ./`: This copies the entire contents of the current directory into the working directory of the container.

- `RUN dotnet publish -c Release -o out`: This compiles and publishes the application in Release mode to the `out` directory.

- `FROM mcr.microsoft.com/dotnet/aspnet:6.0`: This sets up the final stage using the official .NET runtime image.

- `WORKDIR /app`: This sets the working directory inside the container.

- `COPY --from=build-env /app/out .`: This copies the published application from the build stage to the final stage.

- `EXPOSE 80`: This exposes port 80, which is the default port for HTTP applications.

- `ENTRYPOINT ["dotnet", "YourProjectName.dll"]`: This specifies the command to run the application when the container starts. Replace `YourProjectName.dll` with the actual name of your compiled DLL.

### Build and Run:
To build and run the Docker container, you can use the following commands:

```bash
# Build the Docker image
docker build -t your-api-image .

# Run the Docker container
docker run -d -p 8080:80 --name your-api-container your-api-image
```

This will build the Docker image and start a container running your ASP.NET Core API, accessible at `http://localhost:8080`.
