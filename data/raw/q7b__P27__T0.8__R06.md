Here is a basic example of a Dockerfile for a server-rendered web application built in C# using ASP.NET Core MVC:

```Dockerfile
# Use the official .NET Core runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
EXPOSE 80

# Use the official .NET Core SDK to build the application
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build
WORKDIR /src
COPY ["YourProject.csproj", "./"]
RUN dotnet restore
COPY . .
WORKDIR "/src/."
RUN dotnet build "YourProject.csproj" -c Release -o /app/build

# Publish the application to a temporary directory
FROM build AS publish
RUN dotnet publish "YourProject.csproj" -c Release -o /app/publish

# Use the base image again to create a slim image with the published application
FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "YourProject.dll"]
```

Remember to replace "YourProject.csproj" with the actual name of your project file. Also, replace "YourProject.dll" with the actual name of your published application.

This Dockerfile does the following:

1. It creates a base image from Microsoft's official .NET Core runtime image.
2. It sets the working directory and exposes port 80.
3. It creates a build stage that uses the official .NET Core SDK image to build the application.
4. It creates a publish stage that publishes the application to a temporary directory.
5. It creates a final stage that uses the base image again to create a slim image with the published application.
6. It sets the entrypoint to run the published application.

You can build the Docker image by running the following command in the directory containing your Dockerfile:

```
docker build -t your-image-name .
```

Replace "your-image-name" with a name of your choice.
