```Dockerfile
# Use an official .NET SDK image from Microsoft as the parent image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /app

# Copy the project file and restore dependencies
COPY *.csproj ./
RUN dotnet restore

# Copy the source code and build the application
COPY . ./
RUN dotnet publish -c Release -o out

# Use a smaller base image for production
FROM mcr.microsoft.com/dotnet/aspnet:6.0

# Set the working directory in the container
WORKDIR /app

# Copy the built application from the build stage
COPY --from=build-env /app/out .

# Make the application executable
RUN chmod +x ./YourExecutableName

# Expose the application's port
EXPOSE 5000

# Command to run the application
CMD ["./YourExecutableName"]
```

Please replace `YourExecutableName` with the actual name of your executable. This Dockerfile assumes that your project is a .NET Core application. Adjust the .NET SDK version and ASP.NET version as needed based on your project's requirements.
