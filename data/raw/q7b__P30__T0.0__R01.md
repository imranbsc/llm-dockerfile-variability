```Dockerfile
# Use an official .NET SDK image as the base image
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build-env

# Set the working directory in the container
WORKDIR /app

# Copy the project file and restore dependencies
COPY *.csproj ./
RUN dotnet restore

# Copy the rest of the project files and build
COPY . ./
RUN dotnet publish -c Release -o out

# Use an official .NET runtime image for the final stage
FROM mcr.microsoft.com/dotnet/aspnet:6.0

# Set the working directory in the container
WORKDIR /app

# Copy the published application from the build stage
COPY --from=build-env /app/out .

# Expose the port the application will run on
EXPOSE 80

# Run the application
ENTRYPOINT ["dotnet", "YourAppName.dll"]
```

Make sure to replace `YourAppName.dll` with the actual name of your C# application's DLL file. This Dockerfile assumes that your application is a console application that can be run with `dotnet run`. If your application requires additional configuration or environment variables, you may need to adjust the Dockerfile accordingly.
