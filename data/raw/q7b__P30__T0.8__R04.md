Here is an example Dockerfile for a scheduled batch job built in C# using Quartz.NET:
```bash
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
EXPOSE 80

FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build
WORKDIR /src
COPY ["QuartzJob/QuartzJob.csproj", "QuartzJob/"]
RUN dotnet restore "QuartzJob/QuartzJob.csproj"
COPY . .
WORKDIR "/src/QuartzJob"
RUN dotnet build "QuartzJob.csproj" -c Release -o /app/build

FROM build AS publish
RUN dotnet publish "QuartzJob.csproj" -c Release -o /app/publish

FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "QuartzJob.dll"]
```

This Dockerfile starts with a base image from Microsoft, sets the working directory to `/app`, and exposes port 80. It then uses the `build` stage to restore dependencies, copy the source code, and build the application. The `publish` stage publishes the application, and the `final` stage copies the published application to the base image and sets the entrypoint to run the `QuartzJob.dll` file.
To schedule the batch job using Quartz.NET, you can add the necessary job and trigger definitions to your C# code and configure the Quartz.NET scheduler in the `Main` method.
```csharp
public class Program
{
    public static void Main(string[] args)
    {
        var schedulerFactory = new StdSchedulerFactory();
        var scheduler = schedulerFactory.GetScheduler().Result;

        var job = JobBuilder.Create<QuartzJob>()
            .WithIdentity("job", "group")
            .Build();

        var trigger = TriggerBuilder.Create()
            .WithIdentity("trigger", "group")
            .WithCronSchedule("0 0 12 * * ?")
            .Build();

        scheduler.ScheduleJob(job, trigger).Wait();
        scheduler.Start().Wait();

        Console.WriteLine("Press any key to exit");
        Console.ReadKey();

        scheduler.Shutdown().Wait();
    }
}
```

In this example, the `QuartzJob` class is a simple job that logs a message to the console. The trigger is set to run the job at 12:00 PM every day using a cron expression.
Note that this is just an example, and you may need to modify the Dockerfile and C# code to suit your specific requirements.
