Certainly! Below is an example of a Dockerfile for a scheduled batch job built in C# using Quartz.NET. This Dockerfile assumes you have a .NET project with a Quartz.NET job and a `quartz.config` file.

```Dockerfile
# Use an official .NET runtime as a parent image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS base
WORKDIR /app
EXPOSE 80

# Use an official .NET SDK as a parent image to build the app
FROM mcr.microsoft.com/dotnet/sdk:6.0 AS build
WORKDIR /src
COPY ["YourProjectName/YourProjectName.csproj", "YourProjectName/"]
RUN dotnet restore
COPY . .
WORKDIR "/src/YourProjectName"
RUN dotnet build "YourProjectName.csproj" -c Release -o /app/build

# Build the app for production
FROM build AS publish
RUN dotnet publish "YourProjectName.csproj" -c Release -o /app/publish

# Final stage to run the application
FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "YourProjectName.dll"]
```

### Explanation:
1. **Base Image**: The base image is `mcr.microsoft.com/dotnet/aspnet:6.0`, which is a lightweight image for running .NET applications.
2. **Working Directory**: `/app` is set as the working directory.
3. **Expose Port**: `EXPOSE 80` exposes port 80, although this might not be necessary if you are running the job in a non-web context.
4. **Build Stage**: The build stage uses `mcr.microsoft.com/dotnet/sdk:6.0` to restore dependencies, build the application, and publish it.
5. **Publish Stage**: The publish stage copies the published application into the final image.
6. **Final Stage**: The final stage runs the published application.

### Additional Notes:
- Replace `YourProjectName` with the actual name of your project.
- Ensure your `quartz.config` file is included in your project and copied to the output directory during the build process.
- If you need to mount a configuration file or other resources dynamically, you can adjust the `COPY` command accordingly.

This Dockerfile will build a container that runs your C# application with Quartz.NET, allowing it to schedule and execute batch jobs.
