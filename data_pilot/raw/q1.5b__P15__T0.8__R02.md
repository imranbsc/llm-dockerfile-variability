```dockerfile
# Use an official Java runtime as a parent image
FROM openjdk:11-jdk-slim

# Set the working directory in the container
WORKDIR /app

# Copy the current directory contents into the container at /app
COPY . /app

# Install any needed packages specified in pom.xml
RUN mvn install

# Run the app
CMD ["java", "-jar", "target/my-java-spring-boot-api.jar"]
```

In this Dockerfile:
- The base image is `openjdk:11-jdk-slim` which provides a lightweight OpenJDK 11 runtime.
- The working directory is set to `/app` where the project files will be placed.
- The current directory contents are copied into the container at `/app`.
- The Maven `install` command is used to build the project and install the dependencies.
- Finally, the application is run using the `java` command with the JAR file located at `target/my-java-spring-boot-api.jar`.
